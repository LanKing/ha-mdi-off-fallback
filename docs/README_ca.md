> Home Assistant permet utilitzar qualsevol icona MDI, però no totes disposen d’una variant `-off`. Com a resultat, un dispositiu pot estar apagat mentre la icona encara sembla activa. Aquest complement afegeix automàticament una barra diagonal d’estil MDI a les entitats inactives quan no hi ha cap icona d’apagat nativa disponible.

# 🚫 MDI Off Fallback per a Home Assistant

![Visualització del funcionament del complement](demo.jpg)

El complement està dissenyat perquè la barra diagonal afegida sembli una part nativa de Home Assistant:
* funciona amb les targetes Tile estàndard sense substituir-les i conserva l’aspecte, el comportament, els colors, les mides i les interaccions originals;
* només modifica les icones ja renderitzades i només quan no existeix cap variant `-off` nativa;
* afegeix un fons circular tènue d’estil Home Assistant quan falta el fons natiu;
* no modifica els estats de les entitats ni interfereix amb el funcionament dels dispositius.

<a id="installation"></a>
## 📦 Instal·lació

### 🛍 Instal·lació mitjançant HACS
ℹ️ [Què és HACS i com s’instal·la?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_ca.md)

#### 1. Afegir aquest repositori a HACS
La incorporació oficial del complement a HACS pot trigar mesos, així que primer cal afegir el repositori manualment:
1. Obriu HACS.
2. Obriu el menú de la cantonada superior dreta i seleccioneu **Repositoris personalitzats** (**Custom repositories**).
3. Afegiu el repositori:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```

4. Seleccioneu el tipus **Tauler** (**Dashboard**) i premeu **Afegeix** (**Add**).

> Afegir el repositori a **Repositoris personalitzats** només fa que el complement estigui disponible a HACS. El complement s’instal·la per separat amb el botó **Baixa** (**Download**).

#### 2. Instal·lar el complement
1. Cerqueu a HACS: `MDI Off Fallback` i obriu-lo.
2. Premeu **Baixa** (**Download**) i confirmeu la instal·lació.
3. Quan acabi la baixada, torneu a carregar Home Assistant esborrant la memòria cau del navegador.

<a id="manual-installation"></a>
### 🧑‍💻 Instal·lació manual (sense HACS)

1. Baixeu [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Copieu el fitxer a `/config/www/ha-mdi-off-fallback.js`.
3. [Aneu a Recursos](https://my.home-assistant.io/redirect/lovelace_resources/) o obriu-los manualment a Home Assistant: **Configuració → Taulers → ⋮ → Recursos** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Premeu **Afegeix un recurs** (**Add resource**).
5. Introduïu `/local/ha-mdi-off-fallback.js` al camp URL.
6. Seleccioneu **Mòdul JavaScript** (**JavaScript Module**) i premeu **Crea** (**Create**).
7. Torneu a carregar Home Assistant esborrant la memòria cau del navegador.

<a id="configuration"></a>
## 🔧 Configuració

La configuració personalitzada és opcional. Sense un fitxer personalitzat, el complement utilitza els valors integrats:

<a id="default-configuration"></a>
### Configuració predeterminada

Per defecte, els estats següents es consideren inactius:

| Domini de l’entitat | Estats inactius |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

També s’utilitzen els paràmetres següents:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Configuració personalitzada

Per definir les vostres pròpies regles, creeu el fitxer:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Exemple:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

La configuració s’emmagatzema separadament dels fitxers del complement gestionats per HACS, de manera que les actualitzacions no la sobreescriuran.

#### Com funciona la secció `states`

Si la configuració personalitzada conté un objecte `states`, aquest **substitueix completament** la llista integrada. El complement només tindrà en compte els dominis i estats indicats explícitament.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

En aquest exemple, la barra diagonal només s’aplicarà a `light` i `cover`. No s’utilitzaran les regles integrades per a `switch`, `fan`, `climate` ni la resta de dominis.

Per tornar a la llista integrada, elimineu `states` de la configuració o suprimiu el fitxer de configuració.

La resta de paràmetres són independents: si no s’indica un paràmetre, es conserva el seu valor integrat.

<a id="background"></a>
#### Fons de la icona inactiva

Si Home Assistant ja mostra el fons natiu de la icona inactiva, el complement no el modifica.

Si aquest fons no existeix, el complement afegeix un cercle tènue que coincideix amb l’estil de la icona Tile inactiva estàndard de Home Assistant.

Per desactivar-lo:

```json
{
  "faint_background_when_missing": false
}
```

Per canviar l’opacitat:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Configuració temporal des de la consola

`haMdiOffFallback.configure()` utilitza la mateixa lògica.

Un objecte `states` proporcionat substitueix completament la llista actual:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Si no es proporciona `states`, la llista actual no canvia:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Els ajustos aplicats amb `configure()` només romanen actius a la pestanya actual fins que es torna a carregar la pàgina. Per a una configuració permanent, utilitzeu el fitxer JSON.

<a id="reload-config"></a>
#### Tornar a carregar la configuració

Després de modificar el fitxer JSON, podeu tornar a carregar la configuració sense tornar a carregar la pàgina:

```js
haMdiOffFallback.reloadConfig()
```

Per veure la configuració activa:

```js
haMdiOffFallback.getConfig()
```
