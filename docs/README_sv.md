> Home Assistant låter dig använda valfria MDI-ikoner, men alla har inte en `-off`-variant. En enhet kan därför redan vara avstängd medan ikonen fortfarande ser aktiv ut. Detta tillägg lägger automatiskt till ett snedstreck i MDI-stil för inaktiva entiteter när någon inbyggd av-ikon saknas.

# 🚫 MDI Off Fallback för Home Assistant

![Visualisering av tilläggets funktion](demo.jpg)

Tillägget är utformat så att det tillagda snedstrecket ser ut som en inbyggd del av Home Assistant:
* fungerar med standardkortet Ruta utan att ersätta det och bevarar utseende, beteende, färger, storlekar och interaktioner;
* ändrar endast redan renderade ikoner och endast när en inbyggd `-off`-variant saknas;
* kan valfritt lägga till en svag cirkulär bakgrund när den ursprungliga bakgrunden saknas;
* ändrar inte entiteternas tillstånd och påverkar inte enheternas funktion.
<a id="installation"></a>
## 📦 Installation

### 🛍 Installation via HACS
ℹ️ [Vad är HACS och hur installerar jag det?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_sv.md)

#### 1. Lägg till detta arkiv i HACS
Det kan ta flera månader innan tillägget läggs till i HACS standardkatalog, så lägg först till arkivet manuellt:
1. Öppna HACS.
2. Öppna menyn uppe till höger och välj **Anpassade arkiv**.
3. Lägg till arkivet:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Välj typen **Instrumentpanel** och klicka på **Lägg till**.

> Att lägga till arkivet under **Anpassade arkiv** gör bara tillägget tillgängligt i HACS. Själva tillägget installeras separat med knappen **Ladda ned**.

#### 2. Installera tillägget
1. Sök i HACS efter: `MDI Off Fallback` och öppna det.
2. Klicka på **Ladda ned** och bekräfta installationen.
3. När nedladdningen är klar, uppdatera Home Assistant-sidan och rensa webbläsarens cache.

<a id="manual-installation"></a>
### 🧑‍💻 Manuell installation (utan HACS)

1. Ladda ned [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Kopiera filen till `/config/www/ha-mdi-off-fallback.js`.
3. [Gå till Resurser](https://my.home-assistant.io/redirect/lovelace_resources/) eller öppna dem manuellt i Home Assistant: **Inställningar → Instrumentpaneler → ⋮ → Resurser** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Klicka på **Lägg till resurs** (**Add resource**).
5. Ange `/local/ha-mdi-off-fallback.js` i URL-fältet.
6. Välj **JavaScript-modul** (**JavaScript Module**) och klicka på **Skapa** (**Create**).
7. Uppdatera Home Assistant-sidan och rensa webbläsarens cache.

<a id="configuration"></a>
## 🔧 Konfiguration

Anpassad konfiguration är valfri. Utan en anpassad fil använder tillägget de inbyggda värdena:

<a id="default-configuration"></a>
### Standardkonfiguration

Som standard betraktas följande tillstånd som inaktiva:

| Entitetsdomän | Inaktiva tillstånd |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Följande inställningar används också:

```json
{
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Anpassad konfiguration

Skapa följande fil för att ange egna regler:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Exempel:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Konfigurationen lagras separat från tilläggsfilerna som hanteras av HACS, så uppdateringar skriver inte över den.

#### Så fungerar avsnittet `states`

Om den anpassade konfigurationen innehåller ett `states`-objekt **ersätter det hela** den inbyggda listan. Tillägget tar då endast hänsyn till de domäner och tillstånd som uttryckligen anges.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

I detta exempel används snedstrecket endast för `light` och `cover`. De inbyggda reglerna för `switch`, `fan`, `climate` och andra domäner används inte.

Ta bort `states` från konfigurationen eller radera konfigurationsfilen för att återgå till den inbyggda listan.

Övriga inställningar är oberoende: om en inställning utelämnas används dess inbyggda värde.

<a id="background"></a>
#### Valfri bakgrund för ikoner utan cirkel

Vissa MDI-ikoner är visuellt förskjutna. Efter att ett snedstreck har lagts till kan de se obalanserade ut när det inte finns någon cirkulär bakgrund för att rama in dem.

Detta störde min känsla för visuell ordning, så pluginet inkluderar en valfri inställning som ritar en svag cirkel bakom inaktiva ikoner när Home Assistant inte tillhandahåller en.

Det här alternativet är inaktiverat som standard eftersom cirkeln har en betydelse i Home Assistant-gränssnittet: på ett Tile-kort indikerar det normalt att ett klick på ikonen utför en separat åtgärd från att klicka på resten av kortet. Att lägga till en cirkel enbart för visuell justering förändrar därför den visuella semantiken.

Du kan fortfarande aktivera bakgrunden om du föredrar det mer balanserade utseendet:

```json
{
  "faint_background_when_missing": true
}
```

När det är aktiverat lägger insticksprogrammet bara till bakgrunden där Home Assistant inte redan renderar en.

Du kan också justera dess opacitet:

```json
{
  "faint_background_opacity": 0.2
}
```

Välj vilket beteende som är viktigast för din instrumentpanel: bevara Home Assistant:s inbyggda interaktionssignaler eller håll de nedskurna ikonerna visuellt centrerade.

<a id="runtime-configuration"></a>
#### Tillfällig konfiguration via konsolen

`haMdiOffFallback.configure()` använder samma regler.

Ett angivet `states`-objekt ersätter hela den aktuella listan:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Om `states` utelämnas förblir den aktuella listan oförändrad:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Inställningar som görs med `configure()` gäller endast på den aktuella fliken tills sidan laddas om. Använd JSON-filen för permanent konfiguration.

<a id="reload-config"></a>
#### Läs in konfigurationen igen

Efter att JSON-filen ändrats kan konfigurationen läsas in igen utan att sidan uppdateras:

```js
haMdiOffFallback.reloadConfig()
```

Visa den aktiva konfigurationen:

```js
haMdiOffFallback.getConfig()
```
