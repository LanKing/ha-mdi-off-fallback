> Home Assistant umožňuje používat libovolné ikony MDI, ale ne každá má variantu `-off`. Zařízení tak může být vypnuté, zatímco jeho ikona stále vypadá aktivně. Tento doplněk automaticky přidává neaktivním entitám přeškrtnutí ve stylu MDI, pokud není k dispozici nativní ikona vypnutého stavu.

# 🚫 MDI Off Fallback pro Home Assistant

![Ukázka funkce doplňku](demo.jpg)

Doplněk je navržen tak, aby přidané přeškrtnutí působilo jako nativní součást Home Assistantu:
* funguje se standardními kartami Tile bez jejich nahrazení a zachovává jejich původní vzhled, chování, barvy, rozměry a interakce;
* upravuje pouze již vykreslené ikony a jen tehdy, když není dostupná nativní varianta `-off`;
* přidává jemné kruhové pozadí ve stylu Home Assistantu, pokud nativní pozadí chybí;
* nemění stavy entit a nezasahuje do fungování zařízení.

<a id="installation"></a>
## 📦 Instalace

### 🛍 Instalace přes HACS
ℹ️ [Co je HACS a jak se instaluje?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_cs.md)

#### 1. Přidání tohoto repozitáře do HACS
Oficiální přidání doplňku do HACS může trvat několik měsíců, proto nejprve přidejte repozitář ručně:
1. Otevřete HACS.
2. Otevřete nabídku v pravém horním rohu a vyberte **Vlastní repozitáře** (**Custom repositories**).
3. Přidejte repozitář:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```

4. Vyberte typ **Nástěnka** (**Dashboard**) a klikněte na **Přidat** (**Add**).

> Přidání repozitáře do **Vlastních repozitářů** pouze zpřístupní doplněk v HACS. Samotný doplněk se instaluje samostatně tlačítkem **Stáhnout** (**Download**).

#### 2. Instalace doplňku
1. V HACS vyhledejte: `MDI Off Fallback` a otevřete jej.
2. Klikněte na **Stáhnout** (**Download**) a potvrďte instalaci.
3. Po dokončení stahování znovu načtěte Home Assistant a vymažte mezipaměť prohlížeče.

<a id="manual-installation"></a>
### 🧑‍💻 Ruční instalace (bez HACS)

1. Stáhněte [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Zkopírujte soubor do `/config/www/ha-mdi-off-fallback.js`.
3. [Přejděte do Zdrojů](https://my.home-assistant.io/redirect/lovelace_resources/) nebo je otevřete ručně v Home Assistantu: **Nastavení → Nástěnky → ⋮ → Zdroje** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Klikněte na **Přidat zdroj** (**Add resource**).
5. Do pole URL zadejte `/local/ha-mdi-off-fallback.js`.
6. Vyberte **Modul JavaScript** (**JavaScript Module**) a klikněte na **Vytvořit** (**Create**).
7. Znovu načtěte Home Assistant a vymažte mezipaměť prohlížeče.

<a id="configuration"></a>
## 🔧 Nastavení

Vlastní konfigurace je volitelná. Bez vlastního souboru používá doplněk vestavěné hodnoty:

<a id="default-configuration"></a>
### Výchozí konfigurace

Ve výchozím nastavení jsou následující stavy považovány za neaktivní:

| Doména entity | Neaktivní stavy |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Používají se také následující parametry:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Vlastní konfigurace

Chcete-li definovat vlastní pravidla, vytvořte soubor:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Příklad:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Konfigurace je uložena odděleně od souborů doplňku spravovaných HACS, takže ji aktualizace doplňku nepřepíšou.

#### Chování sekce `states`

Pokud vlastní konfigurace obsahuje objekt `states`, **zcela nahradí** vestavěný seznam. Doplněk bude zohledňovat pouze výslovně uvedené domény a stavy.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

V tomto příkladu se přeškrtnutí použije pouze pro `light` a `cover`. Vestavěná pravidla pro `switch`, `fan`, `climate` a ostatní domény se nepoužijí.

Chcete-li se vrátit k vestavěnému seznamu, odstraňte `states` z konfigurace nebo smažte konfigurační soubor.

Ostatní parametry jsou nezávislé: pokud parametr není zadán, zůstane použita jeho vestavěná hodnota.

<a id="background"></a>
#### Pozadí neaktivní ikony

Pokud Home Assistant již vykresluje nativní pozadí neaktivní ikony, doplněk jej nemění.

Pokud pozadí chybí, doplněk přidá jemný kruh odpovídající standardnímu vzhledu neaktivní ikony Tile v Home Assistantu.

Vypnutí:

```json
{
  "faint_background_when_missing": false
}
```

Změna průhlednosti:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Dočasné nastavení z konzole

`haMdiOffFallback.configure()` používá stejnou logiku.

Předaný objekt `states` zcela nahradí aktuální seznam:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Pokud `states` není předán, aktuální seznam se nezmění:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Nastavení použitá pomocí `configure()` platí pouze na aktuální kartě do opětovného načtení stránky. Pro trvalou konfiguraci použijte soubor JSON.

<a id="reload-config"></a>
#### Opětovné načtení konfigurace

Po úpravě souboru JSON lze konfiguraci načíst znovu bez opětovného načtení stránky:

```js
haMdiOffFallback.reloadConfig()
```

Zobrazení aktivní konfigurace:

```js
haMdiOffFallback.getConfig()
```
