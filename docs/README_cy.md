# 🚫 MDI Off Fallback ar gyfer Home Assistant

![Dangos swyddogaeth yr ategyn](demo.jpg)

Mae’r ategyn wedi’i gynllunio fel bod y llinell groes ychwanegol yn edrych fel rhan frodorol o Home Assistant:
* yn gweithio gyda chardiau Tile safonol heb eu disodli ac yn cadw eu hymddangosiad, ymddygiad, lliwiau, meintiau a rhyngweithiadau gwreiddiol;
* yn newid eiconau sydd eisoes wedi’u rendro yn unig, a dim ond pan nad oes amrywiad `-off` brodorol;
* yn ychwanegu cefndir crwn golau yn arddull Home Assistant os nad oes cefndir brodorol;
* nid yw’n newid cyflwr endidau nac yn ymyrryd â gweithrediad dyfeisiau.

<a id="installation"></a>
## 📦 Gosod

### 🛍 Gosod drwy HACS
ℹ️ [Beth yw HACS a sut mae ei osod?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_cy.md)

#### 1. Ychwanegu’r ystorfa hon at HACS
Gall gymryd misoedd cyn i’r ategyn gael ei ychwanegu’n swyddogol at HACS, felly ychwanegwch yr ystorfa â llaw yn gyntaf:
1. Agorwch HACS.
2. Agorwch y ddewislen yn y gornel dde uchaf a dewiswch **Ystorfeydd personol** (**Custom repositories**).
3. Ychwanegwch yr ystorfa:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```

4. Dewiswch y math **Dangosfwrdd** (**Dashboard**) a chliciwch **Ychwanegu** (**Add**).

> Mae ychwanegu’r ystorfa at **Ystorfeydd personol** ond yn gwneud yr ategyn ar gael yn HACS. Gosodir yr ategyn ei hun ar wahân gyda’r botwm **Lawrlwytho** (**Download**).

#### 2. Gosod yr ategyn
1. Chwiliwch yn HACS am: `MDI Off Fallback` a’i agor.
2. Cliciwch **Lawrlwytho** (**Download**) a chadarnhewch y gosodiad.
3. Ar ôl i’r lawrlwythiad orffen, ail-lwythwch Home Assistant gan glirio storfa’r porwr.

<a id="manual-installation"></a>
### 🧑‍💻 Gosod â llaw (heb HACS)

1. Lawrlwythwch [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Copïwch y ffeil i `/config/www/ha-mdi-off-fallback.js`.
3. [Ewch i Adnoddau](https://my.home-assistant.io/redirect/lovelace_resources/) neu eu hagor â llaw yn Home Assistant: **Gosodiadau → Dangosfyrddau → ⋮ → Adnoddau** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Cliciwch **Ychwanegu adnodd** (**Add resource**).
5. Rhowch `/local/ha-mdi-off-fallback.js` yn y maes URL.
6. Dewiswch **Modiwl JavaScript** (**JavaScript Module**) a chliciwch **Creu** (**Create**).
7. Ail-lwythwch Home Assistant gan glirio storfa’r porwr.

<a id="configuration"></a>
## 🔧 Ffurfweddu

Mae ffurfweddiad personol yn ddewisol. Heb ffeil bersonol, mae’r ategyn yn defnyddio’r gwerthoedd adeiledig:

<a id="default-configuration"></a>
### Ffurfweddiad diofyn

Yn ddiofyn, ystyrir y cyflyrau canlynol yn anweithredol:

| Parth endid | Cyflyrau anweithredol |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Defnyddir y gosodiadau canlynol hefyd:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Ffurfweddiad personol

I ddiffinio eich rheolau eich hun, crëwch y ffeil:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Enghraifft:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Cedwir y ffurfweddiad ar wahân i ffeiliau’r ategyn a reolir gan HACS, felly ni fydd diweddariadau’r ategyn yn ei drosysgrifo.

#### Sut mae’r adran `states` yn gweithio

Os yw’r ffurfweddiad personol yn cynnwys gwrthrych `states`, mae’n **disodli’r rhestr adeiledig yn llwyr**. Dim ond y parthau a’r cyflyrau a restrir yn benodol fydd yr ategyn yn eu hystyried.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

Yn yr enghraifft hon, cymhwysir y llinell groes i `light` a `cover` yn unig. Ni ddefnyddir y rheolau adeiledig ar gyfer `switch`, `fan`, `climate` na’r parthau eraill.

I ddychwelyd at y rhestr adeiledig, tynnwch `states` o’r ffurfweddiad neu dilëwch y ffeil ffurfweddu.

Mae’r gosodiadau eraill yn annibynnol: os na nodir gosodiad, mae ei werth adeiledig yn parhau’n weithredol.

<a id="background"></a>
#### Cefndir eicon anweithredol

Os yw Home Assistant eisoes yn dangos y cefndir brodorol ar gyfer eicon anweithredol, nid yw’r ategyn yn ei newid.

Os yw’r cefndir ar goll, mae’r ategyn yn ychwanegu cylch golau sy’n cyfateb i arddull safonol eicon Tile anweithredol yn Home Assistant.

Analluogi:

```json
{
  "faint_background_when_missing": false
}
```

Newid tryloywder:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Ffurfweddu dros dro drwy’r consol

Mae `haMdiOffFallback.configure()` yn defnyddio’r un rhesymeg.

Mae gwrthrych `states` a ddarperir yn disodli’r rhestr gyfredol yn llwyr:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Os na ddarperir `states`, ni chaiff y rhestr gyfredol ei newid:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Mae gosodiadau a gymhwysir drwy `configure()` yn aros yn weithredol yn y tab cyfredol yn unig tan ail-lwytho’r dudalen. Defnyddiwch y ffeil JSON ar gyfer ffurfweddiad parhaol.

<a id="reload-config"></a>
#### Ail-lwytho’r ffurfweddiad

Ar ôl golygu’r ffeil JSON, gellir ail-lwytho’r ffurfweddiad heb ail-lwytho’r dudalen:

```js
haMdiOffFallback.reloadConfig()
```

Gweld y ffurfweddiad gweithredol:

```js
haMdiOffFallback.getConfig()
```
