> Home Assistant lejon përdorimin e çdo ikone MDI, por jo çdo ikonë ka një variant `-off`. Si rezultat, pajisja mund të jetë tashmë e fikur ndërsa ikona ende duket aktive. Ky shtojcë u shton automatikisht entiteteve joaktive një vijë diagonale në stilin MDI kur nuk ekziston një ikonë vendase për gjendjen e fikur.

# 🚫 MDI Off Fallback për Home Assistant

![Paraqitja e funksionit të shtojcës](demo.jpg)

Shtojca është ndërtuar që vija e shtuar të duket si pjesë vendase e Home Assistant:
* punon me kartat standarde Pllakë pa i zëvendësuar dhe ruan pamjen, sjelljen, ngjyrat, madhësitë dhe ndërveprimet;
* ndryshon vetëm ikonat e renderuara dhe vetëm kur mungon varianti vendas `-off`;
* shton një sfond të zbehtë rrethor në stilin e Home Assistant kur sfondi vendas mungon;
* nuk ndryshon gjendjet e entiteteve dhe nuk ndërhyn në funksionimin e pajisjeve.

<a id="installation"></a>
## 📦 Instalimi

### 🛍 Instalimi përmes HACS
ℹ️ [Çfarë është HACS dhe si instalohet?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_sq.md)

#### 1. Shtimi i këtij repozitori në HACS
Mund të duhen muaj që shtojca të futet në katalogun standard të HACS, prandaj fillimisht shtoni repozitorin manualisht:
1. Hapni HACS.
2. Hapni menynë sipër djathtas dhe zgjidhni **Repozitorë të personalizuar**.
3. Shtoni repozitorin:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Zgjidhni llojin **Panel kontrolli** dhe klikoni **Shto**.

> Shtimi i repozitorit te **Repozitorët e personalizuar** vetëm e bën shtojcën të disponueshme në HACS. Vetë shtojca instalohet veçmas me butonin **Shkarko**.

#### 2. Instalimi i shtojcës
1. Kërkoni në HACS: `MDI Off Fallback` dhe hapeni.
2. Klikoni **Shkarko** dhe konfirmoni instalimin.
3. Pas përfundimit të shkarkimit, rifreskoni faqen e Home Assistant duke pastruar cache-in e shfletuesit.

<a id="manual-installation"></a>
### 🧑‍💻 Instalimi manual (pa HACS)

1. Shkarkoni [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Kopjojeni skedarin te `/config/www/ha-mdi-off-fallback.js`.
3. [Shkoni te Burimet](https://my.home-assistant.io/redirect/lovelace_resources/) ose hapini manualisht në Home Assistant: **Cilësimet → Panelet e kontrollit → ⋮ → Burimet** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Klikoni **Shto burim** (**Add resource**).
5. Vendosni `/local/ha-mdi-off-fallback.js` në fushën URL.
6. Zgjidhni **Modul JavaScript** (**JavaScript Module**) dhe klikoni **Krijo** (**Create**).
7. Rifreskoni faqen e Home Assistant duke pastruar cache-in e shfletuesit.

<a id="configuration"></a>
## 🔧 Konfigurimi

Konfigurimi i personalizuar është opsional. Pa skedar personal, shtojca përdor vlerat e integruara:

<a id="default-configuration"></a>
### Konfigurimi i parazgjedhur

Si parazgjedhje, gjendjet e mëposhtme konsiderohen joaktive:

| Domeni i entitetit | Gjendjet joaktive |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Përdoren gjithashtu këto cilësime:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Konfigurimi i personalizuar

Për të përcaktuar rregullat tuaja, krijoni skedarin:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Shembull:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Konfigurimi ruhet veçmas nga skedarët e shtojcës të menaxhuar nga HACS, ndaj përditësimet nuk e mbishkruajnë.

#### Si funksionon seksioni `states`

Nëse konfigurimi i personalizuar përmban një objekt `states`, ai **zëvendëson plotësisht** listën e integruar. Shtojca do të marrë parasysh vetëm domenet dhe gjendjet e listuara shprehimisht.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

Në këtë shembull, vija zbatohet vetëm për `light` dhe `cover`. Rregullat e integruara për `switch`, `fan`, `climate` dhe domenet e tjera nuk përdoren.

Për t'u kthyer te lista e integruar, hiqni `states` nga konfigurimi ose fshini skedarin e konfigurimit.

Cilësimet e tjera janë të pavarura: nëse një cilësim mungon, vazhdon të përdoret vlera e tij e integruar.

<a id="background"></a>
#### Sfondi i ikonës joaktive

Nëse Home Assistant shfaq tashmë sfondin vendas të ikonës joaktive, shtojca nuk e ndryshon.

Kur sfondi mungon, shtojca shton një rreth të zbehtë që përputhet me stilin e ikonave standarde joaktive Pllakë në Home Assistant.

Çaktivizimi:

```json
{
  "faint_background_when_missing": false
}
```

Ndryshimi i tejdukshmërisë:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Konfigurim i përkohshëm nga konsola

`haMdiOffFallback.configure()` përdor të njëjtat rregulla.

Një objekt `states` i dhënë zëvendëson plotësisht listën aktuale:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Nëse `states` mungon, lista aktuale mbetet e pandryshuar:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Cilësimet e aplikuara përmes `configure()` vlejnë vetëm në skedën aktuale deri sa faqja të ringarkohet. Për konfigurim të përhershëm përdorni skedarin JSON.

<a id="reload-config"></a>
#### Ringarkimi i konfigurimit

Pas ndryshimit të skedarit JSON, konfigurimi mund të ringarkohet pa rifreskuar faqen:

```js
haMdiOffFallback.reloadConfig()
```

Shfaqja e konfigurimit aktiv:

```js
haMdiOffFallback.getConfig()
```
