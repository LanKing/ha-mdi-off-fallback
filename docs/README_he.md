# 🚫 MDI Off Fallback עבור Home Assistant

![המחשה של פעולת התוסף](demo.jpg)

התוסף תוכנן כך שהקו שנוסף ייראה כחלק מובנה של Home Assistant:
* עובד עם כרטיסי Tile הרגילים בלי להחליף אותם ושומר על המראה, ההתנהגות, הצבעים, הגדלים והאינטראקציות המקוריים;
* משנה רק סמלים שכבר הוצגו ורק כאשר אין גרסת `-off` מובנית;
* ניתן להוסיף רקע עגול חלש כאשר הרקע המקורי חסר;
* אינו משנה מצבי ישויות ואינו מתערב בפעולת המכשירים.
<a id="installation"></a>
## 📦 התקנה

### 🛍 התקנה באמצעות HACS
ℹ️ [מהו HACS וכיצד מתקינים אותו?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_he.md)

#### 1. הוספת המאגר הזה ל-HACS
ייתכן שיחלפו חודשים עד שהתוסף יתווסף לקטלוג ברירת המחדל של HACS, ולכן תחילה יש להוסיף את המאגר ידנית:
1. פתחו את HACS.
2. פתחו את התפריט בפינה הימנית העליונה ובחרו **מאגרים מותאמים אישית** (**Custom repositories**).
3. הוסיפו את המאגר:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. בחרו **לוח מחוונים** (**Dashboard**) כסוג ולחצו **הוספה** (**Add**).

> הוספת מאגר תחת **מאגרים מותאמים אישית** רק הופכת את התוסף לזמין ב-HACS. את התוסף עצמו מתקינים בנפרד באמצעות הכפתור **הורדה** (**Download**).

#### 2. התקנת התוסף
1. חפשו ב-HACS: `MDI Off Fallback` ופתחו אותו.
2. לחצו **הורדה** (**Download**) ואשרו את ההתקנה.
3. לאחר סיום ההורדה, טענו מחדש את Home Assistant תוך ניקוי מטמון הדפדפן.

<a id="manual-installation"></a>
### 🧑‍💻 התקנה ידנית (ללא HACS)

1. הורידו את [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. העתיקו את הקובץ אל `/config/www/ha-mdi-off-fallback.js`.
3. [עברו אל משאבים](https://my.home-assistant.io/redirect/lovelace_resources/) או פתחו אותם ידנית ב-Home Assistant: **הגדרות → לוחות מחוונים → ⋮ → משאבים** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. לחצו **הוספת משאב** (**Add resource**).
5. הזינו `/local/ha-mdi-off-fallback.js` בשדה URL.
6. בחרו **מודול JavaScript** (**JavaScript Module**) ולחצו **יצירה** (**Create**).
7. טענו מחדש את Home Assistant תוך ניקוי מטמון הדפדפן.

<a id="configuration"></a>
## 🔧 הגדרה

הגדרה מותאמת אישית היא אופציונלית. ללא קובץ מותאם אישית, התוסף משתמש בערכים המובנים שלו:

<a id="default-configuration"></a>
### הגדרת ברירת מחדל

כברירת מחדל, המצבים הבאים נחשבים ללא פעילים:

| תחום הישות | מצבים לא פעילים |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

נעשה שימוש גם בהגדרות הבאות:

```json
{
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### הגדרה מותאמת אישית

כדי להגדיר כללים משלכם, צרו את הקובץ הבא:

```text
/config/www/ha-mdi-off-fallback.config.json
```

דוגמה:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

ההגדרה נשמרת בנפרד מקובצי התוסף שמנוהלים על ידי HACS, ולכן עדכוני התוסף לא ידרסו אותה.

#### כיצד פועל החלק `states`

כאשר ההגדרה המותאמת אישית כוללת אובייקט `states`, הוא **מחליף לחלוטין** את הרשימה המובנית. התוסף יתחשב רק בתחומים ובמצבים שמצוינים במפורש.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

בדוגמה זו, הקו יוחל רק על `light` ועל `cover`. הכללים המובנים עבור `switch`, `fan`, `climate` וכל שאר התחומים לא ישמשו.

כדי לחזור לרשימה המובנית, הסירו את `states` מההגדרה או מחקו את קובץ ההגדרה.

שאר ההגדרות עצמאיות: אם הגדרה לא צוינה, הערך המובנה שלה נשאר בתוקף.

<a id="background"></a>
#### רקע אופציונלי עבור סמלים ללא עיגול

חלק מהסמלים של MDI אינם במרכז. לאחר הוספת קו נטוי, הם יכולים להיראות לא מאוזנים כאשר אין רקע עגול למסגר אותם.

זה הפריע לתחושת הסדר החזותי שלי, אז התוסף כולל הגדרה אופציונלית שמציירת עיגול קלוש מאחורי אייקונים לא פעילים כאשר Home Assistant אינו מספק כזה.

אפשרות זו מושבתת כברירת מחדל מכיוון שלמעגל יש משמעות בממשק Home Assistant: בכרטיס Tile, זה בדרך כלל מציין שלחיצה על הסמל מבצעת פעולה נפרדת מלחיצה על שאר הכרטיס. הוספת עיגול אך ורק לצורך יישור חזותי משנה אפוא את הסמנטיקה החזותית הזו.

אתה עדיין יכול להפעיל את הרקע אם אתה מעדיף את המראה המאוזן יותר:

```json
{
  "faint_background_when_missing": true
}
```

כאשר הוא מופעל, התוסף מוסיף רק את הרקע שבו Home Assistant לא כבר מעבד אחד.

אתה יכול גם להתאים את האטימות שלו:

```json
{
  "faint_background_opacity": 0.2
}
```

בחר את ההתנהגות החשובה יותר עבור לוח המחוונים שלך: שמירה על רמזי האינטראקציה המקוריים של Home Assistant או שמירה על סמלים חתוכים במרכז חזותי.

<a id="runtime-configuration"></a>
#### הגדרה זמנית דרך המסוף

`haMdiOffFallback.configure()` משתמש באותה לוגיקה.

אובייקט `states` שסופק מחליף לחלוטין את הרשימה הנוכחית:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

אם `states` לא סופק, הרשימה הנוכחית אינה משתנה:

```js
haMdiOffFallback.configure({
  debug: true
})
```

הגדרות שמוחלות באמצעות `configure()` נשארות פעילות רק בכרטיסייה הנוכחית עד לטעינה מחדש של הדף. להגדרה קבועה השתמשו בקובץ JSON.

<a id="reload-config"></a>
#### טעינה מחדש של ההגדרה

לאחר עריכת קובץ ה-JSON, ניתן לטעון מחדש את ההגדרה בלי לטעון מחדש את הדף:

```js
haMdiOffFallback.reloadConfig()
```

הצגת ההגדרה הפעילה:

```js
haMdiOffFallback.getConfig()
```
