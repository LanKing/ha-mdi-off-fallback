> Home Assistant lit jo willekeurige MDI-piktogrammen brûke, mar net elk piktogram hat in `-off`-fariant. Dêrtroch kin in apparaat al útskeakele wêze wylst it piktogram noch aktyf liket. Dizze plugin foeget automatysk in diagonale streek yn MDI-styl ta oan ynaktive entiteiten as der gjin ynboud út-piktogram beskikber is.

# 🚫 MDI Off Fallback foar Home Assistant

![Fisualisaasje fan de pluginfunksje](demo.jpg)

De plugin is sa makke dat de tafoege streek as in natuerlik ûnderdiel fan Home Assistant liket:
* wurket mei standert Tile-kaarten sûnder se te ferfangen en behâldt har oarspronklike uterlik, gedrach, kleuren, maten en ynteraksjes;
* feroaret allinnich al werjûne piktogrammen en allinnich as der gjin ynboude `-off`-fariant is;
* foeget in ljochte rûne eftergrûn yn Home Assistant-styl ta as de ynboude eftergrûn ûntbrekt;
* feroaret gjin entiteitssteaten en bemuoit him net mei de wurking fan apparaten.

<a id="installation"></a>
## 📦 Ynstallaasje

### 🛍 Ynstallaasje fia HACS
ℹ️ [Wat is HACS en hoe wurdt it ynstallearre?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_fy.md)

#### 1. Dizze repository oan HACS tafoegje
It kin moannen duorje foardat de plugin offisjeel oan HACS tafoege wurdt, dus foegje de repository earst hânmjittich ta:
1. Iepenje HACS.
2. Iepenje it menu rjochtsboppe en kies **Oanpaste repositories** (**Custom repositories**).
3. Foegje de repository ta:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```

4. Kies it type **Dashboard** en klik op **Tafoegje** (**Add**).

> It tafoegjen oan **Oanpaste repositories** makket de plugin allinnich beskikber yn HACS. De plugin sels wurdt apart ynstallearre mei de knop **Download**.

#### 2. De plugin ynstallearje
1. Sykje yn HACS nei: `MDI Off Fallback` en iepenje it.
2. Klik op **Download** en befêstigje de ynstallaasje.
3. Nei it downloaden, laad Home Assistant opnij mei in lege browsercache.

<a id="manual-installation"></a>
### 🧑‍💻 Hânmjittige ynstallaasje (sûnder HACS)

1. Download [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Kopiearje it bestân nei `/config/www/ha-mdi-off-fallback.js`.
3. [Gean nei Boarnen](https://my.home-assistant.io/redirect/lovelace_resources/) of iepenje se hânmjittich yn Home Assistant: **Ynstellingen → Dashboards → ⋮ → Boarnen** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Klik op **Boarne tafoegje** (**Add resource**).
5. Fier `/local/ha-mdi-off-fallback.js` yn it URL-fjild yn.
6. Kies **JavaScript-module** (**JavaScript Module**) en klik op **Meitsje** (**Create**).
7. Laad Home Assistant opnij mei in lege browsercache.

<a id="configuration"></a>
## 🔧 Konfiguraasje

Oanpaste konfiguraasje is opsjoneel. Sûnder in oanpast bestân brûkt de plugin de ynboude wearden:

<a id="default-configuration"></a>
### Standertkonfiguraasje

Standert wurde de folgjende steaten as ynaktyf beskôge:

| Entiteitsdomein | Ynaktive steaten |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

De folgjende ynstellingen wurde ek brûkt:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Oanpaste konfiguraasje

Meitsje dit bestân om jo eigen regels te definiearjen:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Foarbyld:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

De konfiguraasje wurdt apart opslein fan de pluginbestannen dy't troch HACS beheard wurde, sadat updates har net oerskriuwe.

#### Hoe't de seksje `states` wurket

As de oanpaste konfiguraasje in `states`-objekt befettet, **ferfangt dat de ynboude list folslein**. De plugin hâldt allinnich rekken mei eksplisyt neamde domeinen en steaten.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

Yn dit foarbyld wurdt de streek allinnich tapast op `light` en `cover`. De ynboude regels foar `switch`, `fan`, `climate` en oare domeinen wurde net brûkt.

Om werom te gean nei de ynboude list, ferwiderje `states` út de konfiguraasje of wiskje it konfiguraasjebestân.

De oare ynstellingen binne ûnôfhinklik: as in ynstelling net opjûn wurdt, bliuwt de ynboude wearde jildich.

<a id="background"></a>
#### Eftergrûn fan in ynaktyf piktogram

As Home Assistant de ynboude eftergrûn fan in ynaktyf piktogram al werjout, feroaret de plugin dy net.

As de eftergrûn ûntbrekt, foeget de plugin in ljochte sirkel ta dy't oerienkomt mei de standertstyl fan in ynaktyf Tile-piktogram yn Home Assistant.

Utskeakelje:

```json
{
  "faint_background_when_missing": false
}
```

Trochsichtigens feroarje:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Tydlike konfiguraasje fia de konsole

`haMdiOffFallback.configure()` brûkt deselde logika.

In trochjûn `states`-objekt ferfangt de aktive list folslein:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

As `states` net trochjûn wurdt, feroaret de aktive list net:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Ynstellingen fia `configure()` bliuwe allinnich yn de aktive ljepper jildich oant de side opnij laden wurdt. Brûk it JSON-bestân foar permaninte konfiguraasje.

<a id="reload-config"></a>
#### Konfiguraasje opnij lade

Nei it wizigjen fan it JSON-bestân kin de konfiguraasje opnij laden wurde sûnder de side opnij te laden:

```js
haMdiOffFallback.reloadConfig()
```

Aktive konfiguraasje besjen:

```js
haMdiOffFallback.getConfig()
```
