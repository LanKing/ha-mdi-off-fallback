<a id="user-configuration"></a>


```json
    "water_heater": ["off"],
    "siren": ["off"],
```

D Konfiguration wird separat vo de Plugin-Dateie gspeicheret, wo HACS verwaltet. Updates überschriibed sie drum nöd.

#### So funktioniert dr Abschnitt `states`

Wenn d benutzerdefinierti Konfiguration es `states`-Objekt enthält, **ersetzt es d integrierti Liste vollständig**. S Plugin berücksichtigt nume explizit ufglisteti Domäne und Zuständ.

```json

```

I dem Bispiel wird dr Schrägstrich nume uf `light` und `cover` aagwendet. D integrierte Regle für `switch`, `fan`, `climate` und alli andere Domäne werded nöd bruucht.

Zum zur integrierte Liste zruggkehre, entferne `states` us dr Konfiguration oder lösch d Konfigurationsdatei.

<a id="background"></a>
#### Hintergrund vom inaktive Symbol

Wenn Home Assistant dr native Hintergrund vom inaktive Symbol scho zeichnet, laht s Plugin en unverändert.

Zum abschalte:


