> Home Assistant ļauj izmantot jebkuru MDI ikonu, taču ne katrai ikonai ir `-off` variants. Tāpēc ierīce var būt jau izslēgta, bet tās ikona joprojām izskatās aktīva. Šis spraudnis automātiski pievieno MDI stila diagonālu svītru neaktīvām entītijām, ja nav pieejama iebūvēta izslēgta ikona.

# 🚫 MDI Off Fallback Home Assistant vajadzībām

![Spraudņa darbības vizualizācija](demo.jpg)

Spraudnis ir izstrādāts tā, lai pievienotā svītra izskatītos kā dabiska Home Assistant daļa:
* darbojas ar standarta Tile kartītēm, tās neaizstājot, un saglabā to izskatu, darbību, krāsas, izmērus un mijiedarbību;
* maina tikai jau attēlotās ikonas un tikai tad, ja nav iebūvēta `-off` varianta;
* pievieno blāvu apaļu fonu Home Assistant stilā, ja trūkst standarta fona;
* nemaina entītiju stāvokļus un netraucē ierīču darbību.

<a id="installation"></a>
## 📦 Instalēšana

### 🛍 Instalēšana ar HACS
ℹ️ [Kas ir HACS un kā to instalēt?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_lv.md)

#### 1. Šī repozitorija pievienošana HACS
Var paiet vairāki mēneši, līdz spraudnis tiks pievienots noklusējuma HACS katalogam, tāpēc vispirms pievienojiet repozitoriju manuāli:
1. Atveriet HACS.
2. Atveriet izvēlni augšējā labajā stūrī un izvēlieties **Pielāgotie repozitoriji** (**Custom repositories**).
3. Pievienojiet repozitoriju:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Kā tipu izvēlieties **Informācijas panelis** (**Dashboard**) un nospiediet **Pievienot** (**Add**).

> Repozitorija pievienošana sadaļā **Pielāgotie repozitoriji** tikai padara spraudni pieejamu HACS. Pats spraudnis tiek instalēts atsevišķi ar pogu **Lejupielādēt** (**Download**).

#### 2. Spraudņa instalēšana
1. HACS meklēšanā ievadiet: `MDI Off Fallback` un atveriet to.
2. Nospiediet **Lejupielādēt** (**Download**) un apstipriniet instalēšanu.
3. Kad lejupielāde pabeigta, pārlādējiet Home Assistant, notīrot pārlūka kešatmiņu.

<a id="manual-installation"></a>
### 🧑‍💻 Manuāla instalēšana (bez HACS)

1. Lejupielādējiet [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Kopējiet failu uz `/config/www/ha-mdi-off-fallback.js`.
3. [Atveriet Resursus](https://my.home-assistant.io/redirect/lovelace_resources/) vai pārejiet tur manuāli Home Assistant: **Iestatījumi → Informācijas paneļi → ⋮ → Resursi** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Nospiediet **Pievienot resursu** (**Add resource**).
5. URL laukā ievadiet `/local/ha-mdi-off-fallback.js`.
6. Izvēlieties **JavaScript modulis** (**JavaScript Module**) un nospiediet **Izveidot** (**Create**).
7. Pārlādējiet Home Assistant, notīrot pārlūka kešatmiņu.

<a id="configuration"></a>
## 🔧 Konfigurācija

Pielāgota konfigurācija nav obligāta. Bez pielāgota faila spraudnis izmanto iebūvētās vērtības:

<a id="default-configuration"></a>
### Noklusējuma konfigurācija

Pēc noklusējuma šādi stāvokļi tiek uzskatīti par neaktīviem:

| Entītijas domēns | Neaktīvie stāvokļi |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Tiek izmantoti arī šādi iestatījumi:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Pielāgota konfigurācija

Lai norādītu savus noteikumus, izveidojiet failu:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Piemērs:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Konfigurācija tiek glabāta atsevišķi no HACS pārvaldītajiem spraudņa failiem, tāpēc atjauninājumi to nepārraksta.

#### Kā darbojas sadaļa `states`

Ja pielāgotajā konfigurācijā ir objekts `states`, tas **pilnībā aizstāj** iebūvēto sarakstu. Spraudnis ņems vērā tikai skaidri uzskaitītos domēnus un stāvokļus.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

Šajā piemērā svītra tiks piemērota tikai `light` un `cover`. Iebūvētie noteikumi `switch`, `fan`, `climate` un citiem domēniem netiks izmantoti.

Lai atgrieztos pie iebūvētā saraksta, noņemiet `states` no konfigurācijas vai izdzēsiet konfigurācijas failu.

Pārējie iestatījumi ir neatkarīgi: ja iestatījums nav norādīts, paliek spēkā tā iebūvētā vērtība.

<a id="background"></a>
#### Neaktīvās ikonas fons

Ja Home Assistant jau attēlo standarta neaktīvās ikonas fonu, spraudnis to nemaina.

Ja fona nav, spraudnis pievieno blāvu apli, kas atbilst Home Assistant standarta neaktīvās Tile ikonas stilam.

Atspējot:

```json
{
  "faint_background_when_missing": false
}
```

Mainīt necaurredzamību:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Pagaidu konfigurācija konsolē

`haMdiOffFallback.configure()` izmanto tos pašus noteikumus.

Nodotais `states` objekts pilnībā aizstāj pašreizējo sarakstu:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Ja `states` nav norādīts, pašreizējais saraksts nemainās:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Ar `configure()` norādītie iestatījumi darbojas tikai pašreizējā cilnē līdz lapas pārlādēšanai. Pastāvīgai konfigurācijai izmantojiet JSON failu.

<a id="reload-config"></a>
#### Konfigurācijas pārlādēšana

Pēc JSON faila rediģēšanas konfigurāciju var pārlādēt, nepārlādējot lapu:

```js
haMdiOffFallback.reloadConfig()
```

Skatīt aktīvo konfigurāciju:

```js
haMdiOffFallback.getConfig()
```
