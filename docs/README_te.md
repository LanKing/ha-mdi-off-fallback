# 🚫 Home Assistant కోసం MDI Off Fallback

![ప్లగిన్ పనితీరు చిత్రణ](demo.jpg)

జోడించిన గీత Home Assistant యొక్క స్వదేశీ భాగంలా కనిపించేలా ప్లగిన్ రూపొందించబడింది:
* సాధారణ టైల్ కార్డులను భర్తీ చేయకుండా వాటితో పనిచేసి, వాటి స్వదేశీ రూపం, ప్రవర్తన, రంగులు, పరిమాణాలు మరియు పరస్పర చర్యలను కాపాడుతుంది;
* ఇప్పటికే రెండర్ చేసిన చిహ్నాలను మాత్రమే, స్వదేశీ `-off` రూపం లేనప్పుడు మాత్రమే మారుస్తుంది;
* స్వదేశీ నేపథ్యం లేనప్పుడు Home Assistant శైలిలో మసక వృత్తాకార నేపథ్యాన్ని జోడిస్తుంది;
* ఎంటిటీ స్థితులను మార్చదు మరియు పరికరాల పనితీరులో జోక్యం చేసుకోదు.

<a id="installation"></a>
## 📦 ఇన్‌స్టాలేషన్

### 🛍 HACS ద్వారా ఇన్‌స్టాలేషన్
ℹ️ [HACS అంటే ఏమిటి, దాన్ని ఎలా ఇన్‌స్టాల్ చేయాలి?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_te.md)

#### 1. ఈ రిపోజిటరీని HACS కు జోడించడం
ప్లగిన్ డిఫాల్ట్ HACS కాటలాగ్‌లో చేరడానికి నెలలు పట్టవచ్చు, కాబట్టి ముందుగా రిపోజిటరీని చేతితో జోడించండి:
1. HACS తెరవండి.
2. పై కుడి మూలలోని మెనును తెరిచి **అనుకూల రిపోజిటరీలు** ఎంచుకోండి.
3. రిపోజిటరీని జోడించండి:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. రకంగా **డాష్‌బోర్డ్** ఎంచుకొని **జోడించు** నొక్కండి.

> రిపోజిటరీని **అనుకూల రిపోజిటరీలు** లో జోడించడం ప్లగిన్‌ను HACS లో అందుబాటులోకి మాత్రమే తెస్తుంది. ప్లగిన్‌ను **డౌన్‌లోడ్** బటన్‌తో వేరుగా ఇన్‌స్టాల్ చేయాలి.

#### 2. ప్లగిన్‌ను ఇన్‌స్టాల్ చేయడం
1. HACS లో: `MDI Off Fallback` అని వెతికి దాన్ని తెరవండి.
2. **డౌన్‌లోడ్** నొక్కి ఇన్‌స్టాలేషన్‌ను నిర్ధారించండి.
3. డౌన్‌లోడ్ పూర్తైన తర్వాత బ్రౌజర్ క్యాష్‌ను శుభ్రపరచి Home Assistant పేజీని రీఫ్రెష్ చేయండి.

<a id="manual-installation"></a>
### 🧑‍💻 చేతి ఇన్‌స్టాలేషన్ (HACS లేకుండా)

1. [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js) ఫైల్‌ను డౌన్‌లోడ్ చేయండి.
2. ఫైల్‌ను `/config/www/ha-mdi-off-fallback.js` కు కాపీ చేయండి.
3. [వనరులకు వెళ్లండి](https://my.home-assistant.io/redirect/lovelace_resources/) లేదా Home Assistant లో చేతితో తెరవండి: **సెట్టింగ్‌లు → డాష్‌బోర్డులు → ⋮ → వనరులు** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. **వనరును జోడించు** నొక్కండి (**Add resource**).
5. URL ఫీల్డ్‌లో `/local/ha-mdi-off-fallback.js` నమోదు చేయండి.
6. **JavaScript మాడ్యూల్** ఎంచుకొని (**JavaScript Module**) **సృష్టించు** నొక్కండి (**Create**).
7. బ్రౌజర్ క్యాష్‌ను శుభ్రపరచి Home Assistant పేజీని రీఫ్రెష్ చేయండి.

## 🔧 కాన్ఫిగరేషన్

అనుకూల కాన్ఫిగరేషన్ ఐచ్ఛికం. అనుకూల ఫైల్ లేకపోతే ప్లగిన్ అంతర్నిర్మిత విలువలను ఉపయోగిస్తుంది:

<a id="default-configuration"></a>
### డిఫాల్ట్ కాన్ఫిగరేషన్

డిఫాల్ట్‌గా క్రింది స్థితులు క్రియారహితంగా పరిగణించబడతాయి:

| ఎంటిటీ డొమైన్ | క్రియారహిత స్థితులు |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

క్రింది సెట్టింగ్‌లు కూడా ఉపయోగించబడతాయి:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

```json
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

కాన్ఫిగరేషన్ HACS నిర్వహించే ప్లగిన్ ఫైళ్ల నుండి వేరుగా నిల్వ చేయబడుతుంది, కాబట్టి అప్‌డేట్‌లు దాన్ని ఓవర్‌రైట్ చేయవు.

#### `states` విభాగం ఎలా పనిచేస్తుంది

అనుకూల కాన్ఫిగరేషన్‌లో `states` ఆబ్జెక్ట్ ఉంటే, అది అంతర్నిర్మిత జాబితాను **పూర్తిగా భర్తీ చేస్తుంది**. స్పష్టంగా పేర్కొన్న డొమైన్‌లు మరియు స్థితులనే ప్లగిన్ పరిగణిస్తుంది.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

ఈ ఉదాహరణలో గీత `light` మరియు `cover` కు మాత్రమే వర్తిస్తుంది. `switch`, `fan`, `climate` మరియు ఇతర డొమైన్‌ల అంతర్నిర్మిత నియమాలు ఉపయోగించబడవు.

అంతర్నిర్మిత జాబితాకు తిరిగి వెళ్లడానికి కాన్ఫిగరేషన్ నుండి `states` తొలగించండి లేదా కాన్ఫిగరేషన్ ఫైల్‌ను తొలగించండి.

ఇతర సెట్టింగ్‌లు స్వతంత్రం: ఒక సెట్టింగ్ ఇవ్వకపోతే దాని అంతర్నిర్మిత విలువ కొనసాగుతుంది.

<a id="background"></a>
#### క్రియారహిత చిహ్నం నేపథ్యం

Home Assistant ఇప్పటికే క్రియారహిత చిహ్నం కోసం స్వదేశీ నేపథ్యాన్ని చూపిస్తే ప్లగిన్ దాన్ని మార్చదు.

నేపథ్యం లేకపోతే, Home Assistant లోని సాధారణ క్రియారహిత టైల్ చిహ్నాల శైలికి సరిపోయే మసక వృత్తాన్ని జోడిస్తుంది.

ఆపివేయడం:

```json
{
  "faint_background_when_missing": false
}
```

అపారదర్శకతను మార్చడం:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### కన్సోల్ ద్వారా తాత్కాలిక కాన్ఫిగరేషన్

`haMdiOffFallback.configure()` అదే నియమాలను ఉపయోగిస్తుంది.

ఇచ్చిన `states` ఆబ్జెక్ట్ ప్రస్తుత జాబితాను పూర్తిగా భర్తీ చేస్తుంది:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

`states` ఇవ్వకపోతే ప్రస్తుత జాబితా మారదు:

```js
haMdiOffFallback.configure({
  debug: true
})
```

`configure()` ద్వారా వర్తింపజేసిన సెట్టింగ్‌లు పేజీ మళ్లీ లోడ్ అయ్యే వరకు ప్రస్తుత ట్యాబ్‌లో మాత్రమే చెల్లుతాయి. శాశ్వత కాన్ఫిగరేషన్ కోసం JSON ఫైల్‌ను ఉపయోగించండి.

<a id="reload-config"></a>
#### కాన్ఫిగరేషన్‌ను మళ్లీ లోడ్ చేయడం

JSON ఫైల్‌ను మార్చిన తర్వాత పేజీని రీఫ్రెష్ చేయకుండా కాన్ఫిగరేషన్‌ను మళ్లీ లోడ్ చేయవచ్చు:

```js
haMdiOffFallback.reloadConfig()
```

సక్రియ కాన్ఫిగరేషన్‌ను చూడండి:

```js
haMdiOffFallback.getConfig()
```
