> O Home Assistant permite usar qualquer ícone MDI, mas nem todos têm uma variante `-off`. Assim, um dispositivo pode já estar desligado enquanto o ícone ainda parece ativo. Este plugin adiciona automaticamente um traço no estilo MDI às entidades inativas quando não existe um ícone nativo para o estado desligado.

# 🚫 MDI Off Fallback para Home Assistant

![Visualização do funcionamento do plugin](demo.jpg)

O plugin foi desenvolvido para que o traço adicionado pareça uma parte nativa do Home Assistant:
* funciona com os cartões Bloco padrão sem substituí-los, preservando aparência, comportamento, cores, tamanhos e interações;
* altera apenas ícones já renderizados e somente quando não existe uma variante nativa `-off`;
* adiciona um fundo circular discreto no estilo do Home Assistant quando o fundo nativo está ausente;
* não altera estados das entidades nem interfere no funcionamento dos dispositivos.

<a id="installation"></a>
## 📦 Instalação

### 🛍 Instalação pelo HACS
ℹ️ [O que é o HACS e como instalá-lo?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_pt-BR.md)

#### 1. Adicionar este repositório ao HACS
A inclusão do plugin no catálogo padrão do HACS pode levar meses. Por isso, adicione primeiro este repositório manualmente:
1. Abra o HACS.
2. Abra o menu no canto superior direito e selecione **Repositórios personalizados**.
3. Adicione o repositório:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Selecione o tipo **Painel** e clique em **Adicionar**.

> Adicionar o repositório em **Repositórios personalizados** apenas disponibiliza o plugin no HACS. O plugin é instalado separadamente pelo botão **Baixar**.

#### 2. Instalar o plugin
1. Pesquise no HACS por: `MDI Off Fallback` e abra-o.
2. Clique em **Baixar** e confirme a instalação.
3. Ao finalizar o download, atualize a página do Home Assistant limpando o cache do navegador.

<a id="manual-installation"></a>
### 🧑‍💻 Instalação manual (sem HACS)

1. Baixe [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Copie o arquivo para `/config/www/ha-mdi-off-fallback.js`.
3. [Acesse Recursos](https://my.home-assistant.io/redirect/lovelace_resources/) ou abra-os manualmente no Home Assistant: **Configurações → Painéis → ⋮ → Recursos** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Clique em **Adicionar recurso** (**Add resource**).
5. Insira `/local/ha-mdi-off-fallback.js` no campo URL.
6. Selecione **Módulo JavaScript** (**JavaScript Module**) e clique em **Criar** (**Create**).
7. Atualize a página do Home Assistant limpando o cache do navegador.

<a id="configuration"></a>
## 🔧 Configuração

A configuração personalizada é opcional. Sem um arquivo personalizado, o plugin usa os valores incorporados:

<a id="default-configuration"></a>
### Configuração padrão

Por padrão, os seguintes estados são considerados inativos:

| Domínio da entidade | Estados inativos |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Também são usadas as seguintes configurações:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Configuração personalizada

Para definir suas próprias regras, crie o arquivo:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Exemplo:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

A configuração é armazenada separadamente dos arquivos do plugin gerenciados pelo HACS, portanto as atualizações não a sobrescrevem.

#### Como funciona a seção `states`

Se a configuração personalizada contiver um objeto `states`, ele **substitui completamente** a lista incorporada. O plugin considerará apenas os domínios e estados listados explicitamente.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

Neste exemplo, o traço será aplicado somente a `light` e `cover`. As regras incorporadas para `switch`, `fan`, `climate` e os demais domínios não serão usadas.

Para voltar à lista incorporada, remova `states` da configuração ou exclua o arquivo de configuração.

As demais configurações são independentes: quando uma configuração é omitida, seu valor incorporado permanece em vigor.

<a id="background"></a>
#### Fundo do ícone inativo

Se o Home Assistant já exibir o fundo nativo do ícone inativo, o plugin não o altera.

Se esse fundo estiver ausente, o plugin adiciona um círculo discreto que corresponde ao estilo dos ícones Bloco inativos padrão do Home Assistant.

Desativar:

```json
{
  "faint_background_when_missing": false
}
```

Alterar a opacidade:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Configuração temporária pelo console

`haMdiOffFallback.configure()` usa as mesmas regras.

Um objeto `states` fornecido substitui completamente a lista atual:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Se `states` for omitido, a lista atual permanece inalterada:

```js
haMdiOffFallback.configure({
  debug: true
})
```

As configurações aplicadas por `configure()` permanecem ativas apenas na guia atual até a página ser recarregada. Use o arquivo JSON para configuração permanente.

<a id="reload-config"></a>
#### Recarregar a configuração

Depois de alterar o arquivo JSON, a configuração pode ser recarregada sem atualizar a página:

```js
haMdiOffFallback.reloadConfig()
```

Ver a configuração ativa:

```js
haMdiOffFallback.getConfig()
```
