> Home Assistant에서는 원하는 MDI 아이콘을 사용할 수 있지만, 모든 아이콘에 `-off` 버전이 있는 것은 아닙니다. 그 결과 기기가 이미 꺼져 있어도 아이콘은 계속 활성 상태처럼 보일 수 있습니다. 이 플러그인은 기본 꺼짐 아이콘이 없을 때 비활성 엔티티에 MDI 스타일의 대각선을 자동으로 추가합니다.

# 🚫 Home Assistant용 MDI Off Fallback

![플러그인 동작 예시](demo.jpg)

추가된 대각선이 Home Assistant의 기본 요소처럼 보이도록 설계되었습니다.
* 표준 Tile 카드를 교체하지 않고 동작하며 기본 모양, 동작, 색상, 크기 및 상호작용을 유지합니다.
* 이미 렌더링된 아이콘만 수정하며, 기본 `-off` 버전이 없을 때만 적용합니다.
* 기본 배경이 없으면 Home Assistant 스타일의 흐린 원형 배경을 추가합니다.
* 엔티티 상태를 변경하거나 기기 동작에 간섭하지 않습니다.

<a id="installation"></a>
## 📦 설치

### 🛍 HACS를 통한 설치
ℹ️ [HACS란 무엇이며 어떻게 설치하나요?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_ko.md)

#### 1. 이 저장소를 HACS에 추가
플러그인이 기본 HACS 카탈로그에 추가되기까지 몇 달이 걸릴 수 있으므로 먼저 저장소를 수동으로 추가해야 합니다.
1. HACS를 엽니다.
2. 오른쪽 위 메뉴를 열고 **사용자 지정 저장소** (**Custom repositories**)를 선택합니다.
3. 다음 저장소를 추가합니다.

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. 유형으로 **대시보드** (**Dashboard**)를 선택하고 **추가** (**Add**)를 누릅니다.

> **사용자 지정 저장소**에 저장소를 추가하면 플러그인이 HACS에 표시될 뿐입니다. 플러그인 자체는 **다운로드** (**Download**) 버튼을 사용해 별도로 설치해야 합니다.

#### 2. 플러그인 설치
1. HACS에서 `MDI Off Fallback`을 검색하여 엽니다.
2. **다운로드** (**Download**)를 누르고 설치를 확인합니다.
3. 다운로드가 끝나면 브라우저 캐시를 지우고 Home Assistant를 새로고침합니다.

<a id="manual-installation"></a>
### 🧑‍💻 수동 설치(HACS 미사용)

1. [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js)를 다운로드합니다.
2. 파일을 `/config/www/ha-mdi-off-fallback.js`에 복사합니다.
3. [리소스 열기](https://my.home-assistant.io/redirect/lovelace_resources/)를 사용하거나 Home Assistant에서 수동으로 이동합니다: **설정 → 대시보드 → ⋮ → 리소스** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. **리소스 추가** (**Add resource**)를 누릅니다.
5. URL 필드에 `/local/ha-mdi-off-fallback.js`를 입력합니다.
6. **JavaScript 모듈** (**JavaScript Module**)을 선택하고 **만들기** (**Create**)를 누릅니다.
7. 브라우저 캐시를 지우고 Home Assistant를 새로고침합니다.

<a id="configuration"></a>
## 🔧 구성

사용자 지정 구성은 선택 사항입니다. 별도의 파일이 없으면 플러그인은 내장 값을 사용합니다.

<a id="default-configuration"></a>
### 기본 구성

기본적으로 다음 상태를 비활성 상태로 처리합니다.

| 엔티티 도메인 | 비활성 상태 |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

다음 설정도 사용됩니다.

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### 사용자 지정 구성

직접 규칙을 지정하려면 다음 파일을 만듭니다.

```text
/config/www/ha-mdi-off-fallback.config.json
```

예시:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

구성은 HACS가 관리하는 플러그인 파일과 별도로 저장되므로 플러그인 업데이트로 덮어쓰이지 않습니다.

#### `states` 섹션의 동작

사용자 지정 구성에 `states` 객체가 있으면 내장 목록을 **완전히 대체**합니다. 플러그인은 명시적으로 나열된 도메인과 상태만 고려합니다.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

이 예시에서는 대각선이 `light`와 `cover`에만 적용됩니다. `switch`, `fan`, `climate` 및 기타 도메인의 내장 규칙은 사용되지 않습니다.

내장 목록으로 돌아가려면 구성에서 `states`를 제거하거나 구성 파일을 삭제합니다.

다른 설정은 독립적입니다. 설정을 지정하지 않으면 내장 값이 유지됩니다.

<a id="background"></a>
#### 비활성 아이콘 배경

Home Assistant가 이미 기본 비활성 아이콘 배경을 표시하는 경우 플러그인은 변경하지 않습니다.

배경이 없으면 플러그인이 Home Assistant의 표준 비활성 Tile 아이콘 스타일에 맞는 흐린 원을 추가합니다.

비활성화:

```json
{
  "faint_background_when_missing": false
}
```

불투명도 변경:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### 콘솔에서 임시 구성

`haMdiOffFallback.configure()`도 동일한 규칙을 사용합니다.

전달된 `states` 객체는 현재 목록을 완전히 대체합니다.

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

`states`를 생략하면 현재 목록은 변경되지 않습니다.

```js
haMdiOffFallback.configure({
  debug: true
})
```

`configure()`로 적용한 설정은 페이지를 새로고침할 때까지 현재 탭에서만 유지됩니다. 영구 구성에는 JSON 파일을 사용하세요.

<a id="reload-config"></a>
#### 구성 다시 불러오기

JSON 파일을 편집한 뒤 페이지를 새로고침하지 않고 구성을 다시 불러올 수 있습니다.

```js
haMdiOffFallback.reloadConfig()
```

현재 구성 보기:

```js
haMdiOffFallback.getConfig()
```
