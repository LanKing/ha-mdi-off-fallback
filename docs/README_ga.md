> Ligeann Home Assistant duit deilbhíní MDI ar bith a úsáid, ach níl leagan `-off` ag gach deilbhín. Mar thoradh air sin, d’fhéadfadh gléas a bheith múchta cheana féin agus an deilbhín fós ag breathnú gníomhach. Cuireann an breiseán seo líne trasna i stíl MDI go huathoibríoch le heintitis neamhghníomhacha nuair nach bhfuil deilbhín dúchasach múchta ar fáil.

# 🚫 MDI Off Fallback do Home Assistant

![Feidhm an bhreiseáin léirithe](demo.jpg)

Tá an breiseán deartha ionas go mbeidh an líne bhreise cosúil le cuid dhúchasach de Home Assistant:
* oibríonn sé le gnáthchártaí Tile gan iad a athsholáthar agus coinníonn sé a gcuma, a n-iompar, a ndathanna, a méideanna agus a n-idirghníomhaíochtaí dúchasacha;
* ní athraíonn sé ach deilbhíní atá rindreáilte cheana féin agus sin amháin nuair nach bhfuil leagan dúchasach `-off` ar fáil;
* cuireann sé cúlra ciorclach éadrom i stíl Home Assistant leis nuair atá an cúlra dúchasach ar iarraidh;
* ní athraíonn sé staid na n-eintiteas agus ní chuireann sé isteach ar oibriú na ngléasanna.

<a id="installation"></a>
## 📦 Suiteáil

### 🛍 Suiteáil trí HACS
ℹ️ [Cad é HACS agus conas a shuiteáiltear é?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_ga.md)

#### 1. Cuir an stór seo le HACS
D’fhéadfadh sé míonna a ghlacadh sula gcuirfear an breiseán leis an gcatalóg réamhshocraithe HACS, mar sin cuir an stór seo le HACS de láimh ar dtús:
1. Oscail HACS.
2. Oscail an roghchlár sa chúinne uachtarach ar dheis agus roghnaigh **Stórtha saincheaptha** (**Custom repositories**).
3. Cuir an stór seo leis:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Roghnaigh **Painéal** (**Dashboard**) mar an cineál agus brúigh **Cuir leis** (**Add**).

> Ní dhéanann stór a chur le **Stórtha saincheaptha** ach an breiseán a chur ar fáil in HACS. Suiteáiltear an breiseán féin ar leithligh leis an gcnaipe **Íoslódáil** (**Download**).

#### 2. Suiteáil an breiseán
1. Cuardaigh in HACS: `MDI Off Fallback` agus oscail é.
2. Brúigh **Íoslódáil** (**Download**) agus deimhnigh an tsuiteáil.
3. Nuair a bheidh an íoslódáil críochnaithe, athlódáil Home Assistant agus taisce an bhrabhsálaí á glanadh agat.

<a id="manual-installation"></a>
### 🧑‍💻 Suiteáil de láimh (gan HACS)

1. Íoslódáil [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Cóipeáil an comhad go `/config/www/ha-mdi-off-fallback.js`.
3. [Téigh chuig Acmhainní](https://my.home-assistant.io/redirect/lovelace_resources/) nó oscail iad de láimh in Home Assistant: **Socruithe → Painéil → ⋮ → Acmhainní** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Brúigh **Cuir acmhainn leis** (**Add resource**).
5. Cuir `/local/ha-mdi-off-fallback.js` isteach sa réimse URL.
6. Roghnaigh **Modúl JavaScript** (**JavaScript Module**) agus brúigh **Cruthaigh** (**Create**).
7. Athlódáil Home Assistant agus taisce an bhrabhsálaí á glanadh agat.

<a id="configuration"></a>
## 🔧 Cumraíocht

Tá cumraíocht shaincheaptha roghnach. Gan comhad saincheaptha, úsáideann an breiseán na luachanna ionsuite seo a leanas:

<a id="default-configuration"></a>
### Cumraíocht réamhshocraithe

De réir réamhshocraithe, meastar na staideanna seo a leanas a bheith neamhghníomhach:

| Fearann eintitis | Staideanna neamhghníomhacha |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Úsáidtear na socruithe seo freisin:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Cumraíocht shaincheaptha

Chun do rialacha féin a shainiú, cruthaigh an comhad seo:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Sampla:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Stóráiltear an chumraíocht ar leithligh ó na comhaid bhreiseáin a bhainistíonn HACS, mar sin ní dhéanfaidh nuashonruithe an bhreiseáin í a fhorscríobh.

#### Conas a oibríonn an rannán `states`

Má tá réad `states` sa chumraíocht shaincheaptha, **cuireann sé an liosta ionsuite ina iomláine in ionad**. Ní bhreithneoidh an breiseán ach na fearainn agus na staideanna atá liostaithe go sainráite.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

Sa sampla seo, ní chuirfear an líne trasna ach ar `light` agus `cover`. Ní úsáidfear na rialacha ionsuite do `switch`, `fan`, `climate` ná d’aon fhearann eile.

Chun filleadh ar an liosta ionsuite, bain `states` den chumraíocht nó scrios an comhad cumraíochta féin.

Tá na socruithe eile neamhspleách: mura sonraítear socrú, fanann a luach ionsuite i bhfeidhm.

<a id="background"></a>
#### Cúlra an deilbhín neamhghníomhaigh

Má tharraingíonn Home Assistant an cúlra dúchasach do dheilbhín neamhghníomhach cheana féin, fágann an breiseán gan athrú é.

Má tá an cúlra sin ar iarraidh, cuireann an breiseán ciorcal éadrom leis a mheaitseálann stíl chaighdeánach deilbhín Tile neamhghníomhach Home Assistant.

Chun é a dhíchumasú:

```json
{
  "faint_background_when_missing": false
}
```

Chun an teimhneacht a athrú:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Cumraíocht shealadach ón gconsól

Úsáideann `haMdiOffFallback.configure()` na rialacha céanna.

Cuireann réad `states` a thugtar isteach an liosta reatha ina iomláine in ionad:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Má fhágtar `states` ar lár, fanann an liosta reatha gan athrú:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Ní fhanann socruithe a chuirtear i bhfeidhm trí `configure()` gníomhach ach sa chluaisín reatha go dtí go n-athlódáiltear an leathanach. Úsáid an comhad JSON le haghaidh cumraíocht bhuan.

<a id="reload-config"></a>
#### An chumraíocht a athlódáil

Tar éis duit an comhad JSON a chur in eagar, is féidir an chumraíocht a athlódáil gan an leathanach a athlódáil:

```js
haMdiOffFallback.reloadConfig()
```

Féach ar an gcumraíocht ghníomhach:

```js
haMdiOffFallback.getConfig()
```
