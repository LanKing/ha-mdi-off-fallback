> Home Assistant võimaldab kasutada suvalisi MDI ikoone, kuid kõigil ikoonidel pole `-off` varianti. Seetõttu võib seade olla juba välja lülitatud, samal ajal kui selle ikoon näib endiselt aktiivne. See pistikprogramm lisab mitteaktiivsetele olemitele automaatselt MDI-stiilis kaldkriipsu, kui sisseehitatud väljalülitatud ikoon puudub.

# 🚫 MDI Off Fallback Home Assistantile

![Pistikprogrammi töö visualiseering](demo.jpg)

Pistikprogramm on loodud nii, et lisatud kaldkriips näeks välja Home Assistanti loomuliku osana:
* töötab standardsete Tile-kaartidega neid asendamata ning säilitab nende algse välimuse, käitumise, värvid, suurused ja interaktsioonid;
* muudab ainult juba renderdatud ikoone ja ainult siis, kui sisseehitatud `-off` varianti pole;
* lisab nõrga ümmarguse Home Assistanti stiilis tausta, kui algne taust puudub;
* ei muuda olemite olekuid ega sekku seadmete töösse.

<a id="installation"></a>
## 📦 Paigaldamine

### 🛍 Paigaldamine HACS-i kaudu
ℹ️ [Mis on HACS ja kuidas seda paigaldada?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_et.md)

#### 1. Selle hoidla lisamine HACS-i
Pistikprogrammi ametlik lisamine HACS-i võib võtta kuid, seega tuleb hoidla esmalt käsitsi lisada:
1. Avage HACS.
2. Avage paremas ülanurgas menüü ja valige **Kohandatud hoidlad** (**Custom repositories**).
3. Lisage hoidla:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```

4. Valige tüübiks **Juhtpaneel** (**Dashboard**) ja klõpsake **Lisa** (**Add**).

> Hoidla lisamine jaotisse **Kohandatud hoidlad** teeb pistikprogrammi ainult HACS-is kättesaadavaks. Pistikprogramm ise paigaldatakse eraldi nupuga **Laadi alla** (**Download**).

#### 2. Pistikprogrammi paigaldamine
1. Otsige HACS-is: `MDI Off Fallback` ja avage see.
2. Klõpsake **Laadi alla** (**Download**) ning kinnitage paigaldamine.
3. Pärast allalaadimise lõppu laadige Home Assistant uuesti, tühjendades brauseri vahemälu.

<a id="manual-installation"></a>
### 🧑‍💻 Käsitsi paigaldamine (ilma HACS-ita)

1. Laadige alla [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Kopeerige fail asukohta `/config/www/ha-mdi-off-fallback.js`.
3. [Avage Ressursid](https://my.home-assistant.io/redirect/lovelace_resources/) või avage need Home Assistantis käsitsi: **Seaded → Juhtpaneelid → ⋮ → Ressursid** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Klõpsake **Lisa ressurss** (**Add resource**).
5. Sisestage URL-väljale `/local/ha-mdi-off-fallback.js`.
6. Valige **JavaScripti moodul** (**JavaScript Module**) ja klõpsake **Loo** (**Create**).
7. Laadige Home Assistant uuesti, tühjendades brauseri vahemälu.

<a id="configuration"></a>
## 🔧 Seadistamine

Kohandatud seadistus on valikuline. Kohandatud faili puudumisel kasutab pistikprogramm sisseehitatud väärtusi:

<a id="default-configuration"></a>
### Vaikeseadistus

Vaikimisi loetakse järgmised olekud mitteaktiivseks:

| Olemi domeen | Mitteaktiivsed olekud |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Kasutatakse ka järgmisi seadeid:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Kohandatud seadistus

Oma reeglite määramiseks looge fail:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Näide:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Seadistus salvestatakse HACS-i hallatavatest pistikprogrammi failidest eraldi, seega värskendused seda üle ei kirjuta.

#### Jaotise `states` toimimine

Kui kohandatud seadistus sisaldab objekti `states`, **asendab see sisseehitatud loendi täielikult**. Pistikprogramm arvestab ainult selgesõnaliselt loetletud domeene ja olekuid.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

Selles näites rakendatakse kaldkriipsu ainult domeenidele `light` ja `cover`. Sisseehitatud reegleid domeenidele `switch`, `fan`, `climate` ja teistele ei kasutata.

Sisseehitatud loendi taastamiseks eemaldage seadistusest `states` või kustutage seadistusfail.

Muud seaded on sõltumatud: kui seadet pole määratud, jääb kehtima selle sisseehitatud väärtus.

<a id="background"></a>
#### Mitteaktiivse ikooni taust

Kui Home Assistant kuvab juba mitteaktiivse ikooni algset tausta, ei muuda pistikprogramm seda.

Kui taust puudub, lisab pistikprogramm nõrga ringi, mis vastab Home Assistanti standardse mitteaktiivse Tile-ikooni kujundusele.

Keelamine:

```json
{
  "faint_background_when_missing": false
}
```

Läbipaistvuse muutmine:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Ajutine seadistamine konsooli kaudu

`haMdiOffFallback.configure()` kasutab sama loogikat.

Edastatud objekt `states` asendab praeguse loendi täielikult:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Kui `states` pole edastatud, praegust loendit ei muudeta:

```js
haMdiOffFallback.configure({
  debug: true
})
```

`configure()` kaudu rakendatud seaded kehtivad ainult praegusel vahelehel kuni lehe uuesti laadimiseni. Püsiva seadistuse jaoks kasutage JSON-faili.

<a id="reload-config"></a>
#### Seadistuse uuesti laadimine

Pärast JSON-faili muutmist saab seadistuse uuesti laadida ilma lehte uuesti laadimata:

```js
haMdiOffFallback.reloadConfig()
```

Aktiivse seadistuse vaatamine:

```js
haMdiOffFallback.getConfig()
```
