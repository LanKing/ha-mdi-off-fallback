![პლაგინის მუშაობის ვიზუალიზაცია](demo.jpg)

პლაგინი შექმნილია ისე, რომ დამატებული ხაზი Home Assistant-ის ბუნებრივ ნაწილად გამოიყურებოდეს:
* მუშაობს სტანდარტულ Tile ბარათებთან მათი ჩანაცვლების გარეშე და ინარჩუნებს სტანდარტულ იერსახეს, ქცევას, ფერებს, ზომებსა და ინტერაქციებს;
* ცვლის მხოლოდ უკვე დახატულ ხატულებს და მხოლოდ მაშინ, როცა ჩაშენებული `-off` ვარიანტი არ არსებობს;
* ამატებს Home Assistant-ის სტილის მკრთალ მრგვალ ფონს, თუ სტანდარტული ფონი არ არის;
* არ ცვლის ერთეულების მდგომარეობებს და არ ერევა მოწყობილობების მუშაობაში.

<a id="installation"></a>
## 📦 დაყენება

### 🛍 დაყენება HACS-ის საშუალებით
ℹ️ [რა არის HACS და როგორ დავაყენოთ?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_ka.md)

#### 1. ამ რეპოზიტორიის დამატება HACS-ში
პლაგინის HACS-ის ნაგულისხმევ კატალოგში დამატებას შესაძლოა თვეები დასჭირდეს, ამიტომ ჯერ რეპოზიტორია ხელით დაამატეთ:
1. გახსენით HACS.
2. გახსენით ზედა მარჯვენა კუთხის მენიუ და აირჩიეთ **მორგებული რეპოზიტორიები** (**Custom repositories**).
3. დაამატეთ რეპოზიტორია:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. ტიპად აირჩიეთ **მართვის პანელი** (**Dashboard**) და დააჭირეთ **დამატება** (**Add**).

> რეპოზიტორიის **მორგებულ რეპოზიტორიებში** დამატება მხოლოდ HACS-ში გახდის პლაგინს ხელმისაწვდომს. თავად პლაგინი ცალკე ყენდება ღილაკით **ჩამოტვირთვა** (**Download**).

#### 2. პლაგინის დაყენება
1. HACS-ში მოძებნეთ: `MDI Off Fallback` და გახსენით.
2. დააჭირეთ **ჩამოტვირთვა** (**Download**) და დაადასტურეთ დაყენება.
3. ჩამოტვირთვის დასრულების შემდეგ ხელახლა ჩატვირთეთ Home Assistant და გაასუფთავეთ ბრაუზერის ქეში.

<a id="manual-installation"></a>
### 🧑‍💻 ხელით დაყენება (HACS-ის გარეშე)

1. ჩამოტვირთეთ [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. დააკოპირეთ ფაილი `/config/www/ha-mdi-off-fallback.js` მისამართზე.
3. [გახსენით რესურსები](https://my.home-assistant.io/redirect/lovelace_resources/) ან ხელით გადადით Home Assistant-ში: **პარამეტრები → მართვის პანელები → ⋮ → რესურსები** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. დააჭირეთ **რესურსის დამატება** (**Add resource**).
5. URL ველში მიუთითეთ `/local/ha-mdi-off-fallback.js`.
6. აირჩიეთ **JavaScript მოდული** (**JavaScript Module**) და დააჭირეთ **შექმნა** (**Create**).
7. ხელახლა ჩატვირთეთ Home Assistant და გაასუფთავეთ ბრაუზერის ქეში.

<a id="configuration"></a>
## 🔧 კონფიგურაცია

მორგებული კონფიგურაცია არასავალდებულოა. მორგებული ფაილის გარეშე პლაგინი იყენებს ჩაშენებულ მნიშვნელობებს:

<a id="default-configuration"></a>
### ნაგულისხმევი კონფიგურაცია

ნაგულისხმევად შემდეგი მდგომარეობები არააქტიურად ითვლება:

| ერთეულის დომენი | არააქტიური მდგომარეობები |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

ასევე გამოიყენება შემდეგი პარამეტრები:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### მორგებული კონფიგურაცია

საკუთარი წესების განსაზღვრისთვის შექმენით ფაილი:

```text
/config/www/ha-mdi-off-fallback.config.json
```

მაგალითი:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

კონფიგურაცია ინახება HACS-ის მიერ მართული პლაგინის ფაილებისგან დამოუკიდებლად, ამიტომ განახლებები მას არ გადაწერს.

#### როგორ მუშაობს `states` განყოფილება

თუ მორგებულ კონფიგურაციაში არის `states` ობიექტი, ის **სრულად ანაცვლებს** ჩაშენებულ სიას. პლაგინი გაითვალისწინებს მხოლოდ პირდაპირ ჩამოთვლილ დომენებსა და მდგომარეობებს.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

ამ მაგალითში ხაზი გამოიყენება მხოლოდ `light` და `cover` დომენებზე. `switch`, `fan`, `climate` და სხვა დომენების ჩაშენებული წესები არ გამოიყენება.

ჩაშენებულ სიაზე დასაბრუნებლად ამოიღეთ `states` კონფიგურაციიდან ან წაშალეთ კონფიგურაციის ფაილი.

სხვა პარამეტრები დამოუკიდებელია: თუ პარამეტრი მითითებული არ არის, მისი ჩაშენებული მნიშვნელობა მოქმედებს.

<a id="background"></a>
#### არააქტიური ხატულის ფონი

თუ Home Assistant უკვე აჩვენებს არააქტიური ხატულის სტანდარტულ ფონს, პლაგინი მას არ ცვლის.

თუ ფონი არ არის, პლაგინი ამატებს მკრთალ წრეს, რომელიც Home Assistant-ის სტანდარტულ არააქტიურ Tile ხატულას შეესაბამება.

გამორთვა:

```json
{
  "faint_background_when_missing": false
}
```

გამჭვირვალობის შეცვლა:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### დროებითი კონფიგურაცია კონსოლიდან

`haMdiOffFallback.configure()` იყენებს იმავე წესებს.

გადაცემული `states` ობიექტი სრულად ანაცვლებს მიმდინარე სიას:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

თუ `states` გამოტოვებულია, მიმდინარე სია არ იცვლება:

```js
haMdiOffFallback.configure({
  debug: true
})
```

`configure()`-ით გამოყენებული პარამეტრები მოქმედებს მხოლოდ მიმდინარე ჩანართში გვერდის ხელახლა ჩატვირთვამდე. მუდმივი კონფიგურაციისთვის გამოიყენეთ JSON ფაილი.

<a id="reload-config"></a>
#### კონფიგურაციის ხელახლა ჩატვირთვა

JSON ფაილის შეცვლის შემდეგ კონფიგურაციის ხელახლა ჩატვირთვა გვერდის გადატვირთვის გარეშე შეიძლება:

```js
haMdiOffFallback.reloadConfig()
```

აქტიური კონფიგურაციის ნახვა:

```js
haMdiOffFallback.getConfig()
```
