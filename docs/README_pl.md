> Home Assistant pozwala używać dowolnych ikon MDI, ale nie każda z nich ma wariant `-off`. W rezultacie urządzenie może być już wyłączone, podczas gdy ikona nadal wygląda na aktywną. Ta wtyczka automatycznie dodaje przekreślenie w stylu MDI do nieaktywnych encji, gdy nie istnieje natywna ikona stanu wyłączonego.

# 🚫 MDI Off Fallback dla Home Assistant

![Wizualizacja działania wtyczki](demo.jpg)

Wtyczka została zaprojektowana tak, aby dodane przekreślenie wyglądało jak natywny element Home Assistant:
* działa ze standardowymi kartami Kafelek bez ich zastępowania i zachowuje ich wygląd, zachowanie, kolory, rozmiary oraz interakcje;
* modyfikuje wyłącznie już wyrenderowane ikony i tylko wtedy, gdy brak natywnego wariantu `-off`;
* dodaje delikatne okrągłe tło w stylu Home Assistant, gdy brakuje tła systemowego;
* nie zmienia stanów encji i nie ingeruje w działanie urządzeń.

<a id="installation"></a>
## 📦 Instalacja

### 🛍 Instalacja przez HACS
ℹ️ [Czym jest HACS i jak go zainstalować?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_pl.md)

#### 1. Dodawanie tego repozytorium do HACS
Dodanie wtyczki do domyślnego katalogu HACS może potrwać kilka miesięcy, dlatego najpierw dodaj repozytorium ręcznie:
1. Otwórz HACS.
2. Otwórz menu w prawym górnym rogu i wybierz **Niestandardowe repozytoria**.
3. Dodaj repozytorium:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Wybierz typ **Panel** i kliknij **Dodaj**.

> Dodanie repozytorium do sekcji **Niestandardowe repozytoria** jedynie udostępnia wtyczkę w HACS. Samą wtyczkę instaluje się osobno przyciskiem **Pobierz**.

#### 2. Instalowanie wtyczki
1. Wyszukaj w HACS: `MDI Off Fallback` i otwórz wynik.
2. Kliknij **Pobierz** i potwierdź instalację.
3. Po zakończeniu pobierania odśwież stronę Home Assistant z wyczyszczeniem pamięci podręcznej przeglądarki.

<a id="manual-installation"></a>
### 🧑‍💻 Instalacja ręczna (bez HACS)

1. Pobierz [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Skopiuj plik do `/config/www/ha-mdi-off-fallback.js`.
3. [Przejdź do Zasobów](https://my.home-assistant.io/redirect/lovelace_resources/) lub otwórz je ręcznie w Home Assistant: **Ustawienia → Panele → ⋮ → Zasoby** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Kliknij **Dodaj zasób** (**Add resource**).
5. W polu URL wpisz `/local/ha-mdi-off-fallback.js`.
6. Wybierz typ **Moduł JavaScript** (**JavaScript Module**) i kliknij **Utwórz** (**Create**).
7. Odśwież stronę Home Assistant z wyczyszczeniem pamięci podręcznej przeglądarki.

<a id="configuration"></a>
## 🔧 Konfiguracja

Konfiguracja użytkownika jest opcjonalna. Bez własnego pliku wtyczka używa wartości wbudowanych:

<a id="default-configuration"></a>
### Konfiguracja domyślna

Domyślnie poniższe stany są uznawane za nieaktywne:

| Domena encji | Stany nieaktywne |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Używane są również następujące ustawienia:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Konfiguracja użytkownika

Aby zdefiniować własne reguły, utwórz plik:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Przykład:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Konfiguracja jest przechowywana oddzielnie od plików wtyczki zarządzanych przez HACS, dlatego aktualizacje jej nie nadpisują.

#### Działanie sekcji `states`

Jeśli konfiguracja użytkownika zawiera obiekt `states`, **całkowicie zastępuje on** listę wbudowaną. Wtyczka będzie uwzględniać wyłącznie jawnie wymienione domeny i stany.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

W tym przykładzie przekreślenie zostanie zastosowane tylko do `light` i `cover`. Wbudowane reguły dla `switch`, `fan`, `climate` i pozostałych domen nie będą używane.

Aby wrócić do listy wbudowanej, usuń `states` z konfiguracji albo usuń cały plik konfiguracyjny.

Pozostałe ustawienia są niezależne: jeśli ustawienie nie zostało podane, zachowywana jest jego wartość wbudowana.

<a id="background"></a>
#### Tło nieaktywnej ikony

Jeśli Home Assistant już rysuje natywne tło nieaktywnej ikony, wtyczka pozostawia je bez zmian.

Jeśli takiego tła nie ma, wtyczka dodaje delikatny okrąg zgodny ze stylem standardowej nieaktywnej ikony Kafelek w Home Assistant.

Wyłączanie:

```json
{
  "faint_background_when_missing": false
}
```

Zmiana przezroczystości:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Tymczasowa konfiguracja przez konsolę

`haMdiOffFallback.configure()` korzysta z tych samych zasad.

Przekazany obiekt `states` całkowicie zastępuje bieżącą listę:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Jeśli `states` nie zostanie przekazany, bieżąca lista pozostaje bez zmian:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Ustawienia podane przez `configure()` obowiązują tylko w bieżącej karcie do momentu przeładowania strony. Do trwałej konfiguracji użyj pliku JSON.

<a id="reload-config"></a>
#### Ponowne wczytanie konfiguracji

Po zmianie pliku JSON konfigurację można wczytać ponownie bez przeładowywania strony:

```js
haMdiOffFallback.reloadConfig()
```

Wyświetlanie aktywnej konfiguracji:

```js
haMdiOffFallback.getConfig()
```
