> Home Assistant omogoča uporabo poljubnih ikon MDI, vendar vsaka nima različice `-off`. Naprava je zato lahko že izklopljena, ikona pa je še vedno videti aktivna. Ta vtičnik neaktivnim entitetam samodejno doda prečrtanje v slogu MDI, kadar ni na voljo vgrajena ikona za izklopljeno stanje.

# 🚫 MDI Off Fallback za Home Assistant

![Prikaz delovanja vtičnika](demo.jpg)

Vtičnik je zasnovan tako, da dodano prečrtanje deluje kot izvorni del Home Assistanta:
* deluje s standardnimi karticami Ploščica brez njihove zamenjave ter ohrani videz, vedenje, barve, velikosti in interakcije;
* podpira tudi 🍄 `Mushroom Template Card`; kartica mora imeti nastavljen `entity`, da lahko vtičnik določi njeno stanje;
* spreminja samo že izrisane ikone in samo takrat, ko ni vgrajene različice `-off`;
* lahko po želji doda bledo okroglo ozadje, ko izvorno ozadje manjka;
* ne spreminja stanj entitet in ne posega v delovanje naprav.

## 📦 Namestitev

### 🛍 Namestitev prek HACS
ℹ️ [Kaj je HACS in kako ga namestim?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_sl.md)

🚀 [Poskusite dodati repozitorij s to povezavo](https://my.home-assistant.io/redirect/hacs_repository/?owner=LanKing&repository=ha-mdi-off-fallback&category=plugin). Če vaš HA podpira ta način in deluje, v odprtem oknu kliknite **Add**, nato pa spodaj desno **Download**. Če je vse uspelo, je namestitev končana in preostale korake lahko preskočite. Pojdite neposredno na [Konfiguracija](#configuration).

#### 1. Dodajanje tega repozitorija v HACS
Dodajanje vtičnika v privzeti katalog HACS lahko traja več mesecev, zato najprej ročno dodajte repozitorij:
1. Odprite HACS.
2. Odprite meni zgoraj desno in izberite **Repozitoriji po meri**.
3. Dodajte repozitorij:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Izberite vrsto **Nadzorna plošča** in kliknite **Dodaj**.

> Dodajanje repozitorija med **Repozitorije po meri** samo omogoči vtičnik v HACS. Vtičnik namestite ločeno z gumbom **Prenesi**.

#### 2. Namestitev vtičnika
1. V HACS poiščite: `MDI Off Fallback` in ga odprite.
2. Kliknite **Prenesi** in potrdite namestitev.
3. Po končanem prenosu osvežite stran Home Assistant in počistite predpomnilnik brskalnika.

<a id="manual-installation"></a>
### 🧑‍💻 Ročna namestitev (brez HACS)

1. Prenesite [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Datoteko kopirajte v `/config/www/ha-mdi-off-fallback.js`.
3. [Odprite Vire](https://my.home-assistant.io/redirect/lovelace_resources/) ali jih ročno odprite v Home Assistantu: **Nastavitve → Nadzorne plošče → ⋮ → Viri** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Kliknite **Dodaj vir** (**Add resource**).
5. V polje URL vnesite `/local/ha-mdi-off-fallback.js`.
6. Izberite **Modul JavaScript** (**JavaScript Module**) in kliknite **Ustvari** (**Create**).
7. Osvežite stran Home Assistant in počistite predpomnilnik brskalnika.

## 🔧 Konfiguracija

Konfiguracija po meri ni obvezna. Brez datoteke po meri vtičnik uporabi vgrajene vrednosti:

<a id="default-configuration"></a>
### Privzeta konfiguracija

Privzeto se naslednja stanja štejejo za neaktivna:

| Domena entitete | Neaktivna stanja |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Uporabljajo se tudi naslednje nastavitve:

```json
{
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Konfiguracija po meri

Za lastna pravila ustvarite datoteko:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Primer:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Konfiguracija je shranjena ločeno od datotek vtičnika, ki jih upravlja HACS, zato je posodobitve ne prepišejo.

#### Delovanje razdelka `states`

Če konfiguracija po meri vsebuje predmet `states`, ta **v celoti nadomesti** vgrajeni seznam. Vtičnik upošteva samo izrecno navedene domene in stanja.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

V tem primeru se prečrtanje uporabi samo za `light` in `cover`. Vgrajena pravila za `switch`, `fan`, `climate` in druge domene se ne uporabijo.

Za vrnitev na vgrajeni seznam odstranite `states` iz konfiguracije ali izbrišite konfiguracijsko datoteko.

Druge nastavitve so neodvisne: če nastavitev ni navedena, ostane uporabljena njena vgrajena vrednost.

<a id="background"></a>
#### Izbirno ozadje za ikone brez kroga

Nekatere ikone MDI so vizualno izven sredine. Ko je dodana poševnica, so lahko videti neuravnotežene, če ni okroglega ozadja, ki bi jih uokvirilo.

To je motilo moj občutek vizualnega reda, zato vtičnik vključuje izbirno nastavitev, ki nariše šibek krog za neaktivnimi ikonami, kadar Home Assistant tega ne zagotavlja.

Ta možnost je privzeto onemogočena, ker ima krog pomen v vmesniku Home Assistant: na kartici Tile običajno pomeni, da klik na ikono izvede dejanje, ločeno od klika preostale kartice. Dodajanje kroga zgolj zaradi vizualne poravnave torej spremeni to vizualno semantiko.

Še vedno lahko omogočite ozadje, če imate raje bolj uravnotežen videz:

```json
{
  "faint_background_when_missing": true
}
```

Ko je omogočen, vtičnik samo doda ozadje, kjer ga Home Assistant še ne upodablja.

Prilagodite lahko tudi njegovo motnost:

```json
{
  "faint_background_opacity": 0.2
}
```

Izberite vedenje, ki je pomembnejše za vašo nadzorno ploščo: ohranitev izvirnih interakcijskih namigov Home Assistant ali ohranjanje poševnih ikon vizualno na sredini.

<a id="runtime-configuration"></a>
#### Začasna konfiguracija prek konzole

`haMdiOffFallback.configure()` uporablja enaka pravila.

Podani predmet `states` v celoti nadomesti trenutni seznam:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Če `states` ni podan, trenutni seznam ostane nespremenjen:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Nastavitve prek `configure()` veljajo samo v trenutnem zavihku do ponovnega nalaganja strani. Za trajno konfiguracijo uporabite datoteko JSON.

<a id="reload-config"></a>
#### Ponovno nalaganje konfiguracije

Po spremembi datoteke JSON lahko konfiguracijo znova naložite brez osvežitve strani:

```js
haMdiOffFallback.reloadConfig()
```

Prikaz aktivne konfiguracije:

```js
haMdiOffFallback.getConfig()
```
