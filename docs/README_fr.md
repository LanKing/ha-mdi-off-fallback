> Home Assistant permet d’utiliser n’importe quelle icône MDI, mais toutes ne disposent pas d’une variante `-off`. Un appareil peut donc être éteint alors que son icône semble toujours active. Ce plugin ajoute automatiquement une barre oblique de style MDI aux entités inactives lorsqu’aucune icône d’arrêt native n’est disponible.

# 🚫 MDI Off Fallback pour Home Assistant

![Illustration du fonctionnement du plugin](demo.jpg)

Le plugin est conçu pour que la barre oblique ajoutée ressemble à un élément natif de Home Assistant :
* fonctionne avec les cartes Tile standard sans les remplacer et conserve leur apparence, leur comportement, leurs couleurs, leurs dimensions et leurs interactions d’origine ;
* prend également en charge 🍄 `Mushroom Template Card` ; la carte doit avoir une `entity` configurée afin que le plugin puisse déterminer son état ;
* ne modifie que les icônes déjà rendues, et uniquement lorsqu’aucune variante native `-off` n’est disponible ;
* peut éventuellement ajouter un arrière-plan circulaire pâle lorsque l'arrière-plan natif est manquant ;
* ne modifie pas l’état des entités et n’interfère pas avec le fonctionnement des appareils.

## 📦 Installation

### 🛍 Installation via HACS
ℹ️ [Qu’est-ce que HACS et comment l’installer ?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_fr.md)

🚀 [Essayez d'ajouter le référentiel en utilisant ce lien](https://my.home-assistant.io/redirect/hacs_repository/?owner=LanKing&repository=ha-mdi-off-fallback&category=plugin). Si votre HA prend en charge ce mode et qu'il fonctionne, cliquez sur **Add** dans la fenêtre qui s'ouvre, puis cliquez sur **Download** dans le coin inférieur droit. Si tout fonctionne, l'installation est terminée et vous pouvez ignorer les étapes d'installation restantes. Allez directement à [Configuration](#configuration).

#### 1. Ajouter ce dépôt à HACS
L’ajout officiel du plugin à HACS peut prendre plusieurs mois. Il faut donc commencer par ajouter manuellement le dépôt :
1. Ouvrez HACS.
2. Ouvrez le menu en haut à droite et sélectionnez **Dépôts personnalisés** (**Custom repositories**).
3. Ajoutez le dépôt :

```text
https://github.com/LanKing/ha-mdi-off-fallback
```

4. Sélectionnez le type **Tableau de bord** (**Dashboard**) et cliquez sur **Ajouter** (**Add**).

> L’ajout du dépôt aux **Dépôts personnalisés** rend uniquement le plugin disponible dans HACS. Le plugin lui-même s’installe séparément avec le bouton **Télécharger** (**Download**).

#### 2. Installer le plugin
1. Recherchez dans HACS : `MDI Off Fallback`, puis ouvrez-le.
2. Cliquez sur **Télécharger** (**Download**) et confirmez l’installation.
3. Une fois le téléchargement terminé, rechargez Home Assistant en vidant le cache du navigateur.

<a id="manual-installation"></a>
### 🧑‍💻 Installation manuelle (sans HACS)

1. Téléchargez [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Copiez le fichier dans `/config/www/ha-mdi-off-fallback.js`.
3. [Accédez aux Ressources](https://my.home-assistant.io/redirect/lovelace_resources/) ou ouvrez-les manuellement dans Home Assistant : **Paramètres → Tableaux de bord → ⋮ → Ressources** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Cliquez sur **Ajouter une ressource** (**Add resource**).
5. Saisissez `/local/ha-mdi-off-fallback.js` dans le champ URL.
6. Sélectionnez **Module JavaScript** (**JavaScript Module**) puis cliquez sur **Créer** (**Create**).
7. Rechargez Home Assistant en vidant le cache du navigateur.

## 🔧 Configuration

La configuration personnalisée est facultative. Sans fichier personnalisé, le plugin utilise ses valeurs intégrées :

<a id="default-configuration"></a>
### Configuration par défaut

Par défaut, les états suivants sont considérés comme inactifs :

| Domaine de l’entité | États inactifs |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Les paramètres suivants sont également utilisés :

```json
{
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Configuration personnalisée

Pour définir vos propres règles, créez le fichier suivant :

```text
/config/www/ha-mdi-off-fallback.config.json
```

Exemple :

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

La configuration est stockée séparément des fichiers du plugin gérés par HACS ; les mises à jour du plugin ne l’écrasent donc pas.

#### Fonctionnement de la section `states`

Si la configuration personnalisée contient un objet `states`, celui-ci **remplace entièrement** la liste intégrée. Le plugin ne tiendra compte que des domaines et états explicitement indiqués.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

Dans cet exemple, la barre oblique s’applique uniquement à `light` et `cover`. Les règles intégrées pour `switch`, `fan`, `climate` et les autres domaines ne sont pas utilisées.

Pour revenir à la liste intégrée, supprimez `states` de la configuration ou supprimez le fichier de configuration.

Les autres paramètres sont indépendants : si un paramètre n’est pas indiqué, sa valeur intégrée reste utilisée.

<a id="background"></a>
#### Arrière-plan facultatif pour les icônes sans cercle

Certaines icônes MDI sont visuellement décentrées. Après l’ajout d’une barre oblique, ils peuvent paraître déséquilibrés s’il n’y a pas d’arrière-plan circulaire pour les encadrer.

Cela a gêné mon sens de l'ordre visuel, c'est pourquoi le plugin inclut un paramètre facultatif qui dessine un léger cercle derrière les icônes inactives lorsque Home Assistant n'en fournit pas.

Cette option est désactivée par défaut car le cercle a une signification dans l'interface Home Assistant : sur une carte Tile, il indique normalement que cliquer sur l'icône effectue une action distincte du clic sur le reste de la carte. L'ajout d'un cercle uniquement à des fins d'alignement visuel modifie donc cette sémantique visuelle.

Vous pouvez toujours activer l'arrière-plan si vous préférez une apparence plus équilibrée :

```json
{
  "faint_background_when_missing": true
}
```

Lorsqu'il est activé, le plugin ajoute uniquement l'arrière-plan là où Home Assistant n'en rend pas déjà un.

Vous pouvez également ajuster son opacité :

```json
{
  "faint_background_opacity": 0.2
}
```

Choisissez le comportement qui compte le plus pour votre tableau de bord : préserver les signaux d'interaction natifs de Home Assistant ou garder les icônes barrées visuellement centrées.

<a id="runtime-configuration"></a>
#### Configuration temporaire via la console

`haMdiOffFallback.configure()` utilise la même logique.

Un objet `states` fourni remplace entièrement la liste actuelle :

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Si `states` n’est pas fourni, la liste actuelle reste inchangée :

```js
haMdiOffFallback.configure({
  debug: true
})
```

Les paramètres appliqués avec `configure()` restent actifs uniquement dans l’onglet actuel jusqu’au rechargement de la page. Utilisez le fichier JSON pour une configuration permanente.

<a id="reload-config"></a>
#### Recharger la configuration

Après modification du fichier JSON, la configuration peut être rechargée sans recharger la page :

```js
haMdiOffFallback.reloadConfig()
```

Afficher la configuration active :

```js
haMdiOffFallback.getConfig()
```
