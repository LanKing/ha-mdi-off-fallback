ചേർത്ത വര Home Assistant-ന്റെ സ്വാഭാവിക ഭാഗം പോലെ തോന്നുന്ന വിധത്തിലാണ് പ്ലഗിൻ രൂപകൽപ്പന ചെയ്തിരിക്കുന്നത്:
* സാധാരണ Tile കാർഡുകൾ മാറ്റിസ്ഥാപിക്കാതെ അവയുടെ രൂപം, പെരുമാറ്റം, നിറങ്ങൾ, വലിപ്പം, ഇടപെടലുകൾ എന്നിവ നിലനിർത്തുന്നു;
* ഇതിനകം റെൻഡർ ചെയ്ത ഐക്കണുകൾ മാത്രമേ മാറ്റൂ, അതും അടങ്ങിയ `-off` പതിപ്പ് ഇല്ലാത്തപ്പോൾ മാത്രം;
* സാധാരണ പശ്ചാത്തലം ഇല്ലെങ്കിൽ Home Assistant ശൈലിയിലുള്ള മങ്ങിയ വൃത്താകൃതിയിലുള്ള പശ്ചാത്തലം ചേർക്കുന്നു;
* എന്റിറ്റി നിലകൾ മാറ്റുകയോ ഉപകരണങ്ങളുടെ പ്രവർത്തനത്തിൽ ഇടപെടുകയോ ചെയ്യില്ല.

<a id="installation"></a>
## 📦 ഇൻസ്റ്റാളേഷൻ

### 🛍 HACS വഴി ഇൻസ്റ്റാളേഷൻ
ℹ️ [HACS എന്താണ്, അത് എങ്ങനെ ഇൻസ്റ്റാൾ ചെയ്യാം?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_ml.md)

#### 1. ഈ റിപ്പോസിറ്ററി HACS-ലേക്ക് ചേർക്കുക
പ്ലഗിൻ ഡിഫോൾട്ട് HACS കാറ്റലോഗിൽ ചേർക്കാൻ മാസങ്ങൾ എടുക്കാം, അതിനാൽ ആദ്യം ഈ റിപ്പോസിറ്ററി കൈമാറി ചേർക്കുക:
1. HACS തുറക്കുക.
2. മുകളിൽ വലത് വശത്തെ മെനു തുറന്ന് **ഇഷ്ടാനുസൃത റിപ്പോസിറ്ററികൾ** (**Custom repositories**) തിരഞ്ഞെടുക്കുക.
3. ഈ റിപ്പോസിറ്ററി ചേർക്കുക:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. തരമായി **ഡാഷ്ബോർഡ്** (**Dashboard**) തിരഞ്ഞെടുക്കുകയും **ചേർക്കുക** (**Add**) അമർത്തുകയും ചെയ്യുക.

> **ഇഷ്ടാനുസൃത റിപ്പോസിറ്ററികൾ** വിഭാഗത്തിൽ റിപ്പോസിറ്ററി ചേർക്കുന്നത് പ്ലഗിൻ HACS-ൽ ലഭ്യമാക്കുന്നതേയുള്ളൂ. പ്ലഗിൻ തന്നെ **ഡൗൺലോഡ്** (**Download**) ബട്ടൺ ഉപയോഗിച്ച് വേർതിരിച്ച് ഇൻസ്റ്റാൾ ചെയ്യണം.

#### 2. പ്ലഗിൻ ഇൻസ്റ്റാൾ ചെയ്യുക
1. HACS-ൽ തിരയുക: `MDI Off Fallback`, തുടർന്ന് അത് തുറക്കുക.
2. **ഡൗൺലോഡ്** (**Download**) അമർത്തി ഇൻസ്റ്റാളേഷൻ സ്ഥിരീകരിക്കുക.
3. ഡൗൺലോഡ് പൂർത്തിയായ ശേഷം ബ്രൗസർ കാഷെ മായ്ച്ച് Home Assistant വീണ്ടും ലോഡ് ചെയ്യുക.

<a id="manual-installation"></a>
### 🧑‍💻 മാനുവൽ ഇൻസ്റ്റാളേഷൻ (HACS ഇല്ലാതെ)

1. [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js) ഡൗൺലോഡ് ചെയ്യുക.
2. ഫയൽ `/config/www/ha-mdi-off-fallback.js` എന്നിടത്തേക്ക് പകർത്തുക.
3. [റിസോഴ്സുകൾ തുറക്കുക](https://my.home-assistant.io/redirect/lovelace_resources/) അല്ലെങ്കിൽ Home Assistant-ൽ കൈമാറി തുറക്കുക: **ക്രമീകരണങ്ങൾ → ഡാഷ്ബോർഡുകൾ → ⋮ → റിസോഴ്സുകൾ** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. **റിസോഴ്സ് ചേർക്കുക** (**Add resource**) അമർത്തുക.
5. URL ഫീൽഡിൽ `/local/ha-mdi-off-fallback.js` നൽകുക.
6. **JavaScript മോഡ്യൂൾ** (**JavaScript Module**) തിരഞ്ഞെടുക്കുകയും **സൃഷ്ടിക്കുക** (**Create**) അമർത്തുകയും ചെയ്യുക.
7. ബ്രൗസർ കാഷെ മായ്ച്ച് Home Assistant വീണ്ടും ലോഡ് ചെയ്യുക.

| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

താഴെപ്പറയുന്ന ക്രമീകരണങ്ങളും ഉപയോഗിക്കുന്നു:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### ഇഷ്ടാനുസൃത ക്രമീകരണം

സ്വന്തം നിയമങ്ങൾ നിർവചിക്കാൻ ഈ ഫയൽ സൃഷ്ടിക്കുക:

```text
/config/www/ha-mdi-off-fallback.config.json
```

ഉദാഹരണം:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

ക്രമീകരണം HACS നിയന്ത്രിക്കുന്ന പ്ലഗിൻ ഫയലുകളിൽ നിന്ന് വേർതിരിച്ചാണ് സൂക്ഷിക്കുന്നത്, അതിനാൽ പ്ലഗിൻ അപ്ഡേറ്റുകൾ അത് മായ്ക്കുകയില്ല.

#### `states` വിഭാഗം എങ്ങനെ പ്രവർത്തിക്കുന്നു

ഇഷ്ടാനുസൃത ക്രമീകരണത്തിൽ `states` ഒബ്ജക്റ്റ് ഉണ്ടെങ്കിൽ, അത് അടങ്ങിയ പട്ടികയെ **പൂർണ്ണമായി മാറ്റിസ്ഥാപിക്കും**. വ്യക്തമായി പട്ടികപ്പെടുത്തിയ ഡൊമെയ്‌നുകളും നിലകളും മാത്രമേ പ്ലഗിൻ പരിഗണിക്കൂ.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

ഈ ഉദാഹരണത്തിൽ വര `light`, `cover` എന്നിവയ്ക്കു മാത്രമേ ബാധകമാകൂ. `switch`, `fan`, `climate` തുടങ്ങിയ മറ്റ് ഡൊമെയ്‌നുകളുടെ അടങ്ങിയ നിയമങ്ങൾ ഉപയോഗിക്കില്ല.

അടങ്ങിയ പട്ടികയിലേക്ക് മടങ്ങാൻ ക്രമീകരണത്തിൽ നിന്ന് `states` നീക്കുക അല്ലെങ്കിൽ ക്രമീകരണ ഫയൽ ഇല്ലാതാക്കുക.

മറ്റ് ക്രമീകരണങ്ങൾ സ്വതന്ത്രമാണ്: ഒരു ക്രമീകരണം വ്യക്തമാക്കിയില്ലെങ്കിൽ അതിന്റെ അടങ്ങിയ മൂല്യം തുടരും.

<a id="background"></a>
#### പ്രവർത്തനരഹിത ഐക്കണിന്റെ പശ്ചാത്തലം

Home Assistant ഇതിനകം പ്രവർത്തനരഹിത ഐക്കണിന്റെ സാധാരണ പശ്ചാത്തലം കാണിക്കുന്നുവെങ്കിൽ പ്ലഗിൻ അത് മാറ്റില്ല.

പശ്ചാത്തലം ഇല്ലെങ്കിൽ Home Assistant-ന്റെ സാധാരണ പ്രവർത്തനരഹിത Tile ഐക്കൺ ശൈലിയുമായി പൊരുത്തപ്പെടുന്ന മങ്ങിയ വൃത്തം പ്ലഗിൻ ചേർക്കുന്നു.

അപ്രാപ്തമാക്കാൻ:

```json
{
  "faint_background_when_missing": false
}
```

അസ്പഷ്ടത മാറ്റാൻ:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### കോൺസോളിൽ നിന്ന് താൽക്കാലിക ക്രമീകരണം

`haMdiOffFallback.configure()` ഇതേ നിയമങ്ങളാണ് ഉപയോഗിക്കുന്നത്.

നൽകിയ `states` ഒബ്ജക്റ്റ് നിലവിലെ പട്ടികയെ പൂർണ്ണമായി മാറ്റിസ്ഥാപിക്കുന്നു:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

`states` ഒഴിവാക്കിയാൽ നിലവിലെ പട്ടിക മാറില്ല:

```js
haMdiOffFallback.configure({
  debug: true
})
```

`configure()` വഴി പ്രയോഗിച്ച ക്രമീകരണങ്ങൾ പേജ് വീണ്ടും ലോഡ് ചെയ്യുന്നതുവരെ നിലവിലെ ടാബിൽ മാത്രം സജീവമായിരിക്കും. സ്ഥിര ക്രമീകരണത്തിന് JSON ഫയൽ ഉപയോഗിക്കുക.

<a id="reload-config"></a>
#### ക്രമീകരണം വീണ്ടും ലോഡ് ചെയ്യുക

JSON ഫയൽ തിരുത്തിയ ശേഷം പേജ് വീണ്ടും ലോഡ് ചെയ്യാതെ ക്രമീകരണം വീണ്ടും ലോഡ് ചെയ്യാം:

```js
haMdiOffFallback.reloadConfig()
```

സജീവ ക്രമീകരണം കാണുക:

```js
haMdiOffFallback.getConfig()
```
