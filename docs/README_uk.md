> Home Assistant дає змогу використовувати довільні MDI-іконки, але не для кожної існує варіант `-off`. У результаті пристрій уже вимкнений, а іконка візуально все ще виглядає активною. Цей плагін автоматично додає перекреслення у стилі MDI для неактивних сутностей, коли штатної вимкненої іконки немає.

# 🚫 MDI Off Fallback для Home Assistant

![Візуалізація роботи плагіна](demo.jpg)

Плагін реалізовано так, щоб додане перекреслення виглядало як штатна частина Home Assistant:
* працює зі стандартними картками Tile без їх заміни та зберігає штатний вигляд, поведінку, кольори, розміри й взаємодії;
* змінює лише вже відмальовані іконки й лише за відсутності штатного варіанта `-off`;
* додає блідий круглий фон у стилі Home Assistant, якщо штатного фону немає;
* не змінює стани сутностей і не втручається в роботу пристроїв.

<a id="installation"></a>
## 📦 Встановлення

### 🛍 Встановлення через HACS
ℹ️ [Що таке HACS і як його встановити?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_uk.md)

#### 1. Додавання цього репозиторію до HACS
Поки плагін буде офіційно додано до HACS, можуть минути місяці (чекаємо), тому спочатку потрібно самостійно додати репозиторій до HACS:
1. Відкрийте HACS.
2. Відкрийте меню у правому верхньому куті та виберіть **Custom repositories**.
3. Додайте репозиторій:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Виберіть тип **Dashboard** і натисніть **Add**.

> Додавання репозиторію до **Custom repositories** лише робить плагін доступним у HACS. Сам плагін встановлюється окремо кнопкою **Download**.

#### 2. Встановлення плагіна
1. Знайдіть у пошуку HACS: `MDI Off Fallback` і відкрийте його.
2. Натисніть **Download** і підтвердьте встановлення.
3. Після завершення завантаження оновіть сторінку Home Assistant з очищенням кешу браузера.

<a id="manual-installation"></a>
### 🧑‍💻 Встановлення вручну (без HACS)

1. Завантажте [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Скопіюйте файл до `/config/www/ha-mdi-off-fallback.js`.
3. [Перейдіть до ресурсів](https://my.home-assistant.io/redirect/lovelace_resources/) або відкрийте їх вручну в Home Assistant: **Налаштування → Панелі керування → ⋮ → Ресурси** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Натисніть **Додати ресурс** (**Add resource**).
5. У полі URL вкажіть `/local/ha-mdi-off-fallback.js`.
6. Виберіть тип **Модуль JavaScript** (**JavaScript Module**) і натисніть **Створити** (**Create**).
7. Оновіть сторінку Home Assistant з очищенням кешу браузера.

<a id="configuration"></a>
## 🔧 Налаштування

Користувацька конфігурація необов’язкова. Без користувацького файлу плагін використовує вбудовані значення:

<a id="default-configuration"></a>
### Конфігурація за замовчуванням

За замовчуванням такі стани вважаються вимкненими:

| Домен пристрою | Стани вимкнення |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Також використовуються такі параметри:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Користувацька конфігурація

Щоб задати власні правила, створіть файл:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Приклад:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Конфігурація зберігається окремо від файлів плагіна, якими керує HACS, тому оновлення плагіна її не перезаписують.

#### Особливості секції `states`

Якщо в користувацькій конфігурації є об’єкт `states`, він **повністю замінює** вбудований список. Плагін враховуватиме лише явно вказані домени та стани.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

У цьому прикладі перекреслення застосовуватиметься лише до `light` і `cover`. Вбудовані правила для `switch`, `fan`, `climate` та інших доменів не використовуватимуться.

Щоб повернутися до вбудованого списку, видаліть `states` із конфігурації або видаліть сам файл конфігурації.

Інші параметри незалежні: якщо параметр не вказано, для нього зберігається вбудоване значення.

<a id="background"></a>
#### Фон неактивної іконки

Якщо Home Assistant уже малює штатний фон неактивної іконки, плагін його не змінює.

Якщо такого фону немає, плагін додає бліде коло, що відповідає оформленню стандартної неактивної Tile-іконки Home Assistant — це забезпечує єдине відображення іконок.

Вимкнути:

```json
{
  "faint_background_when_missing": false
}
```

Змінити прозорість:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Тимчасове налаштування через консоль

`haMdiOffFallback.configure()` використовує ту саму логіку.

Переданий `states` повністю замінює поточний список:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Якщо `states` не передано, поточний список не змінюється:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Налаштування, задані через `configure()`, діють лише в поточній вкладці до перезавантаження сторінки. Для постійної конфігурації використовуйте JSON-файл.

<a id="reload-config"></a>
#### Перезавантаження конфігурації

Після зміни JSON-файлу конфігурацію можна перечитати без перезавантаження сторінки:

```js
haMdiOffFallback.reloadConfig()
```

Переглянути активну конфігурацію:

```js
haMdiOffFallback.getConfig()
```
