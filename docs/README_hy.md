![Հավելման աշխատանքի ցուցադրում](demo.jpg)

Հավելումը նախագծված է այնպես, որ ավելացված գիծը Home Assistant-ի բնական մաս թվա․
* աշխատում է ստանդարտ Tile քարտերի հետ՝ առանց դրանք փոխարինելու, և պահպանում է սկզբնական տեսքը, վարքը, գույները, չափերն ու փոխազդեցությունները,
* փոխում է միայն արդեն արտապատկերված պատկերակները և միայն այն դեպքում, երբ ներկառուցված `-off` տարբերակ չկա,
* կարող է ցանկության դեպքում ավելացնել թույլ շրջանաձև ֆոն, երբ բնածին ֆոնը բացակայում է.
* չի փոխում էությունների վիճակները և չի միջամտում սարքերի աշխատանքին։
<a id="installation"></a>
## 📦 Տեղադրում

### 🛍 Տեղադրում HACS-ի միջոցով
ℹ️ [Ի՞նչ է HACS-ը և ինչպե՞ս տեղադրել այն։](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_hy.md)

#### 1. Այս պահոցի ավելացումը HACS-ում
Հավելումը HACS-ի լռելյայն կատալոգում հայտնվելու համար կարող են ամիսներ պահանջվել, ուստի նախ ձեռքով ավելացրեք այս պահոցը․
1. Բացեք HACS-ը։
2. Բացեք վերևի աջ անկյան ընտրացանկը և ընտրեք **Հատուկ պահոցներ** (**Custom repositories**)։
3. Ավելացրեք պահոցը․

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Որպես տեսակ ընտրեք **Վահանակ** (**Dashboard**) և սեղմեք **Ավելացնել** (**Add**)։

> Պահոցը **Հատուկ պահոցներ** բաժնում ավելացնելը միայն հասանելի է դարձնում հավելումը HACS-ում։ Հավելումն ինքնին տեղադրվում է առանձին՝ **Ներբեռնել** (**Download**) կոճակով։

#### 2. Հավելման տեղադրում
1. HACS-ում որոնեք՝ `MDI Off Fallback`, և բացեք այն։
2. Սեղմեք **Ներբեռնել** (**Download**) և հաստատեք տեղադրումը։
3. Ներբեռնումն ավարտվելուց հետո վերաբեռնեք Home Assistant-ը՝ մաքրելով դիտարկիչի քեշը։

<a id="manual-installation"></a>
### 🧑‍💻 Ձեռքով տեղադրում (առանց HACS-ի)

1. Ներբեռնեք [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js) ֆայլը։
2. Պատճենեք այն `/config/www/ha-mdi-off-fallback.js` ուղու վրա։
3. [Բացեք Ռեսուրսները](https://my.home-assistant.io/redirect/lovelace_resources/) կամ անցեք այնտեղ ձեռքով Home Assistant-ում՝ **Կարգավորումներ → Վահանակներ → ⋮ → Ռեսուրսներ** *(**Settings → Dashboards → ⋮ → Resources**)*։
4. Սեղմեք **Ավելացնել ռեսուրս** (**Add resource**)։
5. URL դաշտում նշեք `/local/ha-mdi-off-fallback.js`։
6. Ընտրեք **JavaScript մոդուլ** (**JavaScript Module**) և սեղմեք **Ստեղծել** (**Create**)։
7. Վերաբեռնեք Home Assistant-ը՝ մաքրելով դիտարկիչի քեշը։

<a id="configuration"></a>
## 🔧 Կարգավորում

Հատուկ կարգավորումը պարտադիր չէ։ Առանց հատուկ ֆայլի հավելումն օգտագործում է իր ներկառուցված արժեքները․

<a id="default-configuration"></a>
### Լռելյայն կարգավորում

Լռելյայն հետևյալ վիճակները համարվում են ոչ ակտիվ․

| Էության դոմեն | Ոչ ակտիվ վիճակներ |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Օգտագործվում են նաև հետևյալ պարամետրերը․

```json
{
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Հատուկ կարգավորում

Ձեր կանոնները սահմանելու համար ստեղծեք հետևյալ ֆայլը․

```text
/config/www/ha-mdi-off-fallback.config.json
```

Օրինակ․

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Կարգավորումը պահվում է HACS-ի կողմից կառավարվող հավելման ֆայլերից առանձին, ուստի թարմացումները չեն վերագրի այն։

#### Ինչպես է աշխատում `states` բաժինը

Եթե հատուկ կարգավորումը պարունակում է `states` օբյեկտ, այն **ամբողջությամբ փոխարինում է** ներկառուցված ցուցակը։ Հավելումը հաշվի կառնի միայն բացահայտ նշված դոմեններն ու վիճակները։

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

Այս օրինակում գիծը կկիրառվի միայն `light` և `cover` դոմենների վրա։ `switch`, `fan`, `climate` և մյուս դոմենների ներկառուցված կանոնները չեն օգտագործվի։

Ներկառուցված ցուցակին վերադառնալու համար հեռացրեք `states`-ը կարգավորումից կամ ջնջեք կարգավորման ֆայլը։

Մյուս պարամետրերն անկախ են․ եթե պարամետրը նշված չէ, նրա ներկառուցված արժեքը մնում է ուժի մեջ։

#### կամընտիր ֆոն առանց շրջանակի պատկերակների

MDI որոշ պատկերակներ տեսողականորեն կենտրոնից դուրս են: Շեղի ավելացումից հետո դրանք կարող են անհավասարակշիռ տեսք ունենալ, երբ շրջանաձև ֆոն չկա դրանց շրջանակելու համար:

Սա անհանգստացրեց իմ տեսողական կարգի զգացողությունը, այնպես որ հավելումը ներառում է կամընտիր պարամետր, որը թույլ շրջան է գծում ոչ ակտիվ պատկերակների հետևում, երբ Home Assistant-ը չի տրամադրում:

Այս ընտրանքը լռելյայն անջատված է, քանի որ շրջանակը Home Assistant ինտերֆեյսում ունի նշանակություն. Tile քարտի վրա այն սովորաբար ցույց է տալիս, որ պատկերակը սեղմելը առանձին գործողություն է կատարում քարտի մնացած մասի վրա սեղմելուց: Շրջանակ ավելացնելը զուտ տեսողական հավասարեցման համար, հետևաբար, փոխում է այդ տեսողական իմաստաբանությունը:

Դուք դեռ կարող եք միացնել ֆոնը, եթե նախընտրում եք ավելի հավասարակշռված տեսք.

```json
{
  "faint_background_when_missing": true
}
```

Երբ միացված է, փլագինը ավելացնում է միայն այն ֆոնը, որտեղ Home Assistant-ն արդեն չի արտապատկերում:

Դուք կարող եք նաև հարմարեցնել դրա անթափանցիկությունը.

```json
{
  "faint_background_opacity": 0.2
}
```

Ընտրեք այն վարքագիծը, որն ավելի կարևոր է ձեր վահանակի համար՝ պահպանելով Home Assistant-ի փոխազդեցության բնօրինակ նշանները կամ կտրատված պատկերակները տեսողականորեն կենտրոնում պահելով:

<a id="runtime-configuration"></a>
#### Ժամանակավոր կարգավորում կոնսոլից

`haMdiOffFallback.configure()`-ն օգտագործում է նույն կանոնները։

Փոխանցված `states` օբյեկտն ամբողջությամբ փոխարինում է ընթացիկ ցուցակը․

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Եթե `states`-ը բաց է թողնված, ընթացիկ ցուցակը չի փոխվում․

```js
haMdiOffFallback.configure({
  debug: true
})
```

`configure()`-ի միջոցով կիրառված պարամետրերը գործում են միայն ընթացիկ ներդիրում՝ մինչև էջի վերաբեռնումը։ Մշտական կարգավորման համար օգտագործեք JSON ֆայլը։

<a id="reload-config"></a>
#### Կարգավորման վերաբեռնում

JSON ֆայլը խմբագրելուց հետո կարող եք վերաբեռնել կարգավորումը՝ առանց էջը վերաբեռնելու․

```js
haMdiOffFallback.reloadConfig()
```

Դիտել ակտիվ կարգավորումը․

```js
haMdiOffFallback.getConfig()
```
