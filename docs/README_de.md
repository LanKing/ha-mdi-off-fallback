> Home Assistant ermöglicht die Verwendung beliebiger MDI-Symbole, aber nicht jedes Symbol besitzt eine `-off`-Variante. Dadurch kann ein Gerät bereits ausgeschaltet sein, während sein Symbol weiterhin aktiv aussieht. Dieses Plugin fügt inaktiven Entitäten automatisch einen Schrägstrich im MDI-Stil hinzu, wenn kein natives Aus-Symbol verfügbar ist.

# 🚫 MDI Off Fallback für Home Assistant

![Darstellung der Plugin-Funktion](demo.jpg)

Das Plugin ist so umgesetzt, dass der hinzugefügte Schrägstrich wie ein nativer Bestandteil von Home Assistant wirkt:
* funktioniert mit standardmäßigen Tile-Karten, ohne sie zu ersetzen, und erhält deren ursprüngliches Aussehen, Verhalten, Farben, Größen und Interaktionen;
* verändert nur bereits gerenderte Symbole und nur dann, wenn keine native `-off`-Variante vorhanden ist;
* fügt einen dezenten runden Hintergrund im Home-Assistant-Stil hinzu, wenn der native Hintergrund fehlt;
* verändert keine Entitätszustände und greift nicht in die Funktion der Geräte ein.

<a id="installation"></a>
## 📦 Installation

### 🛍 Installation über HACS
ℹ️ [Was ist HACS und wie wird es installiert?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_de.md)

#### 1. Dieses Repository zu HACS hinzufügen
Bis das Plugin offiziell in HACS aufgenommen wird, können Monate vergehen. Daher muss das Repository zunächst manuell hinzugefügt werden:
1. Öffnen Sie HACS.
2. Öffnen Sie das Menü oben rechts und wählen Sie **Benutzerdefinierte Repositories** (**Custom repositories**).
3. Fügen Sie das Repository hinzu:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```

4. Wählen Sie den Typ **Dashboard** und klicken Sie auf **Hinzufügen** (**Add**).

> Durch das Hinzufügen unter **Benutzerdefinierte Repositories** wird das Plugin lediglich in HACS verfügbar. Das Plugin selbst wird separat über die Schaltfläche **Herunterladen** (**Download**) installiert.

#### 2. Plugin installieren
1. Suchen Sie in HACS nach: `MDI Off Fallback` und öffnen Sie den Eintrag.
2. Klicken Sie auf **Herunterladen** (**Download**) und bestätigen Sie die Installation.
3. Laden Sie Home Assistant nach Abschluss des Downloads mit geleertem Browser-Cache neu.

<a id="manual-installation"></a>
### 🧑‍💻 Manuelle Installation (ohne HACS)

1. Laden Sie [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js) herunter.
2. Kopieren Sie die Datei nach `/config/www/ha-mdi-off-fallback.js`.
3. [Öffnen Sie Ressourcen](https://my.home-assistant.io/redirect/lovelace_resources/) oder navigieren Sie in Home Assistant manuell dorthin: **Einstellungen → Dashboards → ⋮ → Ressourcen** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Klicken Sie auf **Ressource hinzufügen** (**Add resource**).
5. Geben Sie `/local/ha-mdi-off-fallback.js` in das URL-Feld ein.
6. Wählen Sie **JavaScript-Modul** (**JavaScript Module**) und klicken Sie auf **Erstellen** (**Create**).
7. Laden Sie Home Assistant mit geleertem Browser-Cache neu.

<a id="configuration"></a>
## 🔧 Konfiguration

Eine benutzerdefinierte Konfiguration ist optional. Ohne eigene Datei verwendet das Plugin die integrierten Werte:

<a id="default-configuration"></a>
### Standardkonfiguration

Standardmäßig gelten die folgenden Zustände als inaktiv:

| Entitätsdomäne | Inaktive Zustände |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Zusätzlich werden folgende Einstellungen verwendet:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Benutzerdefinierte Konfiguration

Erstellen Sie für eigene Regeln folgende Datei:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Beispiel:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Die Konfiguration wird getrennt von den durch HACS verwalteten Plugin-Dateien gespeichert und daher bei Plugin-Updates nicht überschrieben.

#### Funktionsweise des Abschnitts `states`

Enthält die benutzerdefinierte Konfiguration ein `states`-Objekt, **ersetzt es die integrierte Liste vollständig**. Das Plugin berücksichtigt dann ausschließlich die ausdrücklich aufgeführten Domänen und Zustände.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

In diesem Beispiel wird der Schrägstrich nur auf `light` und `cover` angewendet. Die integrierten Regeln für `switch`, `fan`, `climate` und alle übrigen Domänen werden nicht verwendet.

Entfernen Sie `states` aus der Konfiguration oder löschen Sie die Konfigurationsdatei, um zur integrierten Liste zurückzukehren.

Die übrigen Einstellungen sind unabhängig: Wird eine Einstellung nicht angegeben, bleibt ihr integrierter Wert aktiv.

<a id="background"></a>
#### Hintergrund eines inaktiven Symbols

Wenn Home Assistant bereits den nativen Hintergrund für ein inaktives Symbol darstellt, verändert das Plugin ihn nicht.

Fehlt dieser Hintergrund, fügt das Plugin einen dezenten Kreis hinzu, der dem Standardstil eines inaktiven Tile-Symbols in Home Assistant entspricht.

Deaktivieren:

```json
{
  "faint_background_when_missing": false
}
```

Transparenz ändern:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Temporäre Konfiguration über die Konsole

`haMdiOffFallback.configure()` verwendet dieselbe Logik.

Ein übergebenes `states`-Objekt ersetzt die aktuelle Liste vollständig:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Wird `states` nicht übergeben, bleibt die aktuelle Liste unverändert:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Über `configure()` gesetzte Einstellungen gelten nur im aktuellen Tab bis zum Neuladen der Seite. Verwenden Sie für eine dauerhafte Konfiguration die JSON-Datei.

<a id="reload-config"></a>
#### Konfiguration neu laden

Nach Änderungen an der JSON-Datei kann die Konfiguration ohne Neuladen der Seite erneut eingelesen werden:

```js
haMdiOffFallback.reloadConfig()
```

Aktive Konfiguration anzeigen:

```js
haMdiOffFallback.getConfig()
```
