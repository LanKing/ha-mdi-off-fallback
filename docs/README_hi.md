> Home Assistant किसी भी MDI आइकन का उपयोग करने देता है, लेकिन हर आइकन का `-off` संस्करण उपलब्ध नहीं होता। परिणामस्वरूप, डिवाइस बंद होने के बाद भी उसका आइकन सक्रिय दिखाई दे सकता है। यह प्लगइन निष्क्रिय एंटिटी पर स्वचालित रूप से MDI शैली की तिरछी रेखा जोड़ता है, जब कोई मूल बंद आइकन उपलब्ध नहीं होता।

# 🚫 Home Assistant के लिए MDI Off Fallback

![प्लगइन के कार्य का दृश्य](demo.jpg)

प्लगइन इस प्रकार बनाया गया है कि जोड़ी गई रेखा Home Assistant का मूल हिस्सा लगे:
* मानक Tile कार्ड को बदले बिना उनके मूल रूप, व्यवहार, रंग, आकार और इंटरैक्शन को बनाए रखता है;
* केवल पहले से रेंडर किए गए आइकन बदलता है और वह भी तभी, जब मूल `-off` संस्करण उपलब्ध न हो;
* मूल पृष्ठभूमि न होने पर Home Assistant शैली की हल्की गोल पृष्ठभूमि जोड़ता है;
* एंटिटी की स्थिति नहीं बदलता और डिवाइस के संचालन में हस्तक्षेप नहीं करता।

<a id="installation"></a>
## 📦 इंस्टॉलेशन

### 🛍 HACS के माध्यम से इंस्टॉलेशन
ℹ️ [HACS क्या है और इसे कैसे इंस्टॉल करें?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_hi.md)

#### 1. इस रिपॉज़िटरी को HACS में जोड़ें
प्लगइन को डिफ़ॉल्ट HACS कैटलॉग में शामिल होने में कई महीने लग सकते हैं, इसलिए पहले इस रिपॉज़िटरी को मैन्युअल रूप से जोड़ें:
1. HACS खोलें।
2. ऊपर दाईं ओर का मेनू खोलें और **कस्टम रिपॉज़िटरी** (**Custom repositories**) चुनें।
3. यह रिपॉज़िटरी जोड़ें:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. प्रकार के रूप में **डैशबोर्ड** (**Dashboard**) चुनें और **जोड़ें** (**Add**) दबाएँ।

> **कस्टम रिपॉज़िटरी** में रिपॉज़िटरी जोड़ने से प्लगइन केवल HACS में उपलब्ध होता है। प्लगइन को अलग से **डाउनलोड** (**Download**) बटन से इंस्टॉल किया जाता है।

#### 2. प्लगइन इंस्टॉल करें
1. HACS में खोजें: `MDI Off Fallback` और इसे खोलें।
2. **डाउनलोड** (**Download**) दबाएँ और इंस्टॉलेशन की पुष्टि करें।
3. डाउनलोड पूरा होने के बाद ब्राउज़र कैश साफ़ करते हुए Home Assistant को रीलोड करें।

<a id="manual-installation"></a>
### 🧑‍💻 मैन्युअल इंस्टॉलेशन (HACS के बिना)

1. [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js) डाउनलोड करें।
2. फ़ाइल को `/config/www/ha-mdi-off-fallback.js` में कॉपी करें।
3. [संसाधन पर जाएँ](https://my.home-assistant.io/redirect/lovelace_resources/) या Home Assistant में मैन्युअल रूप से खोलें: **सेटिंग → डैशबोर्ड → ⋮ → संसाधन** *(**Settings → Dashboards → ⋮ → Resources**)*।
4. **संसाधन जोड़ें** (**Add resource**) दबाएँ।
5. URL फ़ील्ड में `/local/ha-mdi-off-fallback.js` दर्ज करें।
6. **JavaScript मॉड्यूल** (**JavaScript Module**) चुनें और **बनाएँ** (**Create**) दबाएँ।
7. ब्राउज़र कैश साफ़ करते हुए Home Assistant को रीलोड करें।

<a id="configuration"></a>
## 🔧 कॉन्फ़िगरेशन

कस्टम कॉन्फ़िगरेशन वैकल्पिक है। कस्टम फ़ाइल न होने पर प्लगइन अपने अंतर्निहित मानों का उपयोग करता है:

<a id="default-configuration"></a>
### डिफ़ॉल्ट कॉन्फ़िगरेशन

डिफ़ॉल्ट रूप से निम्न स्थितियाँ निष्क्रिय मानी जाती हैं:

| एंटिटी डोमेन | निष्क्रिय स्थितियाँ |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

इन सेटिंग्स का भी उपयोग होता है:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### कस्टम कॉन्फ़िगरेशन

अपने नियम निर्धारित करने के लिए यह फ़ाइल बनाएँ:

```text
/config/www/ha-mdi-off-fallback.config.json
```

उदाहरण:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

कॉन्फ़िगरेशन HACS द्वारा प्रबंधित प्लगइन फ़ाइलों से अलग संग्रहीत होता है, इसलिए प्लगइन अपडेट इसे ओवरराइट नहीं करेंगे।

#### `states` सेक्शन कैसे काम करता है

यदि कस्टम कॉन्फ़िगरेशन में `states` ऑब्जेक्ट मौजूद है, तो वह अंतर्निहित सूची को **पूरी तरह बदल देता है**। प्लगइन केवल स्पष्ट रूप से सूचीबद्ध डोमेन और स्थितियों पर विचार करेगा।

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

इस उदाहरण में रेखा केवल `light` और `cover` पर लागू होगी। `switch`, `fan`, `climate` और अन्य डोमेन के अंतर्निहित नियम उपयोग नहीं होंगे।

अंतर्निहित सूची पर लौटने के लिए कॉन्फ़िगरेशन से `states` हटाएँ या कॉन्फ़िगरेशन फ़ाइल मिटा दें।

अन्य सेटिंग स्वतंत्र हैं: कोई सेटिंग न दिए जाने पर उसका अंतर्निहित मान लागू रहता है।

<a id="background"></a>
#### निष्क्रिय आइकन की पृष्ठभूमि

यदि Home Assistant पहले से निष्क्रिय आइकन की मूल पृष्ठभूमि दिखाता है, तो प्लगइन उसे नहीं बदलता।

यदि वह पृष्ठभूमि नहीं है, तो प्लगइन Home Assistant के मानक निष्क्रिय Tile आइकन से मेल खाने वाला हल्का वृत्त जोड़ता है।

अक्षम करने के लिए:

```json
{
  "faint_background_when_missing": false
}
```

अपारदर्शिता बदलने के लिए:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### कंसोल से अस्थायी कॉन्फ़िगरेशन

`haMdiOffFallback.configure()` यही नियम उपयोग करता है।

दिया गया `states` ऑब्जेक्ट वर्तमान सूची को पूरी तरह बदल देता है:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

यदि `states` नहीं दिया गया है, तो वर्तमान सूची नहीं बदलती:

```js
haMdiOffFallback.configure({
  debug: true
})
```

`configure()` के माध्यम से लागू सेटिंग केवल वर्तमान टैब में पृष्ठ रीलोड होने तक सक्रिय रहती हैं। स्थायी कॉन्फ़िगरेशन के लिए JSON फ़ाइल का उपयोग करें।

<a id="reload-config"></a>
#### कॉन्फ़िगरेशन रीलोड करना

JSON फ़ाइल संपादित करने के बाद पृष्ठ रीलोड किए बिना कॉन्फ़िगरेशन रीलोड किया जा सकता है:

```js
haMdiOffFallback.reloadConfig()
```

सक्रिय कॉन्फ़िगरेशन देखें:

```js
haMdiOffFallback.getConfig()
```
