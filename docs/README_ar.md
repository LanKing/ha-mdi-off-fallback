> يتيح لك Home Assistant استخدام أيقونات MDI مخصصة، لكن ليس لكل أيقونة إصدار `-off`. لذلك قد يكون الجهاز متوقفًا بالفعل بينما تبدو الأيقونة نشطة. تضيف هذه الإضافة تلقائيًا خطًا مائلًا بأسلوب MDI إلى الكيانات غير النشطة عندما لا تتوفر أيقونة إيقاف أصلية.

# 🚫 MDI Off Fallback لـ Home Assistant

![عرض توضيحي لوظيفة الإضافة](demo.jpg)

صُممت الإضافة بحيث يبدو الخط المائل المضاف جزءًا أصليًا من Home Assistant:
* تعمل مع بطاقات Tile القياسية من دون استبدالها، وتحافظ على مظهرها وسلوكها وألوانها وأحجامها وتفاعلاتها الأصلية؛
* تعدّل الأيقونات التي تم عرضها فقط، وفقط عند عدم توفر إصدار `-off` أصلي؛
* تضيف خلفية دائرية باهتة بأسلوب Home Assistant عند غياب الخلفية الأصلية؛
* لا تغيّر حالات الكيانات ولا تتدخل في عمل الأجهزة.

<a id="installation"></a>
## 📦 التثبيت

### 🛍 التثبيت عبر HACS
ℹ️ [ما هو HACS وكيف يمكن تثبيته؟](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_ar.md)

#### 1. إضافة هذا المستودع إلى HACS
قد يستغرق إدراج الإضافة رسميًا في HACS عدة أشهر، لذلك يجب أولًا إضافة المستودع يدويًا إلى HACS:
1. افتح HACS.
2. افتح القائمة في الزاوية العلوية اليمنى واختر **المستودعات المخصصة** (**Custom repositories**).
3. أضف المستودع:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```

4. اختر النوع **لوحة المعلومات** (**Dashboard**) واضغط **إضافة** (**Add**).

> إضافة المستودع ضمن **المستودعات المخصصة** تجعل الإضافة متاحة في HACS فقط. يجب تثبيت الإضافة نفسها بشكل منفصل باستخدام زر **تنزيل** (**Download**).

#### 2. تثبيت الإضافة
1. ابحث في HACS عن: `MDI Off Fallback` وافتحها.
2. اضغط **تنزيل** (**Download**) وأكد التثبيت.
3. بعد اكتمال التنزيل، أعد تحميل Home Assistant مع مسح ذاكرة التخزين المؤقت للمتصفح.

<a id="manual-installation"></a>
### 🧑‍💻 التثبيت اليدوي (من دون HACS)

1. نزّل [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. انسخ الملف إلى `/config/www/ha-mdi-off-fallback.js`.
3. [انتقل إلى الموارد](https://my.home-assistant.io/redirect/lovelace_resources/) أو افتحها يدويًا في Home Assistant: **الإعدادات → لوحات المعلومات → ⋮ → الموارد** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. اضغط **إضافة مورد** (**Add resource**).
5. أدخل `/local/ha-mdi-off-fallback.js` في حقل URL.
6. اختر **وحدة JavaScript** (**JavaScript Module**) واضغط **إنشاء** (**Create**).
7. أعد تحميل Home Assistant مع مسح ذاكرة التخزين المؤقت للمتصفح.

<a id="configuration"></a>
## 🔧 الإعداد

الإعداد المخصص اختياري. من دون ملف مخصص، تستخدم الإضافة القيم المضمنة:

<a id="default-configuration"></a>
### الإعداد الافتراضي

تُعد الحالات التالية غير نشطة افتراضيًا:

| نطاق الكيان | الحالات غير النشطة |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

تُستخدم أيضًا الإعدادات التالية:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### إعداد مخصص

لإنشاء قواعدك الخاصة، أنشئ الملف التالي:

```text
/config/www/ha-mdi-off-fallback.config.json
```

مثال:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

يُحفظ الإعداد بشكل منفصل عن ملفات الإضافة التي يديرها HACS، لذلك لن تستبدله تحديثات الإضافة.

#### آلية عمل قسم `states`

إذا احتوى الإعداد المخصص على كائن `states`، فإنه **يستبدل القائمة المضمنة بالكامل**. ستأخذ الإضافة في الاعتبار النطاقات والحالات المذكورة صراحة فقط.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

في هذا المثال، سيُطبّق الخط المائل على `light` و`cover` فقط. لن تُستخدم القواعد المضمنة لـ `switch` و`fan` و`climate` وبقية النطاقات.

للعودة إلى القائمة المضمنة، احذف `states` من الإعداد أو احذف ملف الإعداد نفسه.

الإعدادات الأخرى مستقلة: عند عدم تحديد إعداد ما، تبقى قيمته المضمنة سارية.

<a id="background"></a>
#### خلفية الأيقونة غير النشطة

إذا كان Home Assistant يعرض بالفعل الخلفية الأصلية للأيقونة غير النشطة، فلن تغيّرها الإضافة.

إذا كانت الخلفية غير موجودة، تضيف الإضافة دائرة باهتة تطابق تنسيق أيقونة Tile غير النشطة القياسية في Home Assistant.

لتعطيلها:

```json
{
  "faint_background_when_missing": false
}
```

لتغيير الشفافية:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### إعداد مؤقت عبر وحدة التحكم

تستخدم `haMdiOffFallback.configure()` المنطق نفسه.

يستبدل كائن `states` المُمرر القائمة الحالية بالكامل:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

إذا لم يتم تمرير `states`، فلن تتغير القائمة الحالية:

```js
haMdiOffFallback.configure({
  debug: true
})
```

تبقى الإعدادات المطبقة باستخدام `configure()` فعالة في علامة التبويب الحالية فقط حتى إعادة تحميل الصفحة. استخدم ملف JSON للإعداد الدائم.

<a id="reload-config"></a>
#### إعادة تحميل الإعداد

بعد تعديل ملف JSON، يمكن إعادة تحميل الإعداد من دون إعادة تحميل الصفحة:

```js
haMdiOffFallback.reloadConfig()
```

لعرض الإعداد النشط:

```js
haMdiOffFallback.getConfig()
```
