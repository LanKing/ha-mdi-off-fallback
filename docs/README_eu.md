> Home Assistant-ek edozein MDI ikono erabiltzeko aukera ematen du, baina ikono guztiek ez dute `-off` aldaerarik. Ondorioz, gailua itzalita egon daiteke ikonoak oraindik aktibo dirudien bitartean. Plugin honek MDI estiloko barra diagonala gehitzen die automatikoki entitate inaktiboei jatorrizko itzalitako ikonorik ez dagoenean.

# 🚫 MDI Off Fallback Home Assistant-erako

![Pluginaren funtzioaren bistaratzea](demo.jpg)

Plugina barra diagonala Home Assistant-en jatorrizko zati baten moduan agertzeko diseinatuta dago:
* Tile txartel estandarrekin funtzionatzen du haiek ordezkatu gabe, eta jatorrizko itxura, portaera, koloreak, neurriak eta interakzioak mantentzen ditu;
* dagoeneko errendatutako ikonoak bakarrik aldatzen ditu, eta soilik `-off` aldaera jatorrizkorik ez dagoenean;
* Home Assistant estiloko atzeko plano zirkular lausoa gehitzen du jatorrizko atzeko planoa falta denean;
* ez ditu entitateen egoerak aldatzen eta ez du gailuen funtzionamenduan esku hartzen.

<a id="installation"></a>
## 📦 Instalazioa

### 🛍 HACS bidezko instalazioa
ℹ️ [Zer da HACS eta nola instalatzen da?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_eu.md)

#### 1. Biltegi hau HACS-era gehitzea
Plugina HACS-en ofizialki gehitzeak hilabeteak iraun ditzake, beraz lehenik biltegia eskuz gehitu behar da:
1. Ireki HACS.
2. Ireki goiko eskuineko menua eta hautatu **Biltegi pertsonalizatuak** (**Custom repositories**).
3. Gehitu biltegia:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```

4. Hautatu **Arbela** (**Dashboard**) mota eta sakatu **Gehitu** (**Add**).

> Biltegia **Biltegi pertsonalizatuak** atalean gehitzeak plugina HACS-en eskuragarri jartzen du soilik. Plugina bera aparte instalatzen da **Deskargatu** (**Download**) botoiarekin.

#### 2. Plugina instalatzea
1. Bilatu HACS-en: `MDI Off Fallback` eta ireki.
2. Sakatu **Deskargatu** (**Download**) eta berretsi instalazioa.
3. Deskarga amaitzean, berriz kargatu Home Assistant arakatzailearen cachea garbituta.

<a id="manual-installation"></a>
### 🧑‍💻 Eskuzko instalazioa (HACS gabe)

1. Deskargatu [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Kopiatu fitxategia `/config/www/ha-mdi-off-fallback.js` helbidera.
3. [Joan Baliabideetara](https://my.home-assistant.io/redirect/lovelace_resources/) edo ireki eskuz Home Assistant-en: **Ezarpenak → Arbelak → ⋮ → Baliabideak** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Sakatu **Gehitu baliabidea** (**Add resource**).
5. Sartu `/local/ha-mdi-off-fallback.js` URL eremuan.
6. Hautatu **JavaScript modulua** (**JavaScript Module**) eta sakatu **Sortu** (**Create**).
7. Berriz kargatu Home Assistant arakatzailearen cachea garbituta.

<a id="configuration"></a>
## 🔧 Konfigurazioa

Konfigurazio pertsonalizatua aukerakoa da. Fitxategi pertsonalizaturik gabe, pluginak balio integratuak erabiltzen ditu:

<a id="default-configuration"></a>
### Konfigurazio lehenetsia

Lehenespenez, egoera hauek inaktibotzat hartzen dira:

| Entitatearen domeinua | Egoera inaktiboak |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Ezarpen hauek ere erabiltzen dira:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Konfigurazio pertsonalizatua

Zure arauak definitzeko, sortu fitxategi hau:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Adibidea:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Konfigurazioa HACS-ek kudeatutako plugin-fitxategietatik bereizita gordetzen da, beraz eguneratzeek ez dute gainidatziko.

#### `states` atalaren funtzionamendua

Konfigurazio pertsonalizatuak `states` objektua badu, objektu horrek **zerrenda integratua erabat ordezten du**. Pluginak esplizituki zerrendatutako domeinuak eta egoerak bakarrik hartuko ditu kontuan.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

Adibide honetan, barra diagonala `light` eta `cover` domeinuei bakarrik aplikatuko zaie. `switch`, `fan`, `climate` eta gainerako domeinuetarako arau integratuak ez dira erabiliko.

Zerrenda integratura itzultzeko, kendu `states` konfiguraziotik edo ezabatu konfigurazio-fitxategia.

Gainerako ezarpenak independenteak dira: ezarpen bat zehazten ez bada, haren balio integratua mantentzen da.

<a id="background"></a>
#### Ikono inaktiboaren atzeko planoa

Home Assistant-ek ikono inaktiboaren jatorrizko atzeko planoa dagoeneko marrazten badu, pluginak ez du aldatzen.

Atzeko planoa falta bada, pluginak Home Assistant-eko Tile ikono inaktibo estandarraren estiloarekin bat datorren zirkulu lausoa gehitzen du.

Desgaitzeko:

```json
{
  "faint_background_when_missing": false
}
```

Opakutasuna aldatzeko:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Aldi baterako konfigurazioa kontsolaren bidez

`haMdiOffFallback.configure()` funtzioak logika bera erabiltzen du.

Emandako `states` objektuak uneko zerrenda erabat ordezten du:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

`states` ematen ez bada, uneko zerrenda ez da aldatzen:

```js
haMdiOffFallback.configure({
  debug: true
})
```

`configure()` bidez aplikatutako ezarpenek uneko fitxan bakarrik irauten dute orria berriz kargatu arte. Konfigurazio iraunkorrerako erabili JSON fitxategia.

<a id="reload-config"></a>
#### Konfigurazioa berriz kargatzea

JSON fitxategia aldatu ondoren, konfigurazioa berriz karga daiteke orria berriz kargatu gabe:

```js
haMdiOffFallback.reloadConfig()
```

Konfigurazio aktiboa ikusteko:

```js
haMdiOffFallback.getConfig()
```
