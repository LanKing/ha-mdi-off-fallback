> Home Assistant umožňuje používať ľubovoľné ikony MDI, no nie každá má variant `-off`. Zariadenie tak môže byť vypnuté, zatiaľ čo jeho ikona stále vyzerá aktívne. Tento doplnok automaticky pridá k neaktívnym entitám prečiarknutie v štýle MDI, keď neexistuje natívna ikona vypnutého stavu.

# 🚫 MDI Off Fallback pre Home Assistant

![Ukážka funkcie doplnku](demo.jpg)

Doplnok je navrhnutý tak, aby pridané prečiarknutie pôsobilo ako natívna súčasť Home Assistant:
* funguje so štandardnými kartami Dlaždica bez ich nahradenia a zachováva vzhľad, správanie, farby, rozmery a interakcie;
* podporuje aj `Mushroom Template Card`; karta musí mať nastavené `entity`, aby plugin mohol určiť jej stav;
* mení iba už vykreslené ikony a iba vtedy, keď chýba natívny variant `-off`;
* môže voliteľne pridať slabé kruhové pozadie, keď pôvodné pozadie chýba;
* nemení stavy entít a nezasahuje do fungovania zariadení.
<a id="installation"></a>
## 📦 Inštalácia

### 🛍 Inštalácia cez HACS
ℹ️ [Čo je HACS a ako ho nainštalovať?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_sk.md)

#### 1. Pridanie tohto repozitára do HACS
Zaradenie doplnku do predvoleného katalógu HACS môže trvať niekoľko mesiacov, preto najprv pridajte repozitár ručne:
1. Otvorte HACS.
2. Otvorte ponuku v pravom hornom rohu a vyberte **Vlastné repozitáre**.
3. Pridajte repozitár:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Vyberte typ **Ovládací panel** a kliknite na **Pridať**.

> Pridanie repozitára do **Vlastných repozitárov** iba sprístupní doplnok v HACS. Samotný doplnok sa inštaluje osobitne tlačidlom **Stiahnuť**.

#### 2. Inštalácia doplnku
1. Vyhľadajte v HACS: `MDI Off Fallback` a otvorte ho.
2. Kliknite na **Stiahnuť** a potvrďte inštaláciu.
3. Po dokončení sťahovania obnovte stránku Home Assistant a vymažte vyrovnávaciu pamäť prehliadača.

<a id="manual-installation"></a>
### 🧑‍💻 Ručná inštalácia (bez HACS)

1. Stiahnite [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Skopírujte súbor do `/config/www/ha-mdi-off-fallback.js`.
3. [Prejdite na Zdroje](https://my.home-assistant.io/redirect/lovelace_resources/) alebo ich otvorte ručne v Home Assistant: **Nastavenia → Ovládacie panely → ⋮ → Zdroje** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Kliknite na **Pridať zdroj** (**Add resource**).
5. Do poľa URL zadajte `/local/ha-mdi-off-fallback.js`.
6. Vyberte **Modul JavaScript** (**JavaScript Module**) a kliknite na **Vytvoriť** (**Create**).
7. Obnovte stránku Home Assistant a vymažte vyrovnávaciu pamäť prehliadača.

<a id="configuration"></a>
## 🔧 Konfigurácia

Vlastná konfigurácia je voliteľná. Bez vlastného súboru doplnok používa vstavané hodnoty:

<a id="default-configuration"></a>
### Predvolená konfigurácia

Predvolene sa za neaktívne považujú tieto stavy:

| Doména entity | Neaktívne stavy |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Používajú sa aj tieto nastavenia:

```json
{
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Vlastná konfigurácia

Ak chcete určiť vlastné pravidlá, vytvorte súbor:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Príklad:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Konfigurácia je uložená oddelene od súborov doplnku spravovaných HACS, takže ju aktualizácie neprepíšu.

#### Ako funguje časť `states`

Ak vlastná konfigurácia obsahuje objekt `states`, **úplne nahradí** vstavaný zoznam. Doplnok bude zohľadňovať iba výslovne uvedené domény a stavy.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

V tomto príklade sa prečiarknutie použije iba pre `light` a `cover`. Vstavané pravidlá pre `switch`, `fan`, `climate` a ostatné domény sa nepoužijú.

Ak sa chcete vrátiť k vstavanému zoznamu, odstráňte `states` z konfigurácie alebo odstráňte konfiguračný súbor.

Ostatné nastavenia sú nezávislé: ak nastavenie nie je uvedené, zostane použitá jeho vstavaná hodnota.

<a id="background"></a>
#### Voliteľné pozadie pre ikony bez kruhu

Niektoré ikony MDI sú vizuálne mimo stredu. Po pridaní lomky môžu vyzerať nevyvážene, keď nie je k dispozícii žiadne kruhové pozadie, ktoré by ich orámovalo.

To obťažovalo môj zmysel pre vizuálny poriadok, takže doplnok obsahuje voliteľné nastavenie, ktoré nakreslí slabý kruh za neaktívnymi ikonami, keď ho Home Assistant neposkytuje.

Táto možnosť je predvolene zakázaná, pretože kruh má význam v rozhraní Home Assistant: na karte Tile zvyčajne znamená, že kliknutie na ikonu vykoná inú akciu ako kliknutie na zvyšok karty. Pridanie kruhu výlučne na vizuálne zarovnanie preto mení túto vizuálnu sémantiku.

Ak dávate prednosť vyváženejšiemu vzhľadu, stále môžete povoliť pozadie:

```json
{
  "faint_background_when_missing": true
}
```

Keď je povolený, doplnok pridá pozadie len tam, kde ho Home Assistant ešte nevykresľuje.

Môžete tiež upraviť jeho nepriehľadnosť:

```json
{
  "faint_background_opacity": 0.2
}
```

Vyberte si správanie, ktoré je pre váš prístrojový panel dôležitejšie: zachovanie natívnych interakčných podnetov Home Assistant alebo ponechanie prerezaných ikon vizuálne vycentrovaných.

<a id="runtime-configuration"></a>
#### Dočasná konfigurácia cez konzolu

`haMdiOffFallback.configure()` používa rovnaké pravidlá.

Zadaný objekt `states` úplne nahradí aktuálny zoznam:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Ak `states` nie je zadané, aktuálny zoznam zostane nezmenený:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Nastavenia použité cez `configure()` platia iba v aktuálnej karte do opätovného načítania stránky. Na trvalú konfiguráciu použite súbor JSON.

<a id="reload-config"></a>
#### Opätovné načítanie konfigurácie

Po zmene súboru JSON môžete konfiguráciu načítať znova bez obnovenia stránky:

```js
haMdiOffFallback.reloadConfig()
```

Zobrazenie aktívnej konfigurácie:

```js
haMdiOffFallback.getConfig()
```
