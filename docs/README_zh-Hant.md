> Home Assistant 允許使用任意 MDI 圖示，但並非每個圖示都有 `-off` 變體。因此，裝置可能已經關閉，而圖示看起來仍處於啟用狀態。當沒有原生關閉圖示時，此外掛程式會自動為非啟用實體新增 MDI 風格的斜線。

# 🚫 適用於 Home Assistant 的 MDI Off Fallback

![外掛程式功能示意圖](demo.jpg)

此外掛程式經過設計，使新增的斜線看起來像 Home Assistant 的原生組成部分：
* 適用於標準「方塊」卡片，無需取代卡片，並保留原生外觀、行為、顏色、尺寸與互動；
* 僅修改已經呈現的圖示，而且只在沒有原生 `-off` 變體時修改；
* 當原生背景缺失時，可以選擇加入微弱的圓形背景；
* 不會變更實體狀態，也不會干擾裝置運作。
<a id="installation"></a>
## 📦 安裝

### 🛍 透過 HACS 安裝
ℹ️ [什麼是 HACS？如何安裝？](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_zh-Hant.md)

#### 1. 將此儲存庫新增至 HACS
外掛程式加入 HACS 預設目錄可能需要數個月，因此請先手動新增此儲存庫：
1. 開啟 HACS。
2. 開啟右上角選單，選擇 **自訂儲存庫**。
3. 新增儲存庫：

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. 選擇類型 **儀表板**，然後按一下 **新增**。

> 將儲存庫加入 **自訂儲存庫** 只會讓外掛程式在 HACS 中可用。外掛程式本身需要另外透過 **下載** 按鈕安裝。

#### 2. 安裝外掛程式
1. 在 HACS 中搜尋：`MDI Off Fallback`，然後開啟它。
2. 按一下 **下載** 並確認安裝。
3. 下載完成後，清除瀏覽器快取並重新整理 Home Assistant 頁面。

<a id="manual-installation"></a>
### 🧑‍💻 手動安裝（不使用 HACS）

1. 下載 [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js)。
2. 將檔案複製到 `/config/www/ha-mdi-off-fallback.js`。
3. [前往「資源」](https://my.home-assistant.io/redirect/lovelace_resources/)，或在 Home Assistant 中手動開啟：**設定 → 儀表板 → ⋮ → 資源** *(**Settings → Dashboards → ⋮ → Resources**)*。
4. 按一下 **新增資源** (**Add resource**)。
5. 在 URL 欄位中輸入 `/local/ha-mdi-off-fallback.js`。
6. 選擇 **JavaScript 模組** (**JavaScript Module**)，然後按一下 **建立** (**Create**)。
7. 清除瀏覽器快取並重新整理 Home Assistant 頁面。

<a id="configuration"></a>
## 🔧 設定

自訂設定是選用的。沒有自訂檔案時，外掛程式會使用內建值：

<a id="default-configuration"></a>
### 預設設定

預設情況下，下列狀態會被視為非啟用狀態：

| 實體網域 | 非啟用狀態 |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

同時使用以下設定：

```json
{
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### 自訂設定

若要定義自己的規則，請建立檔案：

```text
/config/www/ha-mdi-off-fallback.config.json
```

範例：

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

設定與 HACS 管理的外掛程式檔案分開儲存，因此外掛程式更新不會覆寫設定。

#### `states` 區段的運作方式

如果自訂設定包含 `states` 物件，它會**完全取代**內建清單。外掛程式只會考慮明確列出的網域與狀態。

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

在此範例中，斜線只會套用至 `light` 與 `cover`。`switch`、`fan`、`climate` 及其他網域的內建規則不會使用。

若要恢復內建清單，請從設定中移除 `states`，或刪除設定檔案。

其他設定彼此獨立：如果省略某項設定，則繼續使用其內建值。

<a id="background"></a>
#### 沒有圓圈的圖示的可選背景

某些 MDI 圖示在視覺上偏離中心。添加斜線後，如果沒有圓形背景來框住它們，它們可能看起來不平衡。

這困擾了我的視覺順序感，因此該插件包含一個可選設置，當 Home Assistant 未提供時，該設置會在非活動圖標後面繪製一個微弱的圓圈。

預設情況下停用此選項，因為圓圈在 Home Assistant 介面中具有含義：在 Tile 卡上，它通常表示單擊該圖示與單擊卡的其餘部分執行單獨的操作。因此，純粹為了視覺對齊而添加圓圈會改變視覺語義。

如果您喜歡更平衡的外觀，您仍然可以啟用背景：

```json
{
  "faint_background_when_missing": true
}
```

啟用後，該外掛程式僅新增 Home Assistant 尚未渲染的背景。

您也可以調整其不透明度：

```json
{
  "faint_background_opacity": 0.2
}
```

選擇對您的儀表板更重要的行為：保留 Home Assistant 的本機互動提示或保持斜線圖示視覺居中。

<a id="runtime-configuration"></a>
#### 透過主控台暫時設定

`haMdiOffFallback.configure()` 使用相同規則。

傳入的 `states` 物件會完全取代目前清單：

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

如果省略 `states`，目前清單保持不變：

```js
haMdiOffFallback.configure({
  debug: true
})
```

透過 `configure()` 套用的設定只會在目前分頁中有效，直到頁面重新載入。永久設定請使用 JSON 檔案。

<a id="reload-config"></a>
#### 重新載入設定

修改 JSON 檔案後，可以在不重新整理頁面的情況下重新載入設定：

```js
haMdiOffFallback.reloadConfig()
```

查看目前設定：

```js
haMdiOffFallback.getConfig()
```
