> Home Assistant omogućava korištenje proizvoljnih MDI ikona, ali nema svaka ikona varijantu `-off`. Zbog toga uređaj može već biti isključen, a ikona i dalje izgledati aktivno. Ovaj dodatak automatski dodaje kosu crtu u MDI stilu neaktivnim entitetima kada ne postoji ugrađena ikona za isključeno stanje.

# 🚫 MDI Off Fallback za Home Assistant

![Prikaz rada dodatka](demo.jpg)

Dodatak je napravljen tako da dodana kosa crta izgleda kao izvorni dio Home Assistanta:
* radi sa standardnim Tile karticama bez njihove zamjene i zadržava izvorni izgled, ponašanje, boje, veličine i interakcije;
* mijenja samo već iscrtane ikone i samo kada nema ugrađene varijante `-off`;
* može po želji dodati blijedu kružnu pozadinu kada nedostaje izvorna pozadina;
* ne mijenja stanja entiteta i ne utiče na rad uređaja.
<a id="installation"></a>
## 📦 Instalacija

### 🛍 Instalacija putem HACS-a
ℹ️ [Šta je HACS i kako ga instalirati?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_bs.md)

#### 1. Dodavanje ovog repozitorija u HACS
Može proći nekoliko mjeseci prije nego što dodatak bude službeno dodan u HACS, zato prvo ručno dodajte repozitorij:
1. Otvorite HACS.
2. Otvorite meni u gornjem desnom uglu i odaberite **Prilagođeni repozitoriji** (**Custom repositories**).
3. Dodajte repozitorij:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```

4. Odaberite tip **Kontrolna ploča** (**Dashboard**) i kliknite **Dodaj** (**Add**).

> Dodavanje repozitorija u **Prilagođene repozitorije** samo čini dodatak dostupnim u HACS-u. Sam dodatak instalira se zasebno dugmetom **Preuzmi** (**Download**).

#### 2. Instalacija dodatka
1. U HACS pretrazi pronađite: `MDI Off Fallback` i otvorite ga.
2. Kliknite **Preuzmi** (**Download**) i potvrdite instalaciju.
3. Nakon preuzimanja ponovo učitajte Home Assistant uz brisanje keša preglednika.

<a id="manual-installation"></a>
### 🧑‍💻 Ručna instalacija (bez HACS-a)

1. Preuzmite [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Kopirajte datoteku u `/config/www/ha-mdi-off-fallback.js`.
3. [Otvorite Resurse](https://my.home-assistant.io/redirect/lovelace_resources/) ili ih ručno otvorite u Home Assistantu: **Postavke → Kontrolne ploče → ⋮ → Resursi** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Kliknite **Dodaj resurs** (**Add resource**).
5. U URL polje unesite `/local/ha-mdi-off-fallback.js`.
6. Odaberite **JavaScript modul** (**JavaScript Module**) i kliknite **Kreiraj** (**Create**).
7. Ponovo učitajte Home Assistant uz brisanje keša preglednika.

<a id="configuration"></a>
## 🔧 Podešavanje

Korisnička konfiguracija nije obavezna. Bez korisničke datoteke dodatak koristi ugrađene vrijednosti:

<a id="default-configuration"></a>
### Zadana konfiguracija

Sljedeća stanja se podrazumijevano smatraju neaktivnim:

| Domena entiteta | Neaktivna stanja |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Koriste se i sljedeće postavke:

```json
{
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Korisnička konfiguracija

Za vlastita pravila napravite datoteku:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Primjer:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Konfiguracija se čuva odvojeno od datoteka dodatka kojima upravlja HACS, pa je ažuriranja dodatka neće prepisati.

#### Posebnosti odjeljka `states`

Ako korisnička konfiguracija sadrži objekt `states`, on **u potpunosti zamjenjuje** ugrađenu listu. Dodatak će uzimati u obzir samo izričito navedene domene i stanja.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

U ovom primjeru kosa crta primjenjuje se samo na `light` i `cover`. Ugrađena pravila za `switch`, `fan`, `climate` i ostale domene neće se koristiti.

Za povratak na ugrađenu listu uklonite `states` iz konfiguracije ili izbrišite konfiguracijsku datoteku.

Ostale postavke su nezavisne: ako postavka nije navedena, ostaje njena ugrađena vrijednost.

<a id="background"></a>
#### Opciona pozadina za ikone bez kruga

Neke MDI ikone su vizuelno udaljene od centra. Nakon što se doda kosa crta, mogu izgledati neuravnoteženo kada nema kružne pozadine koja bi ih uokvirila.

Ovo je smetalo mom osećaju za vizuelni poredak, tako da dodatak uključuje opcionu postavku koja crta slab krug iza neaktivnih ikona kada ga Home Assistant ne pruža.

Ova opcija je podrazumevano onemogućena jer krug ima značenje u interfejsu Home Assistant: na Tile kartici, obično označava da se klikom na ikonu obavlja zasebna radnja od klika na ostatak kartice. Dodavanje kruga isključivo radi vizualnog poravnanja stoga mijenja tu vizualnu semantiku.

Još uvijek možete omogućiti pozadinu ako više volite uravnoteženiji izgled:

```json
{
  "faint_background_when_missing": true
}
```

Kada je omogućen, dodatak dodaje samo pozadinu gdje je Home Assistant već ne renderuje.

Također možete podesiti njegovu neprozirnost:

```json
{
  "faint_background_opacity": 0.2
}
```

Odaberite koje je ponašanje važnije za vašu kontrolnu tablu: očuvanje izvornih znakova interakcije Home Assistant ili zadržavanje isečenih ikona vizualno centriranih.

<a id="runtime-configuration"></a>
#### Privremeno podešavanje putem konzole

`haMdiOffFallback.configure()` koristi istu logiku.

Proslijeđeni objekt `states` potpuno zamjenjuje trenutnu listu:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Ako `states` nije proslijeđen, trenutna lista se ne mijenja:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Postavke primijenjene putem `configure()` važe samo u trenutnoj kartici do ponovnog učitavanja stranice. Za trajnu konfiguraciju koristite JSON datoteku.

<a id="reload-config"></a>
#### Ponovno učitavanje konfiguracije

Nakon izmjene JSON datoteke konfiguracija se može ponovo učitati bez ponovnog učitavanja stranice:

```js
haMdiOffFallback.reloadConfig()
```

Prikaz aktivne konfiguracije:

```js
haMdiOffFallback.getConfig()
```
