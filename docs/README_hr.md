> Home Assistant omogućuje upotrebu bilo koje MDI ikone, ali nema svaka ikona varijantu `-off`. Zbog toga uređaj može već biti isključen, a njegova ikona i dalje izgledati aktivno. Ovaj dodatak automatski dodaje kosu crtu u MDI stilu neaktivnim entitetima kada izvorna ikona isključenog stanja nije dostupna.

# 🚫 MDI Off Fallback za Home Assistant

![Prikaz rada dodatka](demo.jpg)

Dodatak je napravljen tako da dodana crta izgleda kao izvorni dio Home Assistanta:
* radi sa standardnim Tile karticama bez njihove zamjene te zadržava izvorni izgled, ponašanje, boje, veličine i interakcije;
* mijenja samo već prikazane ikone i samo kada nema izvorne varijante `-off`;
* dodaje blijedu kružnu pozadinu u stilu Home Assistanta kada izvorna pozadina nedostaje;
* ne mijenja stanja entiteta i ne ometa rad uređaja.

<a id="installation"></a>
## 📦 Instalacija

### 🛍 Instalacija putem HACS-a
ℹ️ [Što je HACS i kako ga instalirati?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_hr.md)

#### 1. Dodavanje ovog repozitorija u HACS
Može proći nekoliko mjeseci prije nego što dodatak bude dodan u zadani HACS katalog, zato prvo ručno dodajte ovaj repozitorij:
1. Otvorite HACS.
2. Otvorite izbornik u gornjem desnom kutu i odaberite **Prilagođeni repozitoriji** (**Custom repositories**).
3. Dodajte repozitorij:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Kao vrstu odaberite **Nadzorna ploča** (**Dashboard**) i pritisnite **Dodaj** (**Add**).

> Dodavanje repozitorija u **Prilagođene repozitorije** samo čini dodatak dostupnim u HACS-u. Sam dodatak instalira se zasebno gumbom **Preuzmi** (**Download**).

#### 2. Instalacija dodatka
1. U HACS-u potražite: `MDI Off Fallback` i otvorite ga.
2. Pritisnite **Preuzmi** (**Download**) i potvrdite instalaciju.
3. Nakon završetka preuzimanja ponovno učitajte Home Assistant uz čišćenje predmemorije preglednika.

<a id="manual-installation"></a>
### 🧑‍💻 Ručna instalacija (bez HACS-a)

1. Preuzmite [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Kopirajte datoteku u `/config/www/ha-mdi-off-fallback.js`.
3. [Otvorite Resurse](https://my.home-assistant.io/redirect/lovelace_resources/) ili ih otvorite ručno u Home Assistantu: **Postavke → Nadzorne ploče → ⋮ → Resursi** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Pritisnite **Dodaj resurs** (**Add resource**).
5. U polje URL unesite `/local/ha-mdi-off-fallback.js`.
6. Odaberite **JavaScript modul** (**JavaScript Module**) i pritisnite **Izradi** (**Create**).
7. Ponovno učitajte Home Assistant uz čišćenje predmemorije preglednika.

<a id="configuration"></a>
## 🔧 Konfiguracija

Prilagođena konfiguracija nije obavezna. Bez prilagođene datoteke dodatak koristi ugrađene vrijednosti:

<a id="default-configuration"></a>
### Zadana konfiguracija

Prema zadanim postavkama sljedeća se stanja smatraju neaktivnima:

| Domena entiteta | Neaktivna stanja |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Koriste se i sljedeće postavke:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Prilagođena konfiguracija

Za definiranje vlastitih pravila izradite datoteku:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Primjer:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Konfiguracija se čuva odvojeno od datoteka dodatka kojima upravlja HACS, pa je ažuriranja dodatka neće prepisati.

#### Kako radi odjeljak `states`

Ako prilagođena konfiguracija sadrži objekt `states`, on **u potpunosti zamjenjuje** ugrađeni popis. Dodatak će uzeti u obzir samo izričito navedene domene i stanja.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

U ovom primjeru crta se primjenjuje samo na `light` i `cover`. Ugrađena pravila za `switch`, `fan`, `climate` i ostale domene neće se koristiti.

Za povratak na ugrađeni popis uklonite `states` iz konfiguracije ili izbrišite konfiguracijsku datoteku.

Ostale su postavke neovisne: ako postavka nije navedena, zadržava se njezina ugrađena vrijednost.

<a id="background"></a>
#### Pozadina neaktivne ikone

Ako Home Assistant već prikazuje izvornu pozadinu neaktivne ikone, dodatak je ne mijenja.

Ako pozadina nedostaje, dodatak dodaje blijedi krug koji odgovara standardnom stilu neaktivne Tile ikone u Home Assistantu.

Isključivanje:

```json
{
  "faint_background_when_missing": false
}
```

Promjena neprozirnosti:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Privremena konfiguracija putem konzole

`haMdiOffFallback.configure()` koristi ista pravila.

Proslijeđeni objekt `states` u potpunosti zamjenjuje trenutačni popis:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Ako `states` nije proslijeđen, trenutačni se popis ne mijenja:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Postavke primijenjene putem `configure()` vrijede samo u trenutačnoj kartici do ponovnog učitavanja stranice. Za trajnu konfiguraciju upotrijebite JSON datoteku.

<a id="reload-config"></a>
#### Ponovno učitavanje konfiguracije

Nakon uređivanja JSON datoteke konfiguraciju možete ponovno učitati bez ponovnog učitavanja stranice:

```js
haMdiOffFallback.reloadConfig()
```

Prikaz aktivne konfiguracije:

```js
haMdiOffFallback.getConfig()
```
