> Home Assistant 允许使用任意 MDI 图标，但并非每个图标都有 `-off` 变体。因此，设备可能已经关闭，而图标看起来仍然处于活动状态。当没有原生关闭图标时，此插件会自动为非活动实体添加 MDI 风格的斜线。

# 🚫 适用于 Home Assistant 的 MDI Off Fallback

![插件功能示意图](demo.jpg)

插件经过设计，使添加的斜线看起来像 Home Assistant 的原生组成部分：
* 适用于标准“磁贴”卡片，无需替换卡片，并保留原生外观、行为、颜色、尺寸和交互；
* 仅修改已经渲染的图标，并且只在没有原生 `-off` 变体时进行修改；
* 当原生背景缺失时，添加 Home Assistant 风格的淡色圆形背景；
* 不更改实体状态，也不干扰设备运行。

<a id="installation"></a>
## 📦 安装

### 🛍 通过 HACS 安装
ℹ️ [什么是 HACS，如何安装？](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_zh-Hans.md)

#### 1. 将此仓库添加到 HACS
插件加入 HACS 默认目录可能需要数月时间，因此请先手动添加此仓库：
1. 打开 HACS。
2. 打开右上角菜单并选择 **自定义存储库**。
3. 添加仓库：

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. 选择类型 **仪表盘**，然后点击 **添加**。

> 将仓库添加到 **自定义存储库** 只会让插件在 HACS 中可用。插件本身需要通过 **下载** 按钮单独安装。

#### 2. 安装插件
1. 在 HACS 中搜索：`MDI Off Fallback`，然后打开它。
2. 点击 **下载** 并确认安装。
3. 下载完成后，清除浏览器缓存并刷新 Home Assistant 页面。

<a id="manual-installation"></a>
### 🧑‍💻 手动安装（不使用 HACS）

1. 下载 [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js)。
2. 将文件复制到 `/config/www/ha-mdi-off-fallback.js`。
3. [前往“资源”](https://my.home-assistant.io/redirect/lovelace_resources/)，或在 Home Assistant 中手动打开：**设置 → 仪表盘 → ⋮ → 资源** *(**Settings → Dashboards → ⋮ → Resources**)*。
4. 点击 **添加资源** (**Add resource**)。
5. 在 URL 字段中输入 `/local/ha-mdi-off-fallback.js`。
6. 选择 **JavaScript 模块** (**JavaScript Module**)，然后点击 **创建** (**Create**)。
7. 清除浏览器缓存并刷新 Home Assistant 页面。

<a id="configuration"></a>
## 🔧 配置

自定义配置是可选的。没有自定义文件时，插件使用内置值：

<a id="default-configuration"></a>
### 默认配置

默认情况下，以下状态被视为非活动状态：

| 实体域 | 非活动状态 |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

同时使用以下设置：

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### 自定义配置

要定义自己的规则，请创建文件：

```text
/config/www/ha-mdi-off-fallback.config.json
```

示例：

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

配置与 HACS 管理的插件文件分开存储，因此插件更新不会覆盖配置。

#### `states` 部分的工作方式

如果自定义配置包含 `states` 对象，它会**完全替换**内置列表。插件只会考虑明确列出的域和状态。

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

在此示例中，斜线只应用于 `light` 和 `cover`。`switch`、`fan`、`climate` 以及其他域的内置规则不会使用。

要恢复内置列表，请从配置中删除 `states`，或删除配置文件。

其他设置相互独立：如果省略某项设置，则继续使用其内置值。

<a id="background"></a>
#### 非活动图标背景

如果 Home Assistant 已经绘制了非活动图标的原生背景，插件不会修改它。

如果背景缺失，插件会添加一个淡色圆圈，与 Home Assistant 标准非活动“磁贴”图标的样式一致。

禁用：

```json
{
  "faint_background_when_missing": false
}
```

更改透明度：

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### 通过控制台临时配置

`haMdiOffFallback.configure()` 使用相同的规则。

传入的 `states` 对象会完全替换当前列表：

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

如果省略 `states`，当前列表保持不变：

```js
haMdiOffFallback.configure({
  debug: true
})
```

通过 `configure()` 应用的设置只在当前标签页中有效，直到页面重新加载。永久配置请使用 JSON 文件。

<a id="reload-config"></a>
#### 重新加载配置

修改 JSON 文件后，可以在不刷新页面的情况下重新加载配置：

```js
haMdiOffFallback.reloadConfig()
```

查看当前配置：

```js
haMdiOffFallback.getConfig()
```
