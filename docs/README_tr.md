# 🚫 Home Assistant için MDI Off Fallback

![Eklenti işlevinin görselleştirmesi](demo.jpg)

Eklenti, eklenen çizginin Home Assistant'ın yerleşik bir parçası gibi görünmesi için tasarlanmıştır:
* standart Döşeme kartlarını değiştirmeden çalışır ve yerleşik görünüm, davranış, renk, boyut ve etkileşimleri korur;
* yalnızca önceden oluşturulmuş simgeleri ve yalnızca yerleşik `-off` çeşidi yoksa değiştirir;
* yerleşik arka plan yoksa Home Assistant tarzında soluk, dairesel bir arka plan ekler;
* varlık durumlarını değiştirmez ve cihazların çalışmasına müdahale etmez.

<a id="installation"></a>
## 📦 Kurulum

### 🛍 HACS üzerinden kurulum
ℹ️ [HACS nedir ve nasıl kurulur?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_tr.md)

#### 1. Bu depoyu HACS'e ekleme
Eklentinin varsayılan HACS kataloğuna eklenmesi aylar sürebilir. Bu nedenle önce depoyu elle ekleyin:
1. HACS'i açın.
2. Sağ üst köşedeki menüyü açın ve **Özel depolar** seçeneğini seçin.
3. Depoyu ekleyin:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Tür olarak **Gösterge paneli** seçin ve **Ekle**'ye tıklayın.

> Depoyu **Özel depolar** bölümüne eklemek yalnızca eklentiyi HACS'te kullanılabilir hâle getirir. Eklentinin kendisi **İndir** düğmesiyle ayrıca kurulur.

#### 2. Eklentiyi kurma
1. HACS'te şunu arayın: `MDI Off Fallback` ve açın.
2. **İndir**'e tıklayın ve kurulumu onaylayın.
3. İndirme tamamlandığında tarayıcı önbelleğini temizleyerek Home Assistant sayfasını yenileyin.

<a id="manual-installation"></a>
### 🧑‍💻 Elle kurulum (HACS olmadan)

1. [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js) dosyasını indirin.
2. Dosyayı `/config/www/ha-mdi-off-fallback.js` konumuna kopyalayın.
3. [Kaynaklar'a gidin](https://my.home-assistant.io/redirect/lovelace_resources/) veya Home Assistant'ta elle açın: **Ayarlar → Gösterge panelleri → ⋮ → Kaynaklar** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. **Kaynak ekle**'ye tıklayın (**Add resource**).
5. URL alanına `/local/ha-mdi-off-fallback.js` yazın.
6. **JavaScript Modülü**nü seçin (**JavaScript Module**) ve **Oluştur**'a tıklayın (**Create**).
7. Tarayıcı önbelleğini temizleyerek Home Assistant sayfasını yenileyin.

<a id="configuration"></a>
## 🔧 Yapılandırma

Özel yapılandırma isteğe bağlıdır. Özel dosya yoksa eklenti yerleşik değerleri kullanır:

<a id="default-configuration"></a>
### Varsayılan yapılandırma

Varsayılan olarak aşağıdaki durumlar etkin değil kabul edilir:

| Varlık etki alanı | Etkin olmayan durumlar |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Aşağıdaki ayarlar da kullanılır:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Özel yapılandırma

Kendi kurallarınızı tanımlamak için şu dosyayı oluşturun:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Örnek:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Yapılandırma, HACS tarafından yönetilen eklenti dosyalarından ayrı tutulur; bu nedenle güncellemeler yapılandırmayı üzerine yazmaz.

#### `states` bölümü nasıl çalışır

Özel yapılandırmada bir `states` nesnesi varsa bu nesne yerleşik listeyi **tamamen değiştirir**. Eklenti yalnızca açıkça belirtilen etki alanlarını ve durumları dikkate alır.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

Bu örnekte çizgi yalnızca `light` ve `cover` için uygulanır. `switch`, `fan`, `climate` ve diğer etki alanlarına ait yerleşik kurallar kullanılmaz.

Yerleşik listeye dönmek için yapılandırmadan `states` öğesini kaldırın veya yapılandırma dosyasını silin.

Diğer ayarlar bağımsızdır: Bir ayar belirtilmezse yerleşik değeri kullanılmaya devam eder.

<a id="background"></a>
#### Etkin olmayan simgenin arka planı

Home Assistant etkin olmayan simgenin yerleşik arka planını zaten çiziyorsa eklenti bunu değiştirmez.

Arka plan yoksa eklenti, Home Assistant'taki standart etkin olmayan Döşeme simgelerinin stiline uyan soluk bir daire ekler.

Devre dışı bırakma:

```json
{
  "faint_background_when_missing": false
}
```

Saydamlığı değiştirme:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Konsoldan geçici yapılandırma

`haMdiOffFallback.configure()` aynı kuralları kullanır.

Verilen `states` nesnesi geçerli listeyi tamamen değiştirir:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

`states` verilmezse geçerli liste değişmeden kalır:

```js
haMdiOffFallback.configure({
  debug: true
})
```

`configure()` ile uygulanan ayarlar, sayfa yeniden yüklenene kadar yalnızca geçerli sekmede etkin kalır. Kalıcı yapılandırma için JSON dosyasını kullanın.

<a id="reload-config"></a>
#### Yapılandırmayı yeniden yükleme

JSON dosyasını değiştirdikten sonra sayfayı yenilemeden yapılandırmayı yeniden yükleyebilirsiniz:

```js
haMdiOffFallback.reloadConfig()
```

Etkin yapılandırmayı görüntüleme:

```js
haMdiOffFallback.getConfig()
```
