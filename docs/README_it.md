> Home Assistant consente di utilizzare qualsiasi icona MDI, ma non tutte dispongono di una variante `-off`. Di conseguenza, un dispositivo può essere già spento mentre la sua icona appare ancora attiva. Questo plugin aggiunge automaticamente una barra in stile MDI alle entità inattive quando non è disponibile un'icona di spegnimento nativa.

# 🚫 MDI Off Fallback per Home Assistant

![Funzionamento del plugin](demo.jpg)

Il plugin è progettato affinché la barra aggiunta sembri una parte nativa di Home Assistant:
* funziona con le schede Tile standard senza sostituirle e ne conserva aspetto, comportamento, colori, dimensioni e interazioni;
* supporta anche `Mushroom Template Card`; la scheda deve avere una `entity` configurata affinché il plugin possa determinarne lo stato;
* modifica solo le icone già renderizzate e soltanto quando non è disponibile una variante nativa `-off`;
* può facoltativamente aggiungere un debole sfondo circolare quando manca lo sfondo nativo;
* non modifica gli stati delle entità e non interferisce con il funzionamento dei dispositivi.
<a id="installation"></a>
## 📦 Installazione

### 🛍 Installazione tramite HACS
ℹ️ [Che cos'è HACS e come si installa?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_it.md)

#### 1. Aggiunta di questo repository a HACS
Potrebbero trascorrere mesi prima che il plugin venga aggiunto al catalogo HACS predefinito, quindi aggiungi prima manualmente questo repository:
1. Apri HACS.
2. Apri il menu nell'angolo in alto a destra e seleziona **Repository personalizzati** (**Custom repositories**).
3. Aggiungi il repository:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Seleziona **Dashboard** come tipo e premi **Aggiungi** (**Add**).

> L'aggiunta del repository a **Repository personalizzati** rende semplicemente disponibile il plugin in HACS. Il plugin viene installato separatamente con il pulsante **Scarica** (**Download**).

#### 2. Installazione del plugin
1. Cerca in HACS: `MDI Off Fallback` e aprilo.
2. Premi **Scarica** (**Download**) e conferma l'installazione.
3. Al termine del download, ricarica Home Assistant svuotando la cache del browser.

<a id="manual-installation"></a>
### 🧑‍💻 Installazione manuale (senza HACS)

1. Scarica [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Copia il file in `/config/www/ha-mdi-off-fallback.js`.
3. [Apri Risorse](https://my.home-assistant.io/redirect/lovelace_resources/) oppure raggiungile manualmente in Home Assistant: **Impostazioni → Dashboard → ⋮ → Risorse** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Premi **Aggiungi risorsa** (**Add resource**).
5. Inserisci `/local/ha-mdi-off-fallback.js` nel campo URL.
6. Seleziona **Modulo JavaScript** (**JavaScript Module**) e premi **Crea** (**Create**).
7. Ricarica Home Assistant svuotando la cache del browser.

<a id="configuration"></a>
## 🔧 Configurazione

La configurazione personalizzata è facoltativa. Senza un file personalizzato, il plugin utilizza i valori incorporati:

<a id="default-configuration"></a>
### Configurazione predefinita

Per impostazione predefinita, i seguenti stati sono considerati inattivi:

| Dominio dell'entità | Stati inattivi |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Vengono inoltre utilizzate le seguenti impostazioni:

```json
{
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Configurazione personalizzata

Per definire regole personalizzate, crea il file:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Esempio:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

La configurazione viene archiviata separatamente dai file del plugin gestiti da HACS, quindi gli aggiornamenti non la sovrascrivono.

#### Funzionamento della sezione `states`

Se la configurazione personalizzata contiene un oggetto `states`, questo **sostituisce completamente** l'elenco incorporato. Il plugin considera soltanto i domini e gli stati elencati esplicitamente.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

In questo esempio, la barra viene applicata soltanto a `light` e `cover`. Le regole incorporate per `switch`, `fan`, `climate` e gli altri domini non vengono utilizzate.

Per tornare all'elenco incorporato, rimuovi `states` dalla configurazione o elimina il file di configurazione.

Le altre impostazioni sono indipendenti: se un'impostazione non è specificata, rimane valido il suo valore incorporato.

<a id="background"></a>
#### Sfondo opzionale per le icone senza cerchio

Alcune icone MDI sono visivamente decentrate. Dopo l'aggiunta di una barra, possono apparire sbilanciati quando non c'è uno sfondo circolare per incorniciarli.

Ciò ha infastidito il mio senso dell'ordine visivo, quindi il plug-in include un'impostazione opzionale che disegna un debole cerchio dietro le icone inattive quando Home Assistant non ne fornisce uno.

Questa opzione è disabilitata di default perché il cerchio ha un significato nell'interfaccia Home Assistant: su una scheda Tile, normalmente indica che cliccando sull'icona si esegue un'azione separata dal cliccare sul resto della scheda. L'aggiunta di un cerchio esclusivamente per l'allineamento visivo modifica quindi la semantica visiva.

Puoi comunque abilitare lo sfondo se preferisci un aspetto più equilibrato:

```json
{
  "faint_background_when_missing": true
}
```

Quando abilitato, il plugin aggiunge lo sfondo solo dove Home Assistant non ne esegue già il rendering.

Puoi anche regolarne l'opacità:

```json
{
  "faint_background_opacity": 0.2
}
```

Scegli il comportamento più importante per la tua dashboard: preservare i segnali di interazione nativi di Home Assistant o mantenere le icone barrate visivamente centrate.

<a id="runtime-configuration"></a>
#### Configurazione temporanea dalla console

`haMdiOffFallback.configure()` utilizza le stesse regole.

Un oggetto `states` fornito sostituisce completamente l'elenco corrente:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Se `states` viene omesso, l'elenco corrente non cambia:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Le impostazioni applicate tramite `configure()` restano attive soltanto nella scheda corrente fino al ricaricamento della pagina. Per una configurazione permanente utilizza il file JSON.

<a id="reload-config"></a>
#### Ricaricamento della configurazione

Dopo aver modificato il file JSON, puoi ricaricare la configurazione senza ricaricare la pagina:

```js
haMdiOffFallback.reloadConfig()
```

Visualizza la configurazione attiva:

```js
haMdiOffFallback.getConfig()
```
