> Home Assistant овозможува користење произволни MDI икони, но не секоја икона има `-off` варијанта. Затоа уредот може веќе да биде исклучен, а неговата икона сè уште да изгледа активно. Овој приклучок автоматски додава дијагонална линија во MDI стил на неактивни ентитети кога нема вградена исклучена икона.

# 🚫 MDI Off Fallback за Home Assistant

![Приказ на работата на приклучокот](demo.jpg)

Приклучокот е направен така што додадената линија изгледа како природен дел од Home Assistant:
* работи со стандардните Tile картички без да ги заменува и ги зачувува изгледот, однесувањето, боите, големините и интеракциите;
* поддржува и 🍄 `Mushroom Template Card`; картичката мора да има зададено `entity` за приклучокот да може да ја одреди нејзината состојба;
* менува само веќе прикажани икони и само кога нема вградена `-off` варијанта;
* може опционално да додаде слаба кружна позадина кога недостасува мајчината позадина;
* не ги менува состојбите на ентитетите и не се меша во работата на уредите.
<a id="installation"></a>
## 📦 Инсталација

### 🛍 Инсталација преку HACS
ℹ️ [Што е HACS и како се инсталира?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_mk.md)

🚀 [Обидете се да го додадете репозиториумот преку оваа врска](https://my.home-assistant.io/redirect/hacs_repository/?owner=LanKing&repository=ha-mdi-off-fallback&category=plugin). Ако овој начин е поддржан во вашиот HA и работи, кликнете **Add** во отворениот прозорец, а потоа **Download** долу десно. Ако сè е успешно, инсталацијата е завршена и преостанатите чекори може да ги прескокнете. Одете директно на [Конфигурација](#configuration).

#### 1. Додавање на ова складиште во HACS
Може да поминат месеци пред приклучокот да биде додаден во стандардниот HACS каталог, затоа прво додадете го складиштето рачно:
1. Отворете HACS.
2. Отворете го менито во горниот десен агол и изберете **Приспособени складишта** (**Custom repositories**).
3. Додајте го складиштето:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Изберете **Контролна табла** (**Dashboard**) како тип и притиснете **Додај** (**Add**).

> Додавањето во **Приспособени складишта** само го прави приклучокот достапен во HACS. Самиот приклучок се инсталира одделно со копчето **Преземи** (**Download**).

#### 2. Инсталација на приклучокот
1. Пребарајте во HACS: `MDI Off Fallback` и отворете го.
2. Притиснете **Преземи** (**Download**) и потврдете ја инсталацијата.
3. По преземањето, повторно вчитајте го Home Assistant со исчистен кеш на прелистувачот.

<a id="manual-installation"></a>
### 🧑‍💻 Рачна инсталација (без HACS)

1. Преземете го [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Копирајте ја датотеката во `/config/www/ha-mdi-off-fallback.js`.
3. [Отворете Ресурси](https://my.home-assistant.io/redirect/lovelace_resources/) или одете таму рачно во Home Assistant: **Поставки → Контролни табли → ⋮ → Ресурси** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Притиснете **Додај ресурс** (**Add resource**).
5. Во полето URL внесете `/local/ha-mdi-off-fallback.js`.
6. Изберете **JavaScript модул** (**JavaScript Module**) и притиснете **Создај** (**Create**).
7. Повторно вчитајте го Home Assistant со исчистен кеш на прелистувачот.

<a id="configuration"></a>
## 🔧 Конфигурација

Приспособената конфигурација е незадолжителна. Без приспособена датотека приклучокот ги користи вградените вредности:

<a id="default-configuration"></a>
### Стандардна конфигурација

Стандардно следните состојби се сметаат за неактивни:

| Домен на ентитет | Неактивни состојби |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Се користат и следните поставки:

```json
{
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Приспособена конфигурација

За да дефинирате сопствени правила, создајте ја датотеката:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Пример:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Конфигурацијата се чува одделно од датотеките на приклучокот што ги управува HACS, па ажурирањата нема да ја препишат.

#### Како работи делот `states`

Ако приспособената конфигурација содржи објект `states`, тој **целосно ја заменува** вградената листа. Приклучокот ќе ги земе предвид само изречно наведените домени и состојби.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

Во овој пример линијата ќе се примени само на `light` и `cover`. Вградените правила за `switch`, `fan`, `climate` и другите домени нема да се користат.

За враќање на вградената листа, отстранете го `states` од конфигурацијата или избришете ја конфигурациската датотека.

Останатите поставки се независни: ако поставка не е наведена, останува активна нејзината вградена вредност.

<a id="background"></a>
#### Изборна позадина за икони без круг

Некои MDI икони се визуелно надвор од центарот. Откако ќе се додаде коса црта, тие може да изгледаат неурамнотежени кога нема кружна позадина за да ги врами.

Ова го вознемири моето чувство за визуелен ред, па приклучокот вклучува опционална поставка што црта слаб круг зад неактивните икони кога Home Assistant не обезбедува една.

Оваа опција е стандардно оневозможена затоа што кругот има значење во интерфејсот Home Assistant: на картичката Tile, обично покажува дека со кликнување на иконата се врши посебна акција од кликнување на остатокот од картичката. Додавањето круг чисто за визуелно порамнување затоа ја менува таа визуелна семантика.

Сè уште можете да ја овозможите позадината ако претпочитате побалансиран изглед:

```json
{
  "faint_background_when_missing": true
}
```

Кога е овозможено, приклучокот ја додава само позадината каде што Home Assistant веќе не ја прикажува.

Можете исто така да ја прилагодите неговата непроѕирност:

```json
{
  "faint_background_opacity": 0.2
}
```

Изберете кое однесување е повеќе важно за вашата контролна табла: зачувување на изворните знаци за интеракција на Home Assistant или одржување на исечените икони визуелно центрирани.

<a id="runtime-configuration"></a>
#### Привремена конфигурација преку конзолата

`haMdiOffFallback.configure()` ги користи истите правила.

Предадениот објект `states` целосно ја заменува тековната листа:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Ако `states` е изоставен, тековната листа не се менува:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Поставките применети преку `configure()` важат само во тековниот таб до повторното вчитување на страницата. За трајна конфигурација користете ја JSON датотеката.

<a id="reload-config"></a>
#### Повторно вчитување на конфигурацијата

По уредувањето на JSON датотеката, конфигурацијата може повторно да се вчита без повторно вчитување на страницата:

```js
haMdiOffFallback.reloadConfig()
```

Прикажување на активната конфигурација:

```js
haMdiOffFallback.getConfig()
```
