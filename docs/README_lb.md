> Home Assistant erlaabt all MDI-Ikon ze benotzen, mee net all Ikon huet eng `-off`-Variant. Doduerch kann en Apparat schonn ausgeschalt sinn, obwuel seng Ikon nach aktiv ausgesäit. Dëse Plugin setzt automatesch eng MDI-ähnlech Stréchmarkéierung op inaktiv Entitéiten, wann keng agebaute Aus-Ikon disponibel ass.

# 🚫 MDI Off Fallback fir Home Assistant

![Visualiséierung vun der Plugin-Funktioun](demo.jpg)

De Plugin ass esou entwéckelt, datt de bäigesate Stréch wéi en natierlechen Deel vu Home Assistant ausgesäit:
* funktionéiert mat Standard-Tile-Kaarten ouni se ze ersetzen a behält Ausgesinn, Verhalen, Faarwen, Gréissten an Interaktiounen;
* ënnerstëtzt och `Mushroom Template Card`; d'Kaart muss eng `entity` definéiert hunn, fir datt de Plugin hire Status bestëmme kann;
* ännert nëmmen Ikonen déi scho gerendert goufen, an nëmmen wann keng agebaute `-off`-Variant existéiert;
* kann optional e liichtschwaache kreesfërmegen Hannergrond addéieren wann den gebiertege Hannergrond fehlt;
* ännert keng Entitéitszoustänn a gräift net an d'Funktioun vun Apparater an.
<a id="installation"></a>
## 📦 Installatioun

### 🛍 Installatioun iwwer HACS
ℹ️ [Wat ass HACS a wéi gëtt et installéiert?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_lb.md)

#### 1. Dëse Repository bei HACS dobäisetzen
Et ka Méint daueren, bis de Plugin am Standard-HACS-Katalog steet. Dofir muss de Repository fir d'éischt manuell dobäigesat ginn:
1. Maach HACS op.
2. Maach de Menü uewe riets op a wielt **Benotzerdefinéiert Repositories** (**Custom repositories**).
3. Setz dëse Repository dobäi:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Wielt **Dashboard** als Typ a klick op **Dobäisetzen** (**Add**).

> E Repository ënner **Benotzerdefinéiert Repositories** dobäizesetzen mécht de Plugin nëmmen an HACS disponibel. De Plugin selwer gëtt separat mam Knäppchen **Eroflueden** (**Download**) installéiert.

#### 2. De Plugin installéieren
1. Sich an HACS no: `MDI Off Fallback` a maach en op.
2. Klick op **Eroflueden** (**Download**) a bestäteg d'Installatioun.
3. Nom Eroflueden Home Assistant nei lueden an de Browser-Cache läschen.

<a id="manual-installation"></a>
### 🧑‍💻 Manuell Installatioun (ouni HACS)

1. Luet [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js) erof.
2. Kopéier d'Datei op `/config/www/ha-mdi-off-fallback.js`.
3. [Maach Ressourcen op](https://my.home-assistant.io/redirect/lovelace_resources/) oder navigéier manuell a Home Assistant: **Astellungen → Dashboards → ⋮ → Ressourcen** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Klick op **Ressource dobäisetzen** (**Add resource**).
5. Gëff `/local/ha-mdi-off-fallback.js` am URL-Feld an.
6. Wielt **JavaScript-Modul** (**JavaScript Module**) a klick op **Erstellen** (**Create**).
7. Home Assistant nei lueden an de Browser-Cache läschen.

## 🔧 Konfiguratioun

Eng benotzerdefinéiert Konfiguratioun ass optional. Ouni eege Datei benotzt de Plugin seng agebaute Wäerter:

<a id="default-configuration"></a>
### Standardkonfiguratioun

Standardméisseg ginn dës Zoustänn als inaktiv ugesinn:

| Entitéitsdomain | Inaktiv Zoustänn |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Ausserdeem ginn dës Astellunge benotzt:

```json
{
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Benotzerdefinéiert Konfiguratioun

Fir eege Reegelen ze definéieren, erstell dës Datei:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Beispill:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

D'Konfiguratioun gëtt getrennt vun de Plugin-Dateie gespäichert, déi HACS verwalt. Aktualiséierunge schreiwen se dofir net iwwer.

#### Wéi de Beräich `states` funktionéiert

Wann d'benotzerdefinéiert Konfiguratioun en `states`-Objet enthält, **ersetzt en déi agebaute Lëscht komplett**. De Plugin berücksichtegt nëmmen explizitt opgelëschte Domainen an Zoustänn.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

An dësem Beispill gëtt de Stréch nëmmen op `light` an `cover` applizéiert. Déi agebaute Reegelen fir `switch`, `fan`, `climate` an aner Domaine ginn net benotzt.

Fir op déi agebaute Lëscht zeréckzegoen, läsch `states` aus der Konfiguratioun oder läsch d'Konfiguratiounsdatei.

Déi aner Astellunge sinn onofhängeg: wann eng Astellung feelt, bleift hire agebaute Wäert aktiv.

<a id="background"></a>
#### Optional Hannergrond fir Ikonen ouni Krees

E puer MDI Symboler si visuell aus dem Zentrum. Nodeems e Slash bäigefüügt ass, kënne se onbalancéiert ausgesinn wann et kee kreesfërmegen Hannergrond ass fir se ze kadréieren.

Dëst huet mäi Sënn vu visueller Uerdnung gestéiert, sou datt de Plugin eng fakultativ Astellung enthält, déi e liichtschwaache Krees hannert inaktiven Ikonen zitt wann Home Assistant keng ubitt.

Dës Optioun ass par défaut deaktivéiert well de Krees eng Bedeitung an der Home Assistant Interface huet: op enger Tile Kaart weist et normalerweis un datt wann Dir op d'Ikon klickt, eng separat Handlung ausféiert vum Klick op de Rescht vun der Kaart. E Krees derbäi reng fir visuell Ausrichtung ännert dofir déi visuell Semantik.

Dir kënnt nach ëmmer den Hannergrond aktivéieren wann Dir dat méi equilibréiert Erscheinungsbild léiwer hutt:

```json
{
  "faint_background_when_missing": true
}
```

Wann et aktivéiert ass, füügt de Plugin nëmmen den Hannergrond bäi wou Home Assistant net schonn een mécht.

Dir kënnt och seng Opazitéit upassen:

```json
{
  "faint_background_opacity": 0.2
}
```

Wielt wéi ee Verhalen méi wichteg ass fir Ären Dashboard: bewahrt dem Home Assistant seng gebierteg Interaktiounsstécker oder hält geschnidde Symboler visuell zentréiert.

<a id="runtime-configuration"></a>
#### Temporär Konfiguratioun iwwer d'Konsole

`haMdiOffFallback.configure()` benotzt déiselwecht Reegelen.

En iwwerginn `states`-Objet ersetzt déi aktuell Lëscht komplett:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Wann `states` feelt, bleift déi aktuell Lëscht onverännert:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Astellungen iwwer `configure()` bleiwen nëmmen am aktuellen Tab aktiv, bis d'Säit nei geluede gëtt. Fir eng dauerhaft Konfiguratioun benotz d'JSON-Datei.

<a id="reload-config"></a>
#### Konfiguratioun nei lueden

Nom Ännere vun der JSON-Datei kann d'Konfiguratioun ouni Neiluede vun der Säit nei geluede ginn:

```js
haMdiOffFallback.reloadConfig()
```

Aktiv Konfiguratioun weisen:

```js
haMdiOffFallback.getConfig()
```
