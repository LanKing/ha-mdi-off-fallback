> Home Assistantissa voi käyttää mitä tahansa MDI-kuvakkeita, mutta kaikilla kuvakkeilla ei ole `-off`-versiota. Laite voi siis olla pois päältä, vaikka sen kuvake näyttää edelleen aktiiviselta. Tämä lisäosa lisää automaattisesti MDI-tyylisen vinoviivan passiivisiin entiteetteihin, kun sisäänrakennettua pois päältä -kuvaketta ei ole.

# 🚫 MDI Off Fallback Home Assistantille

![Lisäosan toiminnan esittely](demo.jpg)

Lisäosa on toteutettu niin, että lisätty vinoviiva näyttää Home Assistantin alkuperäiseltä osalta:
* toimii tavallisten Tile-korttien kanssa korvaamatta niitä ja säilyttää niiden alkuperäisen ulkoasun, toiminnan, värit, koot ja vuorovaikutukset;
* muuttaa vain jo renderöityjä kuvakkeita ja vain silloin, kun sisäänrakennettua `-off`-versiota ei ole;
* lisää himmeän pyöreän Home Assistant -tyylisen taustan, jos alkuperäinen tausta puuttuu;
* ei muuta entiteettien tiloja eikä häiritse laitteiden toimintaa.

<a id="installation"></a>
## 📦 Asennus

### 🛍 Asennus HACS:n kautta
ℹ️ [Mikä HACS on ja miten se asennetaan?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_fi.md)

#### 1. Tämän tietovaraston lisääminen HACS:iin
Lisäosan virallinen lisääminen HACS:iin voi kestää kuukausia, joten tietovarasto on ensin lisättävä käsin:
1. Avaa HACS.
2. Avaa oikean yläkulman valikko ja valitse **Mukautetut tietovarastot** (**Custom repositories**).
3. Lisää tietovarasto:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```

4. Valitse tyypiksi **Hallintapaneeli** (**Dashboard**) ja napsauta **Lisää** (**Add**).

> Tietovaraston lisääminen kohtaan **Mukautetut tietovarastot** vain tuo lisäosan saataville HACS:ssa. Itse lisäosa asennetaan erikseen **Lataa** (**Download**) -painikkeella.

#### 2. Lisäosan asentaminen
1. Etsi HACS:ssa: `MDI Off Fallback` ja avaa se.
2. Napsauta **Lataa** (**Download**) ja vahvista asennus.
3. Kun lataus on valmis, lataa Home Assistant uudelleen ja tyhjennä selaimen välimuisti.

<a id="manual-installation"></a>
### 🧑‍💻 Manuaalinen asennus (ilman HACS:ia)

1. Lataa [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Kopioi tiedosto sijaintiin `/config/www/ha-mdi-off-fallback.js`.
3. [Siirry Resursseihin](https://my.home-assistant.io/redirect/lovelace_resources/) tai avaa ne käsin Home Assistantissa: **Asetukset → Hallintapaneelit → ⋮ → Resurssit** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Napsauta **Lisää resurssi** (**Add resource**).
5. Syötä URL-kenttään `/local/ha-mdi-off-fallback.js`.
6. Valitse **JavaScript-moduuli** (**JavaScript Module**) ja napsauta **Luo** (**Create**).
7. Lataa Home Assistant uudelleen ja tyhjennä selaimen välimuisti.

<a id="configuration"></a>
## 🔧 Määritys

Mukautettu määritys on valinnainen. Ilman mukautettua tiedostoa lisäosa käyttää sisäänrakennettuja arvoja:

<a id="default-configuration"></a>
### Oletusmääritys

Oletuksena seuraavat tilat katsotaan passiivisiksi:

| Entiteetin toimialue | Passiiviset tilat |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Myös seuraavia asetuksia käytetään:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Mukautettu määritys

Luo omia sääntöjä varten tiedosto:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Esimerkki:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Määritys tallennetaan erilleen HACS:n hallinnoimista lisäosan tiedostoista, joten päivitykset eivät korvaa sitä.

#### `states`-osion toiminta

Jos mukautettu määritys sisältää `states`-objektin, se **korvaa sisäänrakennetun luettelon kokonaan**. Lisäosa ottaa huomioon vain erikseen luetellut toimialueet ja tilat.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

Tässä esimerkissä vinoviiva lisätään vain toimialueille `light` ja `cover`. Sisäänrakennettuja sääntöjä toimialueille `switch`, `fan`, `climate` ja muille ei käytetä.

Palaa sisäänrakennettuun luetteloon poistamalla `states` määrityksestä tai poistamalla määritystiedosto.

Muut asetukset ovat riippumattomia: jos asetusta ei määritetä, sen sisäänrakennettu arvo säilyy.

<a id="background"></a>
#### Passiivisen kuvakkeen tausta

Jos Home Assistant näyttää jo passiivisen kuvakkeen alkuperäisen taustan, lisäosa ei muuta sitä.

Jos tausta puuttuu, lisäosa lisää himmeän ympyrän, joka vastaa Home Assistantin tavallisen passiivisen Tile-kuvakkeen tyyliä.

Poista käytöstä:

```json
{
  "faint_background_when_missing": false
}
```

Muuta läpinäkyvyyttä:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Tilapäinen määritys konsolista

`haMdiOffFallback.configure()` käyttää samaa logiikkaa.

Annettu `states`-objekti korvaa nykyisen luettelon kokonaan:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Jos `states`-objektia ei anneta, nykyinen luettelo ei muutu:

```js
haMdiOffFallback.configure({
  debug: true
})
```

`configure()`-toiminnolla tehdyt asetukset ovat voimassa vain nykyisessä välilehdessä sivun uudelleenlataukseen asti. Käytä pysyvään määritykseen JSON-tiedostoa.

<a id="reload-config"></a>
#### Määrityksen lataaminen uudelleen

JSON-tiedoston muokkaamisen jälkeen määritys voidaan ladata uudelleen lataamatta sivua:

```js
haMdiOffFallback.reloadConfig()
```

Näytä aktiivinen määritys:

```js
haMdiOffFallback.getConfig()
```
