> Home Assistant laat jou toe om enige MDI-ikoon te gebruik, maar nie elke ikoon het ’n `-off`-variant nie. Gevolglik kan ’n toestel reeds afgeskakel wees terwyl die ikoon steeds aktief lyk. Hierdie inprop voeg outomaties ’n MDI-styl skuinsstreep by onaktiewe entiteite wanneer geen ingeboude af-ikoon beskikbaar is nie.

# 🚫 MDI Off Fallback vir Home Assistant

![Visualisering van die inprop se werking](demo.jpg)

Die inprop is ontwerp sodat die bygevoegde skuinsstreep soos ’n ingeboude deel van Home Assistant lyk:
* werk met standaard Tile-kaarte sonder om hulle te vervang en behou hul gewone voorkoms, gedrag, kleure, groottes en interaksies;
* verander slegs ikone wat reeds weergegee is, en slegs wanneer geen ingeboude `-off`-variant beskikbaar is nie;
* voeg ’n dowwe ronde agtergrond in Home Assistant-styl by wanneer die ingeboude agtergrond ontbreek;
* verander nie entiteitstoestande nie en meng nie met toestelle se werking in nie.

<a id="installation"></a>
## 📦 Installasie

### 🛍 Installasie via HACS
ℹ️ [Wat is HACS en hoe installeer ek dit?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_af.md)

#### 1. Voeg hierdie bewaarplek by HACS
Dit kan maande neem voordat die inprop amptelik by HACS gevoeg word, daarom moet die bewaarplek aanvanklik handmatig by HACS gevoeg word:
1. Maak HACS oop.
2. Maak die kieslys regs bo oop en kies **Pasgemaakte bewaarplekke** (**Custom repositories**).
3. Voeg die bewaarplek by:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```

4. Kies die tipe **Kontroleskerm** (**Dashboard**) en klik **Voeg by** (**Add**).

> Om die bewaarplek onder **Pasgemaakte bewaarplekke** by te voeg, maak die inprop net in HACS beskikbaar. Die inprop self word afsonderlik met die **Laai af** (**Download**)-knoppie geïnstalleer.

#### 2. Installeer die inprop
1. Soek in HACS na: `MDI Off Fallback` en maak dit oop.
2. Klik **Laai af** (**Download**) en bevestig die installasie.
3. Wanneer die aflaai voltooi is, herlaai Home Assistant en maak die blaaierkas skoon.

<a id="manual-installation"></a>
### 🧑‍💻 Handmatige installasie (sonder HACS)

1. Laai [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js) af.
2. Kopieer die lêer na `/config/www/ha-mdi-off-fallback.js`.
3. [Gaan na Hulpbronne](https://my.home-assistant.io/redirect/lovelace_resources/) of maak dit handmatig in Home Assistant oop: **Instellings → Kontroleskerms → ⋮ → Hulpbronne** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Klik **Voeg hulpbron by** (**Add resource**).
5. Voer `/local/ha-mdi-off-fallback.js` in die URL-veld in.
6. Kies **JavaScript-module** (**JavaScript Module**) en klik **Skep** (**Create**).
7. Herlaai Home Assistant en maak die blaaierkas skoon.

<a id="configuration"></a>
## 🔧 Opstelling

’n Pasgemaakte opstelling is opsioneel. Sonder ’n pasgemaakte lêer gebruik die inprop sy ingeboude waardes:

<a id="default-configuration"></a>
### Verstekopstelling

By verstek word die volgende toestande as onaktief beskou:

| Entiteitsdomein | Onaktiewe toestande |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Die volgende parameters word ook gebruik:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Pasgemaakte opstelling

Skep die volgende lêer om jou eie reëls te definieer:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Voorbeeld:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Die opstelling word apart van die inproplêers gestoor wat deur HACS bestuur word, dus sal inprop-opdaterings dit nie oorskryf nie.

#### Hoe die `states`-afdeling werk

Wanneer die pasgemaakte opstelling ’n `states`-voorwerp bevat, **vervang dit die ingeboude lys volledig**. Die inprop sal slegs die uitdruklik gelyste domeine en toestande gebruik.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

In hierdie voorbeeld word die skuinsstreep slegs op `light` en `cover` toegepas. Die ingeboude reëls vir `switch`, `fan`, `climate` en alle ander domeine word nie gebruik nie.

Verwyder `states` uit die opstelling of verwyder die opstellingslêer om na die ingeboude lys terug te keer.

Die ander parameters is onafhanklik: wanneer ’n parameter nie vermeld word nie, bly sy ingeboude waarde van toepassing.

<a id="background"></a>
#### Agtergrond van ’n onaktiewe ikoon

As Home Assistant reeds die ingeboude agtergrond vir ’n onaktiewe ikoon teken, verander die inprop dit nie.

Wanneer daardie agtergrond ontbreek, voeg die inprop ’n dowwe sirkel by wat ooreenstem met die standaardstyl van ’n onaktiewe Tile-ikoon in Home Assistant.

Deaktiveer dit:

```json
{
  "faint_background_when_missing": false
}
```

Verander die deursigtigheid:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Tydelike opstelling via die konsole

`haMdiOffFallback.configure()` gebruik dieselfde logika.

’n Verskafde `states`-voorwerp vervang die huidige lys volledig:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Wanneer `states` nie verskaf word nie, bly die huidige lys onveranderd:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Opstellings wat met `configure()` toegepas word, bly slegs in die huidige oortjie aktief totdat die bladsy herlaai word. Gebruik die JSON-lêer vir permanente opstelling.

<a id="reload-config"></a>
#### Herlaai die opstelling

Nadat die JSON-lêer gewysig is, kan die opstelling herlaai word sonder om die bladsy te herlaai:

```js
haMdiOffFallback.reloadConfig()
```

Bekyk die aktiewe opstelling:

```js
haMdiOffFallback.getConfig()
```
