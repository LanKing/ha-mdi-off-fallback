# 🚫 Home Assistant-க்கான MDI Off Fallback

![செருகுநிரல் செயல்பாட்டின் விளக்கம்](demo.jpg)

சேர்க்கப்பட்ட சாய்வுக்கோடு Home Assistant இன் சொந்த பகுதியாகத் தோன்றும் வகையில் செருகுநிரல் வடிவமைக்கப்பட்டுள்ளது:
* நிலையான டைல் கார்டுகளை மாற்றாமல் அவற்றுடன் செயல்பட்டு, சொந்த தோற்றம், நடத்தை, நிறங்கள், அளவுகள் மற்றும் தொடர்புகளைப் பாதுகாக்கிறது;
* ஏற்கனவே வரையப்பட்ட ஐகான்களை மட்டுமே, அதுவும் சொந்த `-off` வடிவம் இல்லாதபோது மட்டுமே மாற்றுகிறது;
* சொந்த பின்னணி இல்லாதபோது Home Assistant பாணியில் மங்கலான வட்டப் பின்னணியைச் சேர்க்கிறது;
* எண்டிட்டி நிலைகளை மாற்றாது; சாதனங்களின் செயல்பாட்டில் தலையிடாது.

## 📦 நிறுவல்

### 🛍 HACS மூலம் நிறுவல்
ℹ️ [HACS என்றால் என்ன, அதை எப்படி நிறுவுவது?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_ta.md)

#### 1. இந்த களஞ்சியத்தை HACS-இல் சேர்த்தல்
செருகுநிரல் இயல்புநிலை HACS பட்டியலில் சேர மாதங்கள் ஆகலாம்; எனவே முதலில் களஞ்சியத்தை கைமுறையாகச் சேர்க்கவும்:
1. HACS-ஐத் திறக்கவும்.
2. மேல் வலது மூலையில் உள்ள மெனுவைத் திறந்து **தனிப்பயன் களஞ்சியங்கள்** என்பதைத் தேர்ந்தெடுக்கவும்.
3. களஞ்சியத்தைச் சேர்க்கவும்:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. வகையாக **டாஷ்போர்டு** என்பதைத் தேர்ந்தெடுத்து **சேர்** என்பதைக் கிளிக் செய்யவும்.

> களஞ்சியத்தை **தனிப்பயன் களஞ்சியங்கள்** பகுதியில் சேர்ப்பது செருகுநிரலை HACS-இல் கிடைக்கச் செய்வதற்கே. செருகுநிரல் தனியாக **பதிவிறக்கு** பொத்தானால் நிறுவப்படுகிறது.

#### 2. செருகுநிரலை நிறுவுதல்
1. HACS-இல்: `MDI Off Fallback` எனத் தேடி அதைத் திறக்கவும்.
2. **பதிவிறக்கு** என்பதைக் கிளிக் செய்து நிறுவலை உறுதிப்படுத்தவும்.
3. பதிவிறக்கம் முடிந்ததும் உலாவி தற்காலிக நினைவகத்தை அழித்து Home Assistant பக்கத்தைப் புதுப்பிக்கவும்.

<a id="manual-installation"></a>
### 🧑‍💻 கைமுறை நிறுவல் (HACS இல்லாமல்)

1. [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js) கோப்பைப் பதிவிறக்கவும்.
2. கோப்பை `/config/www/ha-mdi-off-fallback.js` இடத்துக்கு நகலெடுக்கவும்.
3. [வளங்கள் பகுதிக்குச் செல்லவும்](https://my.home-assistant.io/redirect/lovelace_resources/) அல்லது Home Assistant-இல் கைமுறையாகத் திறக்கவும்: **அமைப்புகள் → டாஷ்போர்டுகள் → ⋮ → வளங்கள்** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. **வளத்தைச் சேர்** என்பதைக் கிளிக் செய்யவும் (**Add resource**).
5. URL புலத்தில் `/local/ha-mdi-off-fallback.js` என உள்ளிடவும்.
6. **JavaScript தொகுதி** என்பதைத் தேர்ந்தெடுத்து (**JavaScript Module**) **உருவாக்கு** என்பதைக் கிளிக் செய்யவும் (**Create**).
7. உலாவி தற்காலிக நினைவகத்தை அழித்து Home Assistant பக்கத்தைப் புதுப்பிக்கவும்.

<a id="configuration"></a>
## 🔧 கட்டமைப்பு

தனிப்பயன் கட்டமைப்பு விருப்பத் தேர்வாகும். தனிப்பயன் கோப்பு இல்லாவிட்டால் செருகுநிரல் உள்ளமைக்கப்பட்ட மதிப்புகளைப் பயன்படுத்தும்:

<a id="default-configuration"></a>
### இயல்புநிலை கட்டமைப்பு

இயல்பாக கீழ்கண்ட நிலைகள் செயலற்றதாகக் கருதப்படும்:

| எண்டிட்டி டொமைன் | செயலற்ற நிலைகள் |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

கீழ்க்கண்ட அமைப்புகளும் பயன்படுத்தப்படுகின்றன:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### தனிப்பயன் கட்டமைப்பு

உங்கள் சொந்த விதிகளை வரையறுக்க இந்தக் கோப்பை உருவாக்கவும்:

```text
/config/www/ha-mdi-off-fallback.config.json
```

எடுத்துக்காட்டு:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

கட்டமைப்பு HACS நிர்வகிக்கும் செருகுநிரல் கோப்புகளிலிருந்து தனியாகச் சேமிக்கப்படும்; எனவே புதுப்பிப்புகள் அதை மேலெழுதாது.

#### `states` பகுதி செயல்படும் விதம்

தனிப்பயன் கட்டமைப்பில் `states` பொருள் இருந்தால், அது உள்ளமைக்கப்பட்ட பட்டியலை **முழுமையாக மாற்றும்**. வெளிப்படையாகக் குறிப்பிடப்பட்ட டொமைன்கள் மற்றும் நிலைகள் மட்டுமே பயன்படுத்தப்படும்.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

இந்த எடுத்துக்காட்டில் சாய்வுக்கோடு `light` மற்றும் `cover` க்கு மட்டுமே பயன்படுத்தப்படும். `switch`, `fan`, `climate` மற்றும் பிற டொமைன்களுக்கான உள்ளமைக்கப்பட்ட விதிகள் பயன்படுத்தப்படாது.

உள்ளமைக்கப்பட்ட பட்டியலுக்குத் திரும்ப, கட்டமைப்பிலிருந்து `states` ஐ நீக்கவும் அல்லது கட்டமைப்பு கோப்பை அழிக்கவும்.

மற்ற அமைப்புகள் தனித்தனியானவை: ஒரு அமைப்பு விடுபட்டால் அதன் உள்ளமைக்கப்பட்ட மதிப்பு தொடர்ந்தும் பயன்படுத்தப்படும்.

<a id="background"></a>
#### செயலற்ற ஐகான் பின்னணி

Home Assistant ஏற்கனவே செயலற்ற ஐகானுக்கான சொந்த பின்னணியை வரையுமானால் செருகுநிரல் அதை மாற்றாது.

பின்னணி இல்லாதபோது, Home Assistant இன் நிலையான செயலற்ற டைல் ஐகான் பாணியுடன் பொருந்தும் மங்கலான வட்டத்தைச் சேர்க்கும்.

முடக்க:

```json
{
  "faint_background_when_missing": false
}
```

ஒளிபுகாமையை மாற்ற:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### கன்சோல் மூலம் தற்காலிக கட்டமைப்பு

`haMdiOffFallback.configure()` இதே விதிகளைப் பயன்படுத்துகிறது.

வழங்கப்பட்ட `states` பொருள் தற்போதைய பட்டியலை முழுமையாக மாற்றும்:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

`states` விடுபட்டால் தற்போதைய பட்டியல் மாறாது:

```js
haMdiOffFallback.configure({
  debug: true
})
```

`configure()` மூலம் பயன்படுத்தப்படும் அமைப்புகள் பக்கம் மீண்டும் ஏற்றப்படும் வரை தற்போதைய தாவலில் மட்டும் செயல்படும். நிரந்தர கட்டமைப்புக்கு JSON கோப்பைப் பயன்படுத்தவும்.

<a id="reload-config"></a>
#### கட்டமைப்பை மீண்டும் ஏற்றுதல்

JSON கோப்பை மாற்றிய பிறகு பக்கத்தைப் புதுப்பிக்காமல் கட்டமைப்பை மீண்டும் ஏற்றலாம்:

```js
haMdiOffFallback.reloadConfig()
```

செயலில் உள்ள கட்டமைப்பைக் காண:

```js
haMdiOffFallback.getConfig()
```
