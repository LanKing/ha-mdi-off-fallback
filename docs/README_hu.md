> A Home Assistant tetszőleges MDI-ikonok használatát engedélyezi, de nem minden ikonhoz tartozik `-off` változat. Emiatt előfordulhat, hogy egy eszköz már ki van kapcsolva, miközben az ikonja továbbra is aktívnak látszik. Ez a bővítmény automatikusan MDI-stílusú áthúzást ad az inaktív entitásokhoz, ha nincs elérhető beépített kikapcsolt ikon.

# 🚫 MDI Off Fallback Home Assistanthoz

![A bővítmény működésének bemutatása](demo.jpg)

A bővítmény úgy készült, hogy a hozzáadott áthúzás a Home Assistant természetes részének tűnjön:
* a szabványos Tile-kártyákkal azok lecserélése nélkül működik, megőrizve az eredeti megjelenést, viselkedést, színeket, méreteket és interakciókat;
* a 🍄 `Mushroom Template Card` kártyát is támogatja; a kártyán meg kell adni egy `entity` értéket, hogy a bővítmény meg tudja határozni az állapotát;
* csak a már kirajzolt ikonokat módosítja, és csak akkor, ha nincs beépített `-off` változat;
* opcionálisan hozzáadhat egy halvány kör alakú hátteret, ha a natív háttér hiányzik;
* nem módosítja az entitások állapotát, és nem avatkozik az eszközök működésébe.
<a id="installation"></a>
## 📦 Telepítés

### 🛍 Telepítés HACS segítségével
ℹ️ [Mi az a HACS, és hogyan telepíthető?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_hu.md)

🚀 [Próbáld meg hozzáadni a tárolót ezzel a hivatkozással](https://my.home-assistant.io/redirect/hacs_repository/?owner=LanKing&repository=ha-mdi-off-fallback&category=plugin). Ha ezt a módot támogatja a HA-d és működik, kattints a megnyíló ablakban az **Add**, majd jobb alul a **Download** gombra. Ha minden sikerült, a telepítés kész, a hátralévő lépések kihagyhatók. Lépj közvetlenül ide: [Konfiguráció](#configuration).

#### 1. A tároló hozzáadása a HACS-hoz
Hónapokba telhet, mire a bővítmény bekerül az alapértelmezett HACS-katalógusba, ezért először kézzel add hozzá ezt a tárolót:
1. Nyisd meg a HACS-ot.
2. Nyisd meg a jobb felső sarokban lévő menüt, és válaszd az **Egyéni tárolók** (**Custom repositories**) lehetőséget.
3. Add hozzá ezt a tárolót:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Típusként válaszd az **Irányítópult** (**Dashboard**) lehetőséget, majd kattints a **Hozzáadás** (**Add**) gombra.

> Az **Egyéni tárolók** közé felvett tároló csak elérhetővé teszi a bővítményt a HACS-ban. Magát a bővítményt külön, a **Letöltés** (**Download**) gombbal kell telepíteni.

#### 2. A bővítmény telepítése
1. Keress rá a HACS-ban erre: `MDI Off Fallback`, majd nyisd meg.
2. Kattints a **Letöltés** (**Download**) gombra, és erősítsd meg a telepítést.
3. A letöltés befejezése után töltsd újra a Home Assistantot a böngésző gyorsítótárának törlésével.

<a id="manual-installation"></a>
### 🧑‍💻 Kézi telepítés (HACS nélkül)

1. Töltsd le a [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js) fájlt.
2. Másold a fájlt ide: `/config/www/ha-mdi-off-fallback.js`.
3. [Nyisd meg az Erőforrásokat](https://my.home-assistant.io/redirect/lovelace_resources/), vagy navigálj oda kézzel a Home Assistantban: **Beállítások → Irányítópultok → ⋮ → Erőforrások** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Kattints az **Erőforrás hozzáadása** (**Add resource**) gombra.
5. Add meg a URL mezőben: `/local/ha-mdi-off-fallback.js`.
6. Válaszd a **JavaScript-modul** (**JavaScript Module**) típust, majd kattints a **Létrehozás** (**Create**) gombra.
7. Töltsd újra a Home Assistantot a böngésző gyorsítótárának törlésével.

<a id="configuration"></a>
## 🔧 Konfiguráció

Az egyéni konfiguráció nem kötelező. Egyéni fájl nélkül a bővítmény a beépített értékeket használja:

<a id="default-configuration"></a>
### Alapértelmezett konfiguráció

Alapértelmezés szerint a következő állapotok számítanak inaktívnak:

| Entitástartomány | Inaktív állapotok |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

A következő beállítások is használatban vannak:

```json
{
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Egyéni konfiguráció

Saját szabályok megadásához hozd létre ezt a fájlt:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Példa:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

A konfiguráció a HACS által kezelt bővítményfájloktól elkülönítve tárolódik, ezért a bővítmény frissítései nem írják felül.

#### A `states` szakasz működése

Ha az egyéni konfiguráció tartalmaz `states` objektumot, az **teljesen lecseréli** a beépített listát. A bővítmény csak a kifejezetten felsorolt tartományokat és állapotokat veszi figyelembe.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

Ebben a példában az áthúzás csak a `light` és a `cover` esetén jelenik meg. A `switch`, `fan`, `climate` és más tartományok beépített szabályai nem lesznek használva.

A beépített listához való visszatéréshez távolítsd el a `states` elemet a konfigurációból, vagy töröld magát a konfigurációs fájlt.

A többi beállítás független: ha egy beállítás nincs megadva, annak beépített értéke marad érvényben.

<a id="background"></a>
#### Választható háttér a kör nélküli ikonokhoz

Egyes MDI ikonok vizuálisan a középponton kívül vannak. A perjel hozzáadása után kiegyensúlyozatlannak tűnhetnek, ha nincs kör alakú háttér a keretezéshez.

Ez zavarta a vizuális rendezettségemet, így a bővítmény tartalmaz egy opcionális beállítást, amely halvány kört rajzol az inaktív ikonok mögé, ha a Home Assistant nem biztosít ilyet.

Ez az opció alapértelmezés szerint le van tiltva, mert a körnek van jelentése a Home Assistant felületen: a Tile kártyán általában azt jelzi, hogy az ikonra kattintás a kártya többi részének kattintásától eltérő műveletet hajt végre. Egy kör hozzáadásával pusztán a vizuális igazítás érdekében megváltozik ez a vizuális szemantika.

Továbbra is engedélyezheti a hátteret, ha a kiegyensúlyozottabb megjelenést szeretné:

```json
{
  "faint_background_when_missing": true
}
```

Ha engedélyezve van, a beépülő modul csak ott adja hozzá a hátteret, ahol a Home Assistant még nem jeleníti meg.

Az átlátszatlanságát is beállíthatja:

```json
{
  "faint_background_opacity": 0.2
}
```

Válassza ki, hogy melyik viselkedés a fontosabb az irányítópult számára: a Home Assistant natív interakciós jelzéseinek megőrzése vagy a vágott ikonok vizuális középpontban tartása.

<a id="runtime-configuration"></a>
#### Ideiglenes konfiguráció a konzolból

A `haMdiOffFallback.configure()` ugyanazokat a szabályokat használja.

A megadott `states` objektum teljesen lecseréli az aktuális listát:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Ha a `states` nincs megadva, az aktuális lista változatlan marad:

```js
haMdiOffFallback.configure({
  debug: true
})
```

A `configure()` segítségével megadott beállítások csak az aktuális lapon maradnak érvényben az oldal újratöltéséig. Tartós konfigurációhoz használd a JSON-fájlt.

<a id="reload-config"></a>
#### A konfiguráció újratöltése

A JSON-fájl módosítása után a konfiguráció az oldal újratöltése nélkül is újraolvasható:

```js
haMdiOffFallback.reloadConfig()
```

Az aktív konfiguráció megtekintése:

```js
haMdiOffFallback.getConfig()
```
