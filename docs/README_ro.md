> Home Assistant permite folosirea oricăror pictograme MDI, însă nu toate au o variantă `-off`. Astfel, un dispozitiv poate fi deja oprit, iar pictograma lui să pară în continuare activă. Acest plugin adaugă automat o bară oblică în stil MDI entităților inactive atunci când nu există o pictogramă nativă pentru starea oprită.

# 🚫 MDI Off Fallback pentru Home Assistant

![Vizualizarea funcției pluginului](demo.jpg)

Pluginul este conceput astfel încât bara adăugată să pară o parte nativă a Home Assistant:
* funcționează cu cardurile standard Dală fără să le înlocuiască și păstrează aspectul, comportamentul, culorile, dimensiunile și interacțiunile implicite;
* modifică numai pictogramele deja randate și doar atunci când lipsește o variantă nativă `-off`;
* adaugă un fundal circular discret în stil Home Assistant atunci când fundalul implicit lipsește;
* nu modifică stările entităților și nu interferează cu funcționarea dispozitivelor.

<a id="installation"></a>
## 📦 Instalare

### 🛍 Instalare prin HACS
ℹ️ [Ce este HACS și cum se instalează?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_ro.md)

#### 1. Adăugarea acestui depozit în HACS
Poate dura luni până când pluginul va fi inclus în catalogul implicit HACS, așa că mai întâi adăugați manual acest depozit:
1. Deschideți HACS.
2. Deschideți meniul din dreapta sus și selectați **Depozite personalizate**.
3. Adăugați depozitul:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Selectați tipul **Tablou de bord** și apăsați **Adăugare**.

> Adăugarea depozitului în **Depozite personalizate** doar face pluginul disponibil în HACS. Pluginul se instalează separat prin butonul **Descărcare**.

#### 2. Instalarea pluginului
1. Căutați în HACS: `MDI Off Fallback` și deschideți rezultatul.
2. Apăsați **Descărcare** și confirmați instalarea.
3. După descărcare, reîmprospătați pagina Home Assistant și goliți memoria cache a browserului.

<a id="manual-installation"></a>
### 🧑‍💻 Instalare manuală (fără HACS)

1. Descărcați [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Copiați fișierul în `/config/www/ha-mdi-off-fallback.js`.
3. [Accesați Resurse](https://my.home-assistant.io/redirect/lovelace_resources/) sau deschideți-le manual în Home Assistant: **Setări → Tablouri de bord → ⋮ → Resurse** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Apăsați **Adăugare resursă** (**Add resource**).
5. Introduceți `/local/ha-mdi-off-fallback.js` în câmpul URL.
6. Selectați **Modul JavaScript** (**JavaScript Module**) și apăsați **Creare** (**Create**).
7. Reîmprospătați pagina Home Assistant și goliți memoria cache a browserului.

<a id="configuration"></a>
## 🔧 Configurare

Configurația personalizată este opțională. Fără un fișier personalizat, pluginul folosește valorile încorporate:

<a id="default-configuration"></a>
### Configurația implicită

În mod implicit, următoarele stări sunt considerate inactive:

| Domeniul entității | Stări inactive |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Sunt folosite și următoarele setări:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Configurație personalizată

Pentru a defini propriile reguli, creați fișierul:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Exemplu:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Configurația este stocată separat de fișierele pluginului administrate de HACS, astfel încât actualizările nu o suprascriu.

#### Cum funcționează secțiunea `states`

Dacă configurația personalizată conține un obiect `states`, acesta **înlocuiește complet** lista încorporată. Pluginul va lua în calcul numai domeniile și stările enumerate explicit.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

În acest exemplu, bara se aplică numai pentru `light` și `cover`. Regulile încorporate pentru `switch`, `fan`, `climate` și celelalte domenii nu vor fi utilizate.

Pentru a reveni la lista încorporată, eliminați `states` din configurație sau ștergeți fișierul de configurare.

Celelalte setări sunt independente: dacă o setare lipsește, rămâne activă valoarea sa încorporată.

<a id="background"></a>
#### Fundalul pictogramei inactive

Dacă Home Assistant afișează deja fundalul nativ al pictogramei inactive, pluginul nu îl modifică.

Dacă fundalul lipsește, pluginul adaugă un cerc discret care corespunde stilului pictogramelor Dală inactive standard din Home Assistant.

Dezactivare:

```json
{
  "faint_background_when_missing": false
}
```

Modificarea opacității:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Configurare temporară din consolă

`haMdiOffFallback.configure()` folosește aceleași reguli.

Un obiect `states` transmis înlocuiește complet lista curentă:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Dacă `states` este omis, lista curentă rămâne neschimbată:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Setările aplicate prin `configure()` rămân active numai în fila curentă până la reîncărcarea paginii. Pentru o configurație permanentă, folosiți fișierul JSON.

<a id="reload-config"></a>
#### Reîncărcarea configurației

După modificarea fișierului JSON, configurația poate fi reîncărcată fără reîmprospătarea paginii:

```js
haMdiOffFallback.reloadConfig()
```

Afișarea configurației active:

```js
haMdiOffFallback.getConfig()
```
