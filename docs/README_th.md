# 🚫 MDI Off Fallback สำหรับ Home Assistant

![ภาพแสดงการทำงานของปลั๊กอิน](demo.jpg)

ปลั๊กอินถูกออกแบบให้เส้นทับที่เพิ่มเข้ามาดูเหมือนเป็นส่วนหนึ่งของ Home Assistant:
* ทำงานร่วมกับการ์ด Tile มาตรฐานโดยไม่แทนที่การ์ดเดิม และคงรูปลักษณ์ พฤติกรรม สี ขนาด และการโต้ตอบตามปกติไว้;
* แก้ไขเฉพาะไอคอนที่เรนเดอร์แล้ว และเฉพาะเมื่อไม่มีรุ่น `-off` แบบมาตรฐาน;
* เพิ่มพื้นหลังวงกลมจาง ๆ ในสไตล์ Home Assistant เมื่อไม่มีพื้นหลังเดิม;
* ไม่เปลี่ยนสถานะของเอนทิตีและไม่รบกวนการทำงานของอุปกรณ์

<a id="installation"></a>
## 📦 การติดตั้ง

### 🛍 การติดตั้งผ่าน HACS
ℹ️ [HACS คืออะไรและติดตั้งอย่างไร?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_th.md)

#### 1. เพิ่มที่เก็บนี้ใน HACS
การเพิ่มปลั๊กอินนี้ลงในแค็ตตาล็อก HACS อย่างเป็นทางการอาจใช้เวลาหลายเดือน ดังนั้นก่อนอื่นให้เพิ่มที่เก็บนี้ใน HACS ด้วยตนเอง:
1. เปิด **HACS**
2. เปิดเมนูที่มุมขวาบน แล้วเลือก **ที่เก็บแบบกำหนดเอง** (**Custom repositories**)
3. เพิ่มที่เก็บนี้:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. เลือกประเภท **แดชบอร์ด** (**Dashboard**) แล้วคลิก **เพิ่ม** (**Add**)

> การเพิ่มที่เก็บใน **ที่เก็บแบบกำหนดเอง** เพียงทำให้ปลั๊กอินพร้อมใช้งานใน HACS เท่านั้น ตัวปลั๊กอินจะติดตั้งแยกต่างหากด้วยปุ่ม **ดาวน์โหลด** (**Download**)

#### 2. ติดตั้งปลั๊กอิน
1. ค้นหาใน HACS: `MDI Off Fallback` แล้วเปิด
2. คลิก **ดาวน์โหลด** (**Download**) และยืนยันการติดตั้ง
3. เมื่อดาวน์โหลดเสร็จ ให้โหลด Home Assistant ใหม่พร้อมล้างแคชของเบราว์เซอร์

<a id="manual-installation"></a>
### 🧑‍💻 การติดตั้งด้วยตนเอง (ไม่ใช้ HACS)

1. ดาวน์โหลด [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js)
2. คัดลอกไฟล์ไปที่ `/config/www/ha-mdi-off-fallback.js`
3. [ไปที่ทรัพยากร](https://my.home-assistant.io/redirect/lovelace_resources/) หรือเปิดด้วยตนเองใน Home Assistant: **การตั้งค่า → แดชบอร์ด → ⋮ → ทรัพยากร** *(**Settings → Dashboards → ⋮ → Resources**)*
4. คลิก **เพิ่มทรัพยากร** (**Add resource**)
5. ป้อน `/local/ha-mdi-off-fallback.js` ในช่อง URL
6. เลือก **โมดูล JavaScript** (**JavaScript Module**) แล้วคลิก **สร้าง** (**Create**)
7. โหลด Home Assistant ใหม่พร้อมล้างแคชของเบราว์เซอร์

<a id="configuration"></a>
## 🔧 การกำหนดค่า

ไม่จำเป็นต้องมีการกำหนดค่าแบบกำหนดเอง หากไม่มีไฟล์กำหนดค่า ปลั๊กอินจะใช้ค่าที่มีมาให้:

<a id="default-configuration"></a>
### การกำหนดค่าเริ่มต้น

โดยค่าเริ่มต้น สถานะต่อไปนี้ถือว่าไม่ทำงาน:

| โดเมนเอนทิตี | สถานะที่ไม่ทำงาน |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

ยังใช้ค่าต่อไปนี้ด้วย:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### การกำหนดค่าแบบกำหนดเอง

หากต้องการกำหนดกฎของคุณเอง ให้สร้างไฟล์นี้:

```text
/config/www/ha-mdi-off-fallback.config.json
```

ตัวอย่าง:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

ไฟล์กำหนดค่าจะถูกเก็บแยกจากไฟล์ปลั๊กอินที่ HACS จัดการ ดังนั้นการอัปเดตปลั๊กอินจะไม่เขียนทับไฟล์นี้

#### วิธีทำงานของส่วน `states`

เมื่อการกำหนดค่าแบบกำหนดเองมีออบเจ็กต์ `states` ออบเจ็กต์นี้จะ **แทนที่** รายการในตัวทั้งหมด ปลั๊กอินจะพิจารณาเฉพาะโดเมนและสถานะที่ระบุไว้อย่างชัดเจน

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

ในตัวอย่างนี้ เส้นทับจะใช้เฉพาะกับ `light` และ `cover` เท่านั้น กฎในตัวสำหรับ `switch`, `fan`, `climate` และโดเมนอื่น ๆ จะไม่ถูกใช้

หากต้องการกลับไปใช้รายการในตัว ให้ลบ `states` ออกจากการกำหนดค่า หรือลบไฟล์กำหนดค่า

การตั้งค่าอื่นเป็นอิสระต่อกัน: หากไม่ได้ระบุค่าใด ค่าที่มีมาให้จะยังคงใช้งานอยู่

<a id="background"></a>
#### พื้นหลังไอคอนที่ไม่ทำงาน

หาก Home Assistant แสดงพื้นหลังมาตรฐานของไอคอนที่ไม่ทำงานอยู่แล้ว ปลั๊กอินจะไม่เปลี่ยนแปลง

หากไม่มีพื้นหลังดังกล่าว ปลั๊กอินจะเพิ่มวงกลมจาง ๆ ที่ตรงกับสไตล์ไอคอน Tile ที่ไม่ทำงานมาตรฐานของ Home Assistant เพื่อให้การแสดงผลไอคอนสอดคล้องกัน

ปิดใช้งาน:

```json
{
  "faint_background_when_missing": false
}
```

เปลี่ยนความทึบ:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### การกำหนดค่าชั่วคราวผ่านคอนโซล

`haMdiOffFallback.configure()` ใช้กฎเดียวกัน

ออบเจ็กต์ `states` ที่ส่งเข้ามาจะแทนที่รายการปัจจุบันทั้งหมด:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

หากไม่ส่ง `states` รายการปัจจุบันจะไม่เปลี่ยนแปลง:

```js
haMdiOffFallback.configure({
  debug: true
})
```

การตั้งค่าที่ใช้ผ่าน `configure()` จะมีผลเฉพาะในแท็บปัจจุบันจนกว่าจะโหลดหน้าใหม่ ใช้ไฟล์ JSON สำหรับการกำหนดค่าแบบถาวร

<a id="reload-config"></a>
#### โหลดการกำหนดค่าใหม่

หลังจากแก้ไขไฟล์ JSON สามารถโหลดการกำหนดค่าใหม่โดยไม่ต้องโหลดหน้าใหม่:

```js
haMdiOffFallback.reloadConfig()
```

ดูการกำหนดค่าที่ใช้งานอยู่:

```js
haMdiOffFallback.getConfig()
```
