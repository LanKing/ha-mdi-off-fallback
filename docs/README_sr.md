> Home Assistant омогућава употребу произвољних MDI икона, али нема свака варијанту `-off`. Зато уређај може већ бити искључен, а икона и даље изгледати активно. Овај додатак аутоматски додаје прецртавање у MDI стилу неактивним ентитетима када не постоји уграђена икона за искључено стање.

# 🚫 MDI Off Fallback за Home Assistant

![Приказ рада додатка](demo.jpg)

Додатак је направљен тако да додато прецртавање изгледа као саставни део Home Assistant-а:
* ради са стандардним картицама Плочица без њихове замене и чува изглед, понашање, боје, величине и интеракције;
* подржава и `Mushroom Template Card`; картица мора имати подешен `entity` како би додатак могао да одреди њено стање;
* мења само већ исцртане иконе и само када не постоји уграђена варијанта `-off`;
* може опционо додати бледу кружну позадину када недостаје изворна позадина;
* не мења стања ентитета и не утиче на рад уређаја.
<a id="installation"></a>
## 📦 Инсталација

### 🛍 Инсталација преко HACS-а
ℹ️ [Шта је HACS и како се инсталира?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_sr.md)

#### 1. Додавање овог репозиторијума у HACS
Укључивање додатка у подразумевани HACS каталог може трајати месецима, па прво ручно додајте репозиторијум:
1. Отворите HACS.
2. Отворите мени у горњем десном углу и изаберите **Прилагођени репозиторијуми**.
3. Додајте репозиторијум:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Изаберите тип **Контролна табла** и кликните **Додај**.

> Додавање репозиторијума у **Прилагођене репозиторијуме** само чини додатак доступним у HACS-у. Сам додатак се инсталира засебно дугметом **Преузми**.

#### 2. Инсталирање додатка
1. У HACS претрази пронађите: `MDI Off Fallback` и отворите га.
2. Кликните **Преузми** и потврдите инсталацију.
3. По завршетку преузимања освежите страницу Home Assistant-а уз брисање кеша прегледача.

<a id="manual-installation"></a>
### 🧑‍💻 Ручна инсталација (без HACS-а)

1. Преузмите [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Копирајте датотеку у `/config/www/ha-mdi-off-fallback.js`.
3. [Идите на Ресурсе](https://my.home-assistant.io/redirect/lovelace_resources/) или их ручно отворите у Home Assistant-у: **Подешавања → Контролне табле → ⋮ → Ресурси** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Кликните **Додај ресурс** (**Add resource**).
5. У URL поље унесите `/local/ha-mdi-off-fallback.js`.
6. Изаберите **JavaScript модул** (**JavaScript Module**) и кликните **Креирај** (**Create**).
7. Освежите страницу Home Assistant-а уз брисање кеша прегледача.

<a id="configuration"></a>
## 🔧 Конфигурација

Прилагођена конфигурација није обавезна. Без прилагођене датотеке додатак користи уграђене вредности:

<a id="default-configuration"></a>
### Подразумевана конфигурација

Подразумевано се следећа стања сматрају неактивним:

| Домен ентитета | Неактивна стања |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Користе се и следећа подешавања:

```json
{
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Прилагођена конфигурација

За сопствена правила направите датотеку:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Пример:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Конфигурација се чува одвојено од датотека додатка којима управља HACS, па је ажурирања неће преписати.

#### Како ради одељак `states`

Ако прилагођена конфигурација садржи објекат `states`, он **у потпуности замењује** уграђену листу. Додатак ће узимати у обзир само изричито наведене домене и стања.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

У овом примеру прецртавање се примењује само на `light` и `cover`. Уграђена правила за `switch`, `fan`, `climate` и остале домене неће се користити.

За повратак на уграђену листу уклоните `states` из конфигурације или избришите конфигурациону датотеку.

Остала подешавања су независна: ако подешавање није наведено, користи се његова уграђена вредност.

<a id="background"></a>
#### Опциона позадина за иконе без круга

Неке ЗКСКМДИККСЗ иконе су визуелно удаљене од центра. Након што се дода коса црта, могу изгледати неуравнотежено када нема кружне позадине која би их уоквирила.

Ово је сметало мом осећају за визуелни поредак, тако да додатак укључује опционо подешавање које црта слаб круг иза неактивних икона када га ЗКСКХОМЕАССИСТАНТККСЗ не пружа.

Ова опција је подразумевано онемогућена зато што круг има значење у интерфејсу ЗКСКХОМЕАССИСТАНТККСЗ: на ЗКСКТИЛЕККСЗ картици, обично означава да се кликом на икону обавља засебна радња од клика на остатак картице. Додавање круга искључиво ради визуелног поравнања стога мења ту визуелну семантику.

Још увек можете да омогућите позадину ако више волите уравнотеженији изглед:

```json
{
  "faint_background_when_missing": true
}
```

Када је омогућен, додатак додаје само позадину где је ЗКСКХОМЕАССИСТАНТККСЗ већ не приказује.

Такође можете подесити његову непрозирност:

```json
{
  "faint_background_opacity": 0.2
}
```

Изаберите које је понашање важније за вашу контролну таблу: очување изворних знакова интеракције ЗКСКХОМЕАССИСТАНТККСЗ или задржавање исечених икона визуелно центрираних.

<a id="runtime-configuration"></a>
#### Привремена конфигурација преко конзоле

`haMdiOffFallback.configure()` користи иста правила.

Прослеђени објекат `states` у потпуности замењује тренутну листу:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Ако `states` није прослеђен, тренутна листа остаје непромењена:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Подешавања примењена преко `configure()` важе само у тренутној картици до поновног учитавања странице. За трајну конфигурацију користите JSON датотеку.

<a id="reload-config"></a>
#### Поновно учитавање конфигурације

Након измене JSON датотеке конфигурацију можете поново учитати без освежавања странице:

```js
haMdiOffFallback.reloadConfig()
```

Приказ активне конфигурације:

```js
haMdiOffFallback.getConfig()
```
