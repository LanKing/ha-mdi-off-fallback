> Home Assistant lar deg bruke vilkårlige MDI-ikoner, men ikke alle har en `-off`-variant. Dermed kan en enhet allerede være slått av mens ikonet fortsatt ser aktivt ut. Dette programtillegget legger automatisk til en skråstrek i MDI-stil for inaktive entiteter når det ikke finnes et innebygd av-ikon.

# 🚫 MDI Off Fallback for Home Assistant

![Visualisering av programtilleggets funksjon](demo.jpg)

Programtillegget er laget slik at den ekstra skråstreken ser ut som en innebygd del av Home Assistant:
* fungerer med standard Flis-kort uten å erstatte dem, og beholder standard utseende, oppførsel, farger, størrelser og interaksjoner;
* støtter også `Mushroom Template Card`; kortet må ha en `entity` angitt slik at programtillegget kan fastslå tilstanden;
* endrer bare ikoner som allerede er tegnet, og bare når det ikke finnes en innebygd `-off`-variant;
* kan eventuelt legge til en svak sirkulær bakgrunn når den opprinnelige bakgrunnen mangler;
* endrer ikke entitetstilstander og påvirker ikke enhetenes funksjon.
<a id="installation"></a>
## 📦 Installasjon

### 🛍 Installasjon via HACS
ℹ️ [Hva er HACS, og hvordan installerer jeg det?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_nb.md)

#### 1. Legg dette repositoriet til i HACS
Det kan ta flere måneder før programtillegget blir lagt til i den offisielle HACS-katalogen, så først må du legge repositoriet til manuelt:
1. Åpne HACS.
2. Åpne menyen øverst til høyre og velg **Egendefinerte repositorier**.
3. Legg til repositoriet:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Velg typen **Dashbord** og trykk **Legg til**.

> Når du legger til repositoriet under **Egendefinerte repositorier**, blir programtillegget bare tilgjengelig i HACS. Selve programtillegget installeres separat med knappen **Last ned**.

#### 2. Installer programtillegget
1. Søk i HACS etter: `MDI Off Fallback`, og åpne det.
2. Trykk **Last ned** og bekreft installasjonen.
3. Når nedlastingen er fullført, oppdater Home Assistant-siden og tøm nettleserbufferen.

<a id="manual-installation"></a>
### 🧑‍💻 Manuell installasjon (uten HACS)

1. Last ned [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Kopier filen til `/config/www/ha-mdi-off-fallback.js`.
3. [Gå til Ressurser](https://my.home-assistant.io/redirect/lovelace_resources/) eller åpne dem manuelt i Home Assistant: **Innstillinger → Dashbord → ⋮ → Ressurser** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Trykk **Legg til ressurs** (**Add resource**).
5. Skriv inn `/local/ha-mdi-off-fallback.js` i URL-feltet.
6. Velg typen **JavaScript-modul** (**JavaScript Module**) og trykk **Opprett** (**Create**).
7. Oppdater Home Assistant-siden og tøm nettleserbufferen.

<a id="configuration"></a>
## 🔧 Konfigurasjon

Egendefinert konfigurasjon er valgfri. Uten en egendefinert fil bruker programtillegget de innebygde verdiene:

<a id="default-configuration"></a>
### Standardkonfigurasjon

Som standard regnes følgende tilstander som inaktive:

| Entitetsdomene | Inaktive tilstander |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Følgende innstillinger brukes også:

```json
{
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Egendefinert konfigurasjon

Opprett denne filen for å definere egne regler:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Eksempel:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Konfigurasjonen lagres separat fra programtilleggsfilene som administreres av HACS, så oppdateringer overskriver den ikke.

#### Slik fungerer `states`-delen

Hvis den egendefinerte konfigurasjonen inneholder et `states`-objekt, **erstatter det hele** den innebygde listen. Programtillegget tar da bare hensyn til domenene og tilstandene som er oppført eksplisitt.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

I dette eksemplet brukes skråstreken bare på `light` og `cover`. De innebygde reglene for `switch`, `fan`, `climate` og andre domener brukes ikke.

Fjern `states` fra konfigurasjonen eller slett konfigurasjonsfilen for å gå tilbake til den innebygde listen.

De andre innstillingene er uavhengige: Hvis en innstilling ikke er oppgitt, brukes den innebygde verdien.

<a id="background"></a>
#### Valgfri bakgrunn for ikoner uten sirkel

Noen MDI-ikoner er visuelt utenfor midten. Etter at en skråstrek er lagt til, kan de se ubalanserte ut når det ikke er noen sirkulær bakgrunn for å ramme dem inn.

Dette plaget min følelse av visuell rekkefølge, så plugin-en inkluderer en valgfri innstilling som tegner en svak sirkel bak inaktive ikoner når Home Assistant ikke gir en.

Dette alternativet er deaktivert som standard fordi sirkelen har en betydning i Home Assistant-grensesnittet: på et Tile-kort indikerer det normalt at å klikke på ikonet utfører en annen handling fra å klikke på resten av kortet. Å legge til en sirkel utelukkende for visuell justering endrer derfor den visuelle semantikken.

Du kan fortsatt aktivere bakgrunnen hvis du foretrekker det mer balanserte utseendet:

```json
{
  "faint_background_when_missing": true
}
```

Når den er aktivert, legger plugin-en bare til bakgrunnen der Home Assistant ikke allerede gjengir en.

Du kan også justere opasiteten:

```json
{
  "faint_background_opacity": 0.2
}
```

Velg hvilken oppførsel som er viktigst for dashbordet ditt: bevar Home Assistants opprinnelige interaksjonssignaler eller hold ikonene med skråstilte visuelt sentrert.

<a id="runtime-configuration"></a>
#### Midlertidig konfigurasjon via konsollen

`haMdiOffFallback.configure()` følger de samme reglene.

Et angitt `states`-objekt erstatter hele den gjeldende listen:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Hvis `states` utelates, forblir den gjeldende listen uendret:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Innstillinger angitt med `configure()` gjelder bare i den gjeldende fanen frem til siden lastes inn på nytt. Bruk JSON-filen for en permanent konfigurasjon.

<a id="reload-config"></a>
#### Last inn konfigurasjonen på nytt

Etter at JSON-filen er endret, kan konfigurasjonen lastes inn på nytt uten å oppdatere siden:

```js
haMdiOffFallback.reloadConfig()
```

Vis den aktive konfigurasjonen:

```js
haMdiOffFallback.getConfig()
```
