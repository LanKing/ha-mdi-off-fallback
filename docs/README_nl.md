> Home Assistant ondersteunt willekeurige MDI-pictogrammen, maar niet elk pictogram heeft een `-off`-variant. Daardoor kan een apparaat al uitgeschakeld zijn terwijl het pictogram nog actief lijkt. Deze plug-in voegt automatisch een schuine streep in MDI-stijl toe aan inactieve entiteiten wanneer geen ingebouwd uit-pictogram beschikbaar is.

# 🚫 MDI Off Fallback voor Home Assistant

![Visualisatie van de werking van de plug-in](demo.jpg)

De plug-in is zo ontworpen dat de toegevoegde schuine streep eruitziet als een standaardonderdeel van Home Assistant:
* werkt met standaard Tegel-kaarten zonder ze te vervangen en behoudt hun standaarduiterlijk, gedrag, kleuren, afmetingen en interacties;
* wijzigt alleen reeds weergegeven pictogrammen en alleen wanneer geen ingebouwde `-off`-variant bestaat;
* voegt een lichte ronde achtergrond in Home Assistant-stijl toe wanneer de standaardachtergrond ontbreekt;
* wijzigt geen entiteitsstatussen en grijpt niet in op de werking van apparaten.

<a id="installation"></a>
## 📦 Installatie

### 🛍 Installatie via HACS
ℹ️ [Wat is HACS en hoe installeer ik het?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_nl.md)

#### 1. Deze repository aan HACS toevoegen
Het kan maanden duren voordat de plug-in aan de standaard HACS-catalogus wordt toegevoegd. Voeg daarom eerst deze repository handmatig toe:
1. Open HACS.
2. Open het menu rechtsboven en kies **Aangepaste repositories**.
3. Voeg de repository toe:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Kies het type **Dashboard** en klik op **Toevoegen**.

> Het toevoegen van de repository aan **Aangepaste repositories** maakt de plug-in alleen beschikbaar in HACS. De plug-in zelf wordt afzonderlijk geïnstalleerd met de knop **Downloaden**.

#### 2. De plug-in installeren
1. Zoek in HACS naar: `MDI Off Fallback` en open deze.
2. Klik op **Downloaden** en bevestig de installatie.
3. Vernieuw na het downloaden de Home Assistant-pagina en wis de browsercache.

<a id="manual-installation"></a>
### 🧑‍💻 Handmatige installatie (zonder HACS)

1. Download [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Kopieer het bestand naar `/config/www/ha-mdi-off-fallback.js`.
3. [Ga naar Bronnen](https://my.home-assistant.io/redirect/lovelace_resources/) of open deze handmatig in Home Assistant: **Instellingen → Dashboards → ⋮ → Bronnen** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Klik op **Bron toevoegen** (**Add resource**).
5. Voer `/local/ha-mdi-off-fallback.js` in het URL-veld in.
6. Kies **JavaScript-module** (**JavaScript Module**) en klik op **Maken** (**Create**).
7. Vernieuw de Home Assistant-pagina en wis de browsercache.

<a id="configuration"></a>
## 🔧 Configuratie

Een aangepaste configuratie is optioneel. Zonder aangepast bestand gebruikt de plug-in de ingebouwde waarden:

<a id="default-configuration"></a>
### Standaardconfiguratie

Standaard worden de volgende statussen als inactief beschouwd:

| Entiteitsdomein | Inactieve statussen |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Ook worden de volgende instellingen gebruikt:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Aangepaste configuratie

Maak het volgende bestand om eigen regels in te stellen:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Voorbeeld:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

De configuratie wordt apart opgeslagen van de door HACS beheerde plug-inbestanden, zodat updates deze niet overschrijven.

#### Werking van de sectie `states`

Als de aangepaste configuratie een object `states` bevat, **vervangt dit de ingebouwde lijst volledig**. De plug-in houdt dan alleen rekening met expliciet vermelde domeinen en statussen.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

In dit voorbeeld wordt de schuine streep alleen toegepast op `light` en `cover`. De ingebouwde regels voor `switch`, `fan`, `climate` en overige domeinen worden niet gebruikt.

Verwijder `states` uit de configuratie of verwijder het configuratiebestand om terug te keren naar de ingebouwde lijst.

De overige instellingen zijn onafhankelijk: als een instelling ontbreekt, blijft de ingebouwde waarde gelden.

<a id="background"></a>
#### Achtergrond van een inactief pictogram

Als Home Assistant al een standaardachtergrond voor het inactieve pictogram tekent, laat de plug-in deze ongewijzigd.

Als die achtergrond ontbreekt, voegt de plug-in een lichte cirkel toe die overeenkomt met de stijl van standaard inactieve Tegel-pictogrammen in Home Assistant.

Uitschakelen:

```json
{
  "faint_background_when_missing": false
}
```

Doorzichtigheid wijzigen:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Tijdelijke configuratie via de console

`haMdiOffFallback.configure()` gebruikt dezelfde regels.

Een opgegeven `states`-object vervangt de huidige lijst volledig:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Als `states` wordt weggelaten, blijft de huidige lijst ongewijzigd:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Instellingen via `configure()` gelden alleen in het huidige tabblad totdat de pagina opnieuw wordt geladen. Gebruik het JSON-bestand voor permanente configuratie.

<a id="reload-config"></a>
#### Configuratie opnieuw laden

Na het wijzigen van het JSON-bestand kan de configuratie opnieuw worden geladen zonder de pagina te vernieuwen:

```js
haMdiOffFallback.reloadConfig()
```

Actieve configuratie bekijken:

```js
haMdiOffFallback.getConfig()
```
