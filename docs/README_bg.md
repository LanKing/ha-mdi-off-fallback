> Home Assistant позволява използването на произволни MDI икони, но не всяка икона има вариант `-off`. В резултат устройството може вече да е изключено, докато иконата все още изглежда активна. Този плъгин автоматично добавя диагонална черта в стил MDI към неактивните обекти, когато няма вградена икона за изключено състояние.

# 🚫 MDI Off Fallback за Home Assistant

![Визуализация на работата на плъгина](demo.jpg)

Плъгинът е реализиран така, че добавената черта да изглежда като естествена част от Home Assistant:
* работи със стандартните Tile карти без да ги заменя и запазва техния оригинален вид, поведение, цветове, размери и взаимодействия;
* променя само вече изобразените икони и само когато няма вграден вариант `-off`;
* добавя блед кръгъл фон в стила на Home Assistant, ако стандартният фон липсва;
* не променя състоянията на обектите и не се намесва в работата на устройствата.

<a id="installation"></a>
## 📦 Инсталиране

### 🛍 Инсталиране чрез HACS
ℹ️ [Какво е HACS и как се инсталира?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_bg.md)

#### 1. Добавяне на това хранилище в HACS
Официалното добавяне на плъгина към HACS може да отнеме месеци, затова първо трябва ръчно да добавите хранилището в HACS:
1. Отворете HACS.
2. Отворете менюто в горния десен ъгъл и изберете **Персонализирани хранилища** (**Custom repositories**).
3. Добавете хранилището:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```

4. Изберете тип **Табло** (**Dashboard**) и натиснете **Добавяне** (**Add**).

> Добавянето на хранилището в **Персонализирани хранилища** само прави плъгина достъпен в HACS. Самият плъгин се инсталира отделно чрез бутона **Изтегляне** (**Download**).

#### 2. Инсталиране на плъгина
1. Потърсете в HACS: `MDI Off Fallback` и го отворете.
2. Натиснете **Изтегляне** (**Download**) и потвърдете инсталирането.
3. След приключване на изтеглянето презаредете Home Assistant с изчистване на кеша на браузъра.

<a id="manual-installation"></a>
### 🧑‍💻 Ръчно инсталиране (без HACS)

1. Изтеглете [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Копирайте файла в `/config/www/ha-mdi-off-fallback.js`.
3. [Отидете в Ресурси](https://my.home-assistant.io/redirect/lovelace_resources/) или ги отворете ръчно в Home Assistant: **Настройки → Табла → ⋮ → Ресурси** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Натиснете **Добавяне на ресурс** (**Add resource**).
5. Въведете `/local/ha-mdi-off-fallback.js` в полето URL.
6. Изберете **JavaScript модул** (**JavaScript Module**) и натиснете **Създаване** (**Create**).
7. Презаредете Home Assistant с изчистване на кеша на браузъра.

<a id="configuration"></a>
## 🔧 Настройване

Потребителската конфигурация е по избор. Без потребителски файл плъгинът използва вградените стойности:

<a id="default-configuration"></a>
### Конфигурация по подразбиране

По подразбиране следните състояния се считат за неактивни:

| Домейн на обекта | Неактивни състояния |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Използват се и следните параметри:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Потребителска конфигурация

За да зададете собствени правила, създайте файла:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Пример:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Конфигурацията се съхранява отделно от файловете на плъгина, управлявани от HACS, така че актуализациите на плъгина няма да я презапишат.

#### Особености на секцията `states`

Ако потребителската конфигурация съдържа обект `states`, той **напълно заменя** вградения списък. Плъгинът ще отчита само изрично посочените домейни и състояния.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

В този пример чертата ще се прилага само към `light` и `cover`. Вградените правила за `switch`, `fan`, `climate` и останалите домейни няма да се използват.

За да се върнете към вградения списък, премахнете `states` от конфигурацията или изтрийте самия конфигурационен файл.

Останалите параметри са независими: ако даден параметър не е зададен, се запазва неговата вградена стойност.

<a id="background"></a>
#### Фон на неактивната икона

Ако Home Assistant вече изобразява стандартния фон на неактивната икона, плъгинът не го променя.

Ако такъв фон липсва, плъгинът добавя блед кръг, съответстващ на оформлението на стандартната неактивна Tile икона в Home Assistant.

Изключване:

```json
{
  "faint_background_when_missing": false
}
```

Промяна на прозрачността:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Временна настройка чрез конзолата

`haMdiOffFallback.configure()` използва същата логика.

Подаденият обект `states` напълно заменя текущия списък:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Ако `states` не е подаден, текущият списък не се променя:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Настройките, зададени чрез `configure()`, действат само в текущия раздел до презареждане на страницата. За постоянна конфигурация използвайте JSON файла.

<a id="reload-config"></a>
#### Презареждане на конфигурацията

След промяна на JSON файла конфигурацията може да се презареди без презареждане на страницата:

```js
haMdiOffFallback.reloadConfig()
```

Преглед на активната конфигурация:

```js
haMdiOffFallback.getConfig()
```
