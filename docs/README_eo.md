> Home Assistant permesas uzi ajnajn MDI-piktogramojn, sed ne ĉiu piktogramo havas varianton `-off`. Sekve aparato povas jam esti malŝaltita dum ĝia piktogramo ankoraŭ aspektas aktiva. Ĉi tiu kromprogramo aŭtomate aldonas oblikvan strekon laŭ la stilo de MDI al neaktivaj entoj kiam mankas denaska malŝaltita piktogramo.

# 🚫 MDI Off Fallback por Home Assistant

![Bildigo de la funkcio de la kromprogramo](demo.jpg)

La kromprogramo estas farita tiel, ke la aldonita streko aspektu kiel denaska parto de Home Assistant:
* funkcias kun normaj Tile-kartoj sen anstataŭigi ilin kaj konservas ilian denaskan aspekton, konduton, kolorojn, grandecojn kaj interagojn;
* ŝanĝas nur jam bildigitajn piktogramojn kaj nur kiam ne ekzistas denaska varianto `-off`;
* aldonas palan rondan fonon laŭ la stilo de Home Assistant kiam la denaska fono mankas;
* ne ŝanĝas la statojn de entoj kaj ne intervenas en la funkciadon de aparatoj.

<a id="installation"></a>
## 📦 Instalado

### 🛍 Instalado per HACS
ℹ️ [Kio estas HACS kaj kiel instali ĝin?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_eo.md)

#### 1. Aldonu ĉi tiun deponejon al HACS
Povas pasi monatoj antaŭ ol la kromprogramo estos oficiale aldonita al HACS, do unue aldonu la deponejon permane:
1. Malfermu HACS.
2. Malfermu la menuon supre dekstre kaj elektu **Propraj deponejoj** (**Custom repositories**).
3. Aldonu la deponejon:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```

4. Elektu la tipon **Panelo** (**Dashboard**) kaj alklaku **Aldoni** (**Add**).

> Aldoni la deponejon al **Propraj deponejoj** nur faras la kromprogramon disponebla en HACS. La kromprogramo mem estas instalata aparte per la butono **Elŝuti** (**Download**).

#### 2. Instalu la kromprogramon
1. Serĉu en HACS: `MDI Off Fallback` kaj malfermu ĝin.
2. Alklaku **Elŝuti** (**Download**) kaj konfirmu la instaladon.
3. Post la elŝuto, reŝargu Home Assistant kun malplenigita retumila kaŝmemoro.

<a id="manual-installation"></a>
### 🧑‍💻 Mana instalado (sen HACS)

1. Elŝutu [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Kopiu la dosieron al `/config/www/ha-mdi-off-fallback.js`.
3. [Iru al Rimedoj](https://my.home-assistant.io/redirect/lovelace_resources/) aŭ malfermu ilin permane en Home Assistant: **Agordoj → Paneloj → ⋮ → Rimedoj** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Alklaku **Aldoni rimedon** (**Add resource**).
5. Enigu `/local/ha-mdi-off-fallback.js` en la URL-kampon.
6. Elektu **JavaScript-modulo** (**JavaScript Module**) kaj alklaku **Krei** (**Create**).
7. Reŝargu Home Assistant kun malplenigita retumila kaŝmemoro.

<a id="configuration"></a>
## 🔧 Agordo

Propra agordo estas nedeviga. Sen propra dosiero la kromprogramo uzas la enkonstruitajn valorojn:

<a id="default-configuration"></a>
### Defaŭlta agordo

Defaŭlte la jenaj statoj estas konsiderataj neaktivaj:

| Enta domajno | Neaktivaj statoj |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Ankaŭ estas uzataj la jenaj agordoj:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Propra agordo

Por difini viajn proprajn regulojn, kreu la dosieron:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Ekzemplo:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

La agordo estas konservata aparte de la kromprogramaj dosieroj administrataj de HACS, do ĝisdatigoj ne superskribos ĝin.

#### Kiel funkcias la sekcio `states`

Se la propra agordo enhavas objekton `states`, ĝi **tute anstataŭigas** la enkonstruitan liston. La kromprogramo konsideros nur la eksplicite listigitajn domajnojn kaj statojn.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

En ĉi tiu ekzemplo la streko aplikiĝos nur al `light` kaj `cover`. La enkonstruitaj reguloj por `switch`, `fan`, `climate` kaj aliaj domajnoj ne estos uzataj.

Por reveni al la enkonstruita listo, forigu `states` el la agordo aŭ forigu la agordan dosieron.

La aliaj agordoj estas sendependaj: se agordo ne estas specifita, ĝia enkonstruita valoro restas valida.

<a id="background"></a>
#### Fono de neaktiva piktogramo

Se Home Assistant jam montras la denaskan fonon de neaktiva piktogramo, la kromprogramo ne ŝanĝas ĝin.

Se la fono mankas, la kromprogramo aldonas palan cirklon kongruan kun la norma stilo de neaktiva Tile-piktogramo en Home Assistant.

Malŝalti:

```json
{
  "faint_background_when_missing": false
}
```

Ŝanĝi travideblecon:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Provizora agordo per la konzolo

`haMdiOffFallback.configure()` uzas la saman logikon.

Donita objekto `states` tute anstataŭigas la aktualan liston:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Se `states` ne estas donita, la aktuala listo ne ŝanĝiĝas:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Agordoj aplikitaj per `configure()` restas aktivaj nur en la aktuala langeto ĝis reŝargo de la paĝo. Por konstanta agordo uzu la JSON-dosieron.

<a id="reload-config"></a>
#### Reŝargi la agordon

Post redakto de la JSON-dosiero, la agordo povas esti reŝargita sen reŝargi la paĝon:

```js
haMdiOffFallback.reloadConfig()
```

Vidi la aktivan agordon:

```js
haMdiOffFallback.getConfig()
```
