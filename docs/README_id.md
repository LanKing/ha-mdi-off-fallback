> Home Assistant memungkinkan penggunaan ikon MDI apa pun, tetapi tidak semua ikon memiliki varian `-off`. Akibatnya, perangkat dapat sudah mati sementara ikonnya masih terlihat aktif. Plugin ini secara otomatis menambahkan garis miring bergaya MDI pada entitas yang tidak aktif ketika ikon mati bawaan tidak tersedia.

# 🚫 MDI Off Fallback untuk Home Assistant

![Visualisasi fungsi plugin](demo.jpg)

Plugin dirancang agar garis yang ditambahkan terlihat seperti bagian bawaan Home Assistant:
* bekerja dengan kartu Tile standar tanpa menggantinya serta mempertahankan tampilan, perilaku, warna, ukuran, dan interaksi bawaan;
* hanya mengubah ikon yang sudah dirender dan hanya jika varian `-off` bawaan tidak tersedia;
* menambahkan latar belakang lingkaran samar bergaya Home Assistant ketika latar belakang bawaan tidak ada;
* tidak mengubah status entitas dan tidak mengganggu pengoperasian perangkat.

<a id="installation"></a>
## 📦 Instalasi

### 🛍 Instalasi melalui HACS
ℹ️ [Apa itu HACS dan bagaimana cara memasangnya?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_id.md)

#### 1. Menambahkan repositori ini ke HACS
Diperlukan waktu berbulan-bulan sebelum plugin ditambahkan ke katalog HACS bawaan, jadi tambahkan repositori ini secara manual terlebih dahulu:
1. Buka HACS.
2. Buka menu di sudut kanan atas dan pilih **Repositori khusus** (**Custom repositories**).
3. Tambahkan repositori berikut:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Pilih **Dasbor** (**Dashboard**) sebagai jenis, lalu tekan **Tambahkan** (**Add**).

> Menambahkan repositori ke **Repositori khusus** hanya membuat plugin tersedia di HACS. Plugin itu sendiri dipasang secara terpisah menggunakan tombol **Unduh** (**Download**).

#### 2. Memasang plugin
1. Cari di HACS: `MDI Off Fallback`, lalu buka.
2. Tekan **Unduh** (**Download**) dan konfirmasikan pemasangan.
3. Setelah pengunduhan selesai, muat ulang Home Assistant sambil membersihkan cache browser.

<a id="manual-installation"></a>
### 🧑‍💻 Instalasi manual (tanpa HACS)

1. Unduh [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Salin berkas ke `/config/www/ha-mdi-off-fallback.js`.
3. [Buka Sumber daya](https://my.home-assistant.io/redirect/lovelace_resources/) atau buka secara manual di Home Assistant: **Pengaturan → Dasbor → ⋮ → Sumber daya** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Tekan **Tambahkan sumber daya** (**Add resource**).
5. Masukkan `/local/ha-mdi-off-fallback.js` pada kolom URL.
6. Pilih **Modul JavaScript** (**JavaScript Module**) lalu tekan **Buat** (**Create**).
7. Muat ulang Home Assistant sambil membersihkan cache browser.

<a id="configuration"></a>
## 🔧 Konfigurasi

Konfigurasi khusus bersifat opsional. Tanpa berkas khusus, plugin menggunakan nilai bawaannya:

<a id="default-configuration"></a>
### Konfigurasi bawaan

Secara bawaan, status berikut dianggap tidak aktif:

| Domain entitas | Status tidak aktif |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Pengaturan berikut juga digunakan:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Konfigurasi khusus

Untuk menentukan aturan sendiri, buat berkas berikut:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Contoh:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Konfigurasi disimpan terpisah dari berkas plugin yang dikelola HACS, sehingga pembaruan plugin tidak akan menimpanya.

#### Cara kerja bagian `states`

Jika konfigurasi khusus berisi objek `states`, objek tersebut **sepenuhnya menggantikan** daftar bawaan. Plugin hanya mempertimbangkan domain dan status yang dicantumkan secara eksplisit.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

Pada contoh ini, garis hanya diterapkan pada `light` dan `cover`. Aturan bawaan untuk `switch`, `fan`, `climate`, dan domain lainnya tidak digunakan.

Untuk kembali ke daftar bawaan, hapus `states` dari konfigurasi atau hapus berkas konfigurasi.

Pengaturan lain bersifat independen: jika suatu pengaturan tidak disebutkan, nilai bawaannya tetap digunakan.

<a id="background"></a>
#### Latar belakang ikon tidak aktif

Jika Home Assistant sudah menampilkan latar belakang bawaan ikon tidak aktif, plugin membiarkannya tetap seperti itu.

Jika latar belakang tersebut tidak ada, plugin menambahkan lingkaran samar yang sesuai dengan gaya ikon Tile tidak aktif standar Home Assistant.

Untuk menonaktifkan:

```json
{
  "faint_background_when_missing": false
}
```

Untuk mengubah opasitas:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Konfigurasi sementara melalui konsol

`haMdiOffFallback.configure()` menggunakan aturan yang sama.

Objek `states` yang diberikan sepenuhnya menggantikan daftar saat ini:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Jika `states` tidak diberikan, daftar saat ini tidak berubah:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Pengaturan melalui `configure()` hanya aktif di tab saat ini hingga halaman dimuat ulang. Gunakan berkas JSON untuk konfigurasi permanen.

<a id="reload-config"></a>
#### Memuat ulang konfigurasi

Setelah mengedit berkas JSON, konfigurasi dapat dimuat ulang tanpa memuat ulang halaman:

```js
haMdiOffFallback.reloadConfig()
```

Lihat konfigurasi aktif:

```js
haMdiOffFallback.getConfig()
```
