> Home Assistant omogućava korišćenje proizvoljnih MDI ikona, ali nema svaka varijantu `-off`. Zato uređaj može već biti isključen, a ikona i dalje izgledati aktivno. Ovaj dodatak automatski dodaje precrtavanje u MDI stilu neaktivnim entitetima kada ne postoji ugrađena ikona za isključeno stanje.

# 🚫 MDI Off Fallback za Home Assistant

![Prikaz rada dodatka](demo.jpg)

Dodatak je napravljen tako da dodato precrtavanje izgleda kao sastavni deo Home Assistant-a:
* radi sa standardnim karticama Pločica bez njihove zamene i čuva izgled, ponašanje, boje, veličine i interakcije;
* menja samo već iscrtane ikone i samo kada ne postoji ugrađena varijanta `-off`;
* dodaje bledu kružnu pozadinu u stilu Home Assistant-a kada ugrađena pozadina nedostaje;
* ne menja stanja entiteta i ne utiče na rad uređaja.

<a id="installation"></a>
## 📦 Instalacija

### 🛍 Instalacija preko HACS-a
ℹ️ [Šta je HACS i kako se instalira?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_sr-Latn.md)

#### 1. Dodavanje ovog repozitorijuma u HACS
Uključivanje dodatka u podrazumevani HACS katalog može trajati mesecima, pa prvo ručno dodajte repozitorijum:
1. Otvorite HACS.
2. Otvorite meni u gornjem desnom uglu i izaberite **Prilagođeni repozitorijumi**.
3. Dodajte repozitorijum:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Izaberite tip **Kontrolna tabla** i kliknite **Dodaj**.

> Dodavanje repozitorijuma u **Prilagođene repozitorijume** samo čini dodatak dostupnim u HACS-u. Sam dodatak se instalira zasebno dugmetom **Preuzmi**.

#### 2. Instaliranje dodatka
1. U HACS pretrazi pronađite: `MDI Off Fallback` i otvorite ga.
2. Kliknite **Preuzmi** i potvrdite instalaciju.
3. Po završetku preuzimanja osvežite stranicu Home Assistant-a uz brisanje keša pregledača.

<a id="manual-installation"></a>
### 🧑‍💻 Ručna instalacija (bez HACS-a)

1. Preuzmite [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Kopirajte datoteku u `/config/www/ha-mdi-off-fallback.js`.
3. [Idite na Resurse](https://my.home-assistant.io/redirect/lovelace_resources/) ili ih ručno otvorite u Home Assistant-u: **Podešavanja → Kontrolne table → ⋮ → Resursi** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Kliknite **Dodaj resurs** (**Add resource**).
5. U URL polje unesite `/local/ha-mdi-off-fallback.js`.
6. Izaberite **JavaScript modul** (**JavaScript Module**) i kliknite **Kreiraj** (**Create**).
7. Osvežite stranicu Home Assistant-a uz brisanje keša pregledača.

<a id="configuration"></a>
## 🔧 Konfiguracija

Prilagođena konfiguracija nije obavezna. Bez prilagođene datoteke dodatak koristi ugrađene vrednosti:

<a id="default-configuration"></a>
### Podrazumevana konfiguracija

Podrazumevano se sledeća stanja smatraju neaktivnim:

| Domen entiteta | Neaktivna stanja |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Koriste se i sledeća podešavanja:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Prilagođena konfiguracija

Za sopstvena pravila napravite datoteku:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Primer:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Konfiguracija se čuva odvojeno od datoteka dodatka kojima upravlja HACS, pa je ažuriranja neće prepisati.

#### Kako radi odeljak `states`

Ako prilagođena konfiguracija sadrži objekat `states`, on **u potpunosti zamenjuje** ugrađenu listu. Dodatak će uzimati u obzir samo izričito navedene domene i stanja.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

U ovom primeru precrtavanje se primenjuje samo na `light` i `cover`. Ugrađena pravila za `switch`, `fan`, `climate` i ostale domene neće se koristiti.

Za povratak na ugrađenu listu uklonite `states` iz konfiguracije ili izbrišite konfiguracionu datoteku.

Ostala podešavanja su nezavisna: ako podešavanje nije navedeno, koristi se njegova ugrađena vrednost.

<a id="background"></a>
#### Pozadina neaktivne ikone

Ako Home Assistant već prikazuje ugrađenu pozadinu neaktivne ikone, dodatak je ne menja.

Kada pozadina nedostaje, dodatak dodaje bledi krug koji odgovara stilu standardnih neaktivnih ikona Pločica u Home Assistant-u.

Isključivanje:

```json
{
  "faint_background_when_missing": false
}
```

Promena providnosti:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Privremena konfiguracija preko konzole

`haMdiOffFallback.configure()` koristi ista pravila.

Prosleđeni objekat `states` u potpunosti zamenjuje trenutnu listu:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Ako `states` nije prosleđen, trenutna lista ostaje nepromenjena:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Podešavanja primenjena preko `configure()` važe samo u trenutnoj kartici do ponovnog učitavanja stranice. Za trajnu konfiguraciju koristite JSON datoteku.

<a id="reload-config"></a>
#### Ponovno učitavanje konfiguracije

Nakon izmene JSON datoteke konfiguraciju možete ponovo učitati bez osvežavanja stranice:

```js
haMdiOffFallback.reloadConfig()
```

Prikaz aktivne konfiguracije:

```js
haMdiOffFallback.getConfig()
```
