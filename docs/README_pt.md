> O Home Assistant permite utilizar quaisquer ícones MDI, mas nem todos possuem uma variante `-off`. Assim, um dispositivo pode já estar desligado enquanto o respetivo ícone continua a parecer ativo. Este plug-in adiciona automaticamente um traço ao estilo MDI às entidades inativas quando não existe um ícone nativo de desligado.

# 🚫 MDI Off Fallback para o Home Assistant

![Visualização do funcionamento do plug-in](demo.jpg)

O plug-in foi desenvolvido para que o traço adicionado pareça uma parte nativa do Home Assistant:
* funciona com os cartões Mosaico padrão sem os substituir e preserva o aspeto, comportamento, cores, tamanhos e interações originais;
* altera apenas ícones já renderizados e apenas quando não existe uma variante nativa `-off`;
* adiciona um fundo circular discreto ao estilo do Home Assistant quando o fundo nativo não existe;
* não altera estados das entidades nem interfere com o funcionamento dos dispositivos.

<a id="installation"></a>
## 📦 Instalação

### 🛍 Instalação através do HACS
ℹ️ [O que é o HACS e como o instalar?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_pt.md)

#### 1. Adicionar este repositório ao HACS
A inclusão do plug-in no catálogo padrão do HACS pode demorar vários meses. Por isso, adicione primeiro este repositório manualmente:
1. Abra o HACS.
2. Abra o menu no canto superior direito e selecione **Repositórios personalizados**.
3. Adicione o repositório:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Selecione o tipo **Painel** e clique em **Adicionar**.

> Adicionar o repositório a **Repositórios personalizados** apenas disponibiliza o plug-in no HACS. O plug-in é instalado separadamente através do botão **Transferir**.

#### 2. Instalar o plug-in
1. Pesquise no HACS por: `MDI Off Fallback` e abra-o.
2. Clique em **Transferir** e confirme a instalação.
3. Quando a transferência terminar, atualize a página do Home Assistant limpando a cache do navegador.

<a id="manual-installation"></a>
### 🧑‍💻 Instalação manual (sem HACS)

1. Transfira [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Copie o ficheiro para `/config/www/ha-mdi-off-fallback.js`.
3. [Aceda a Recursos](https://my.home-assistant.io/redirect/lovelace_resources/) ou abra-os manualmente no Home Assistant: **Definições → Painéis → ⋮ → Recursos** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Clique em **Adicionar recurso** (**Add resource**).
5. Introduza `/local/ha-mdi-off-fallback.js` no campo URL.
6. Selecione **Módulo JavaScript** (**JavaScript Module**) e clique em **Criar** (**Create**).
7. Atualize a página do Home Assistant limpando a cache do navegador.

<a id="configuration"></a>
## 🔧 Configuração

A configuração personalizada é opcional. Sem um ficheiro personalizado, o plug-in utiliza os valores incorporados:

<a id="default-configuration"></a>
### Configuração predefinida

Por predefinição, os seguintes estados são considerados inativos:

| Domínio da entidade | Estados inativos |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

São também utilizadas as seguintes definições:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Configuração personalizada

Para definir as suas próprias regras, crie o ficheiro:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Exemplo:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

A configuração é guardada separadamente dos ficheiros do plug-in geridos pelo HACS, pelo que as atualizações não a substituem.

#### Funcionamento da secção `states`

Se a configuração personalizada contiver um objeto `states`, este **substitui completamente** a lista incorporada. O plug-in considerará apenas os domínios e estados explicitamente indicados.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

Neste exemplo, o traço será aplicado apenas a `light` e `cover`. As regras incorporadas para `switch`, `fan`, `climate` e os restantes domínios não serão utilizadas.

Para regressar à lista incorporada, remova `states` da configuração ou elimine o ficheiro de configuração.

As restantes definições são independentes: quando uma definição é omitida, mantém-se o respetivo valor incorporado.

<a id="background"></a>
#### Fundo do ícone inativo

Se o Home Assistant já apresentar o fundo nativo do ícone inativo, o plug-in não o altera.

Se esse fundo não existir, o plug-in adiciona um círculo discreto correspondente ao estilo dos ícones Mosaico inativos padrão do Home Assistant.

Desativar:

```json
{
  "faint_background_when_missing": false
}
```

Alterar a opacidade:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Configuração temporária através da consola

`haMdiOffFallback.configure()` utiliza as mesmas regras.

Um objeto `states` fornecido substitui completamente a lista atual:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Se `states` for omitido, a lista atual permanece inalterada:

```js
haMdiOffFallback.configure({
  debug: true
})
```

As definições aplicadas através de `configure()` mantêm-se apenas no separador atual até a página ser recarregada. Utilize o ficheiro JSON para uma configuração permanente.

<a id="reload-config"></a>
#### Recarregar a configuração

Depois de alterar o ficheiro JSON, pode recarregar a configuração sem atualizar a página:

```js
haMdiOffFallback.reloadConfig()
```

Ver a configuração ativa:

```js
haMdiOffFallback.getConfig()
```
