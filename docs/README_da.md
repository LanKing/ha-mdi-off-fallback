> Home Assistant giver mulighed for at bruge vilkårlige MDI-ikoner, men ikke alle ikoner har en `-off`-variant. Derfor kan en enhed være slukket, mens ikonet stadig ser aktivt ud. Dette plugin tilføjer automatisk en skråstreg i MDI-stil til inaktive entiteter, når der ikke findes et indbygget slukket ikon.

# 🚫 MDI Off Fallback til Home Assistant

![Visualisering af pluginets funktion](demo.jpg)

Pluginet er udviklet, så den tilføjede skråstreg ser ud som en indbygget del af Home Assistant:
* fungerer med standard Tile-kort uden at erstatte dem og bevarer deres normale udseende, adfærd, farver, størrelser og interaktioner;
* understøtter også 🍄 `Mushroom Template Card`; kortet skal have en `entity` angivet, så pluginet kan bestemme dets tilstand;
* ændrer kun allerede gengivne ikoner og kun når der ikke findes en indbygget `-off`-variant;
* kan eventuelt tilføje en svag cirkulær baggrund, når den oprindelige baggrund mangler;
* ændrer ikke entiteternes tilstande og griber ikke ind i enhedernes funktion.
<a id="installation"></a>
## 📦 Installation

### 🛍 Installation via HACS
ℹ️ [Hvad er HACS, og hvordan installeres det?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_da.md)

#### 1. Tilføj dette lager til HACS
Det kan tage måneder, før pluginet officielt bliver tilføjet til HACS, så lageret skal først tilføjes manuelt:
1. Åbn HACS.
2. Åbn menuen øverst til højre, og vælg **Brugerdefinerede lagre** (**Custom repositories**).
3. Tilføj lageret:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```

4. Vælg typen **Dashboard**, og klik på **Tilføj** (**Add**).

> Når lageret tilføjes under **Brugerdefinerede lagre**, bliver pluginet kun tilgængeligt i HACS. Selve pluginet installeres separat med knappen **Download**.

#### 2. Installer pluginet
1. Søg i HACS efter: `MDI Off Fallback`, og åbn det.
2. Klik på **Download**, og bekræft installationen.
3. Når download er færdig, skal Home Assistant genindlæses med ryddet browsercache.

<a id="manual-installation"></a>
### 🧑‍💻 Manuel installation (uden HACS)

1. Download [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Kopiér filen til `/config/www/ha-mdi-off-fallback.js`.
3. [Gå til Ressourcer](https://my.home-assistant.io/redirect/lovelace_resources/), eller åbn dem manuelt i Home Assistant: **Indstillinger → Dashboards → ⋮ → Ressourcer** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Klik på **Tilføj ressource** (**Add resource**).
5. Angiv `/local/ha-mdi-off-fallback.js` i URL-feltet.
6. Vælg **JavaScript-modul** (**JavaScript Module**), og klik på **Opret** (**Create**).
7. Genindlæs Home Assistant med ryddet browsercache.

<a id="configuration"></a>
## 🔧 Konfiguration

Brugerdefineret konfiguration er valgfri. Uden en brugerdefineret fil bruger pluginet de indbyggede værdier:

<a id="default-configuration"></a>
### Standardkonfiguration

Følgende tilstande betragtes som inaktive som standard:

| Entitetsdomæne | Inaktive tilstande |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Følgende indstillinger anvendes også:

```json
{
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Brugerdefineret konfiguration

Opret denne fil for at definere dine egne regler:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Eksempel:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Konfigurationen gemmes separat fra pluginfilerne, der administreres af HACS, så pluginopdateringer ikke overskriver den.

#### Sådan fungerer sektionen `states`

Hvis den brugerdefinerede konfiguration indeholder et `states`-objekt, **erstatter det hele den indbyggede liste**. Pluginet tager kun højde for de domæner og tilstande, der er angivet eksplicit.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

I dette eksempel anvendes skråstregen kun på `light` og `cover`. De indbyggede regler for `switch`, `fan`, `climate` og de øvrige domæner anvendes ikke.

Fjern `states` fra konfigurationen, eller slet konfigurationsfilen for at vende tilbage til den indbyggede liste.

De øvrige indstillinger er uafhængige: Hvis en indstilling ikke er angivet, bevares dens indbyggede værdi.

<a id="background"></a>
#### Valgfri baggrund for ikoner uden en cirkel

Nogle MDI-ikoner er visuelt off-center. Efter en skråstreg er tilføjet, kan de se ubalancerede ud, når der ikke er nogen cirkulær baggrund til at indramme dem.

Dette generede min følelse af visuel orden, så plugin'et inkluderer en valgfri indstilling, der tegner en svag cirkel bag inaktive ikoner, når Home Assistant ikke giver en.

Denne mulighed er deaktiveret som standard, fordi cirklen har en betydning i Home Assistant-grænsefladen: på et Tile-kort angiver det normalt, at et klik på ikonet udfører en separat handling fra at klikke på resten af ​​kortet. Tilføjelse af en cirkel udelukkende for visuel justering ændrer derfor den visuelle semantik.

Du kan stadig aktivere baggrunden, hvis du foretrækker det mere afbalancerede udseende:

```json
{
  "faint_background_when_missing": true
}
```

Når det er aktiveret, tilføjer plugin'et kun baggrunden, hvor Home Assistant ikke allerede gengiver en.

Du kan også justere dens opacitet:

```json
{
  "faint_background_opacity": 0.2
}
```

Vælg den opførsel, der betyder mest for dit dashboard: bevar Home Assistant's indbyggede interaktionssignaler eller hold skåret ikoner visuelt centreret.

<a id="runtime-configuration"></a>
#### Midlertidig konfiguration via konsollen

`haMdiOffFallback.configure()` bruger samme logik.

Et angivet `states`-objekt erstatter hele den aktuelle liste:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Hvis `states` ikke angives, ændres den aktuelle liste ikke:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Indstillinger, der anvendes via `configure()`, er kun aktive på den aktuelle fane, indtil siden genindlæses. Brug JSON-filen til permanent konfiguration.

<a id="reload-config"></a>
#### Genindlæsning af konfigurationen

Efter redigering af JSON-filen kan konfigurationen genindlæses uden at genindlæse siden:

```js
haMdiOffFallback.reloadConfig()
```

Vis den aktive konfiguration:

```js
haMdiOffFallback.getConfig()
```
