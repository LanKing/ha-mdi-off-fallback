> Home Assistant leyfir notkun hvaða MDI-tákns sem er, en ekki eru öll tákn með `-off` útgáfu. Því getur tæki verið slökkt þó táknið líti enn út fyrir að vera virkt. Þessi viðbót bætir sjálfkrafa við skástriki í MDI-stíl á óvirkar einingar þegar innbyggt slökkt tákn er ekki til.

# 🚫 MDI Off Fallback fyrir Home Assistant

![Sýning á virkni viðbótarinnar](demo.jpg)

Viðbótin er hönnuð þannig að skástrikið líti út eins og innbyggður hluti af Home Assistant:
* virkar með stöðluðum Tile-spjöldum án þess að skipta þeim út og varðveitir útlit, hegðun, liti, stærðir og samskipti;
* breytir aðeins táknum sem þegar hafa verið birt og aðeins þegar engin innbyggð `-off` útgáfa er til;
* bætir við daufum hringlaga bakgrunni í Home Assistant-stíl þegar innbyggðan bakgrunn vantar;
* breytir ekki stöðu eininga og hefur ekki áhrif á virkni tækja.

<a id="installation"></a>
## 📦 Uppsetning

### 🛍 Uppsetning með HACS
ℹ️ [Hvað er HACS og hvernig er það sett upp?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_is.md)

#### 1. Bæta þessari geymslu við HACS
Það getur tekið marga mánuði áður en viðbótin birtist í sjálfgefna HACS-safninu, svo fyrst þarf að bæta geymslunni við handvirkt:
1. Opnaðu HACS.
2. Opnaðu valmyndina efst til hægri og veldu **Sérsniðnar geymslur** (**Custom repositories**).
3. Bættu þessari geymslu við:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Veldu **Mælaborð** (**Dashboard**) sem tegund og ýttu á **Bæta við** (**Add**).

> Að bæta geymslu við **Sérsniðnar geymslur** gerir viðbótina aðeins aðgengilega í HACS. Viðbótin sjálf er sett upp sérstaklega með hnappinum **Sækja** (**Download**).

#### 2. Setja viðbótina upp
1. Leitaðu í HACS að: `MDI Off Fallback` og opnaðu hana.
2. Ýttu á **Sækja** (**Download**) og staðfestu uppsetninguna.
3. Þegar niðurhalinu er lokið skaltu endurhlaða Home Assistant og hreinsa skyndiminni vafrans.

<a id="manual-installation"></a>
### 🧑‍💻 Handvirk uppsetning (án HACS)

1. Sæktu [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Afritaðu skrána í `/config/www/ha-mdi-off-fallback.js`.
3. [Opnaðu Tilföng](https://my.home-assistant.io/redirect/lovelace_resources/) eða farðu þangað handvirkt í Home Assistant: **Stillingar → Mælaborð → ⋮ → Tilföng** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Ýttu á **Bæta við tilfangi** (**Add resource**).
5. Sláðu inn `/local/ha-mdi-off-fallback.js` í URL-reitinn.
6. Veldu **JavaScript-eining** (**JavaScript Module**) og ýttu á **Búa til** (**Create**).
7. Endurhlaðaðu Home Assistant og hreinsaðu skyndiminni vafrans.

<a id="configuration"></a>
## 🔧 Stillingar

Sérsniðin stilling er valfrjáls. Án sérsniðinnar skráar notar viðbótin innbyggð gildi:

<a id="default-configuration"></a>
### Sjálfgefnar stillingar

Sjálfgefið teljast eftirfarandi stöður óvirkar:

| Lén einingar | Óvirkar stöður |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Einnig eru eftirfarandi stillingar notaðar:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Sérsniðnar stillingar

Til að skilgreina eigin reglur skaltu búa til þessa skrá:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Dæmi:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Stillingarnar eru geymdar aðskildar frá viðbótarskrám sem HACS sér um, þannig að uppfærslur skrifa þær ekki yfir.

#### Hvernig `states` hlutinn virkar

Ef sérsniðnar stillingar innihalda `states` hlut, **kemur hann alveg í stað** innbyggða listans. Viðbótin tekur aðeins tillit til léna og staða sem eru sérstaklega skráð.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

Í þessu dæmi er skástrikið aðeins notað á `light` og `cover`. Innbyggðar reglur fyrir `switch`, `fan`, `climate` og önnur lén eru ekki notaðar.

Til að fara aftur í innbyggða listann skaltu fjarlægja `states` úr stillingunum eða eyða stillingaskránni.

Aðrar stillingar eru óháðar: ef stilling er ekki tilgreind heldur hún innbyggðu gildi sínu.

<a id="background"></a>
#### Bakgrunnur óvirks tákns

Ef Home Assistant sýnir þegar innbyggðan bakgrunn óvirks tákns lætur viðbótin hann óbreyttan.

Ef bakgrunninn vantar bætir viðbótin við daufum hring sem passar við staðlaðan stíl óvirks Tile-tákns í Home Assistant.

Slökkva:

```json
{
  "faint_background_when_missing": false
}
```

Breyta gagnsæi:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Tímabundnar stillingar úr stjórnborði

`haMdiOffFallback.configure()` notar sömu reglur.

Uppgefinn `states` hlutur kemur alveg í stað núverandi lista:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Ef `states` er sleppt helst núverandi listi óbreyttur:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Stillingar sem eru settar með `configure()` gilda aðeins í núverandi flipa þar til síðunni er endurhlaðið. Notaðu JSON-skrána fyrir varanlegar stillingar.

<a id="reload-config"></a>
#### Endurhlaða stillingum

Eftir að JSON-skránni er breytt má endurhlaða stillingunum án þess að endurhlaða síðunni:

```js
haMdiOffFallback.reloadConfig()
```

Skoða virkar stillingar:

```js
haMdiOffFallback.getConfig()
```
