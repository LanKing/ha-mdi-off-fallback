> Home Assistant permite utilizar cualquier icono MDI, pero no todos disponen de una variante `-off`. Como resultado, un dispositivo puede estar apagado mientras su icono sigue pareciendo activo. Este complemento añade automáticamente una barra diagonal de estilo MDI a las entidades inactivas cuando no existe un icono de apagado nativo.

# 🚫 MDI Off Fallback para Home Assistant

![Visualización del funcionamiento del complemento](demo.jpg)

El complemento está diseñado para que la barra diagonal añadida parezca una parte nativa de Home Assistant:
* funciona con las tarjetas Tile estándar sin sustituirlas y conserva su aspecto, comportamiento, colores, tamaños e interacciones originales;
* también admite `Mushroom Template Card`; la tarjeta debe tener una `entity` configurada para que el complemento pueda determinar su estado;
* modifica únicamente los iconos ya renderizados y solo cuando no existe una variante `-off` nativa;
* opcionalmente, puede agregar un fondo circular tenue cuando falta el fondo nativo;
* no cambia los estados de las entidades ni interfiere con el funcionamiento de los dispositivos.
<a id="installation"></a>
## 📦 Instalación

### 🛍 Instalación mediante HACS
ℹ️ [¿Qué es HACS y cómo se instala?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_es.md)

#### 1. Añadir este repositorio a HACS
La incorporación oficial del complemento a HACS puede tardar meses, por lo que primero es necesario añadir el repositorio manualmente:
1. Abra HACS.
2. Abra el menú de la esquina superior derecha y seleccione **Repositorios personalizados** (**Custom repositories**).
3. Añada el repositorio:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```

4. Seleccione el tipo **Panel de control** (**Dashboard**) y pulse **Añadir** (**Add**).

> Añadir el repositorio a **Repositorios personalizados** solo hace que el complemento esté disponible en HACS. El complemento se instala por separado mediante el botón **Descargar** (**Download**).

#### 2. Instalar el complemento
1. Busque en HACS: `MDI Off Fallback` y ábralo.
2. Pulse **Descargar** (**Download**) y confirme la instalación.
3. Cuando finalice la descarga, vuelva a cargar Home Assistant borrando la caché del navegador.

<a id="manual-installation"></a>
### 🧑‍💻 Instalación manual (sin HACS)

1. Descargue [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Copie el archivo en `/config/www/ha-mdi-off-fallback.js`.
3. [Vaya a Recursos](https://my.home-assistant.io/redirect/lovelace_resources/) o ábralos manualmente en Home Assistant: **Ajustes → Paneles de control → ⋮ → Recursos** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Pulse **Añadir recurso** (**Add resource**).
5. Introduzca `/local/ha-mdi-off-fallback.js` en el campo URL.
6. Seleccione **Módulo JavaScript** (**JavaScript Module**) y pulse **Crear** (**Create**).
7. Vuelva a cargar Home Assistant borrando la caché del navegador.

## 🔧 Configuración

La configuración personalizada es opcional. Sin un archivo personalizado, el complemento utiliza los valores integrados:

<a id="default-configuration"></a>
### Configuración predeterminada

De forma predeterminada, los siguientes estados se consideran inactivos:

| Dominio de la entidad | Estados inactivos |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

También se utilizan los siguientes parámetros:

```json
{
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Configuración personalizada

Para definir sus propias reglas, cree el archivo:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Ejemplo:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

La configuración se almacena por separado de los archivos del complemento administrados por HACS, por lo que las actualizaciones no la sobrescriben.

#### Funcionamiento de la sección `states`

Si la configuración personalizada contiene un objeto `states`, este **sustituye por completo** la lista integrada. El complemento solo tendrá en cuenta los dominios y estados indicados explícitamente.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

En este ejemplo, la barra diagonal solo se aplica a `light` y `cover`. No se utilizarán las reglas integradas para `switch`, `fan`, `climate` ni los demás dominios.

Para volver a la lista integrada, elimine `states` de la configuración o borre el archivo de configuración.

Los demás parámetros son independientes: si no se especifica un parámetro, se conserva su valor integrado.

<a id="background"></a>
#### Fondo opcional para iconos sin círculo

Algunos íconos MDI están visualmente descentrados. Después de agregar una barra, pueden verse desequilibradas cuando no hay un fondo circular para enmarcarlas.

Esto molestó mi sentido del orden visual, por lo que el complemento incluye una configuración opcional que dibuja un círculo tenue detrás de los íconos inactivos cuando Home Assistant no proporciona uno.

Esta opción está deshabilitada de forma predeterminada porque el círculo tiene un significado en la interfaz Home Assistant: en una tarjeta Tile, normalmente indica que hacer clic en el icono realiza una acción separada de hacer clic en el resto de la tarjeta. Por lo tanto, agregar un círculo únicamente para alineación visual cambia esa semántica visual.

Aún puedes habilitar el fondo si prefieres una apariencia más equilibrada:

```json
{
  "faint_background_when_missing": true
}
```

Cuando está habilitado, el complemento solo agrega el fondo donde Home Assistant aún no representa uno.

También puedes ajustar su opacidad:

```json
{
  "faint_background_opacity": 0.2
}
```

Elija el comportamiento que sea más importante para su panel: preservar las señales de interacción nativas de Home Assistant o mantener los íconos recortados visualmente centrados.

<a id="runtime-configuration"></a>
#### Configuración temporal mediante la consola

`haMdiOffFallback.configure()` utiliza la misma lógica.

Un objeto `states` proporcionado sustituye por completo la lista actual:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Si no se proporciona `states`, la lista actual no cambia:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Los ajustes aplicados mediante `configure()` solo permanecen activos en la pestaña actual hasta que se vuelva a cargar la página. Utilice el archivo JSON para una configuración permanente.

<a id="reload-config"></a>
#### Volver a cargar la configuración

Después de editar el archivo JSON, la configuración puede volver a cargarse sin recargar la página:

```js
haMdiOffFallback.reloadConfig()
```

Ver la configuración activa:

```js
haMdiOffFallback.getConfig()
```
