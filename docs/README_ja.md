> Home Assistant では任意の MDI アイコンを使用できますが、すべてのアイコンに `-off` バリエーションがあるわけではありません。そのため、デバイスがすでにオフでも、アイコンがまだアクティブに見えることがあります。このプラグインは、標準のオフアイコンがない場合に、非アクティブなエンティティへ MDI 風の斜線を自動で追加します。

# 🚫 Home Assistant 用 MDI Off Fallback

![プラグインの動作イメージ](demo.jpg)

追加された斜線が Home Assistant の標準要素に見えるように設計されています。
* 標準の Tile カードを置き換えずに動作し、標準の外観、動作、色、サイズ、操作性を維持します。
* すでに描画されたアイコンだけを、標準の `-off` バリエーションがない場合に限って変更します。
* 標準の背景がない場合は、Home Assistant 風の薄い円形背景を追加します。
* エンティティの状態を変更せず、デバイスの動作にも干渉しません。

<a id="installation"></a>
## 📦 インストール

### 🛍 HACS 経由でインストール
ℹ️ [HACS とは何ですか？また、どのようにインストールしますか？](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_ja.md)

#### 1. このリポジトリを HACS に追加
プラグインが HACS の標準カタログに追加されるまで数か月かかる場合があるため、最初にこのリポジトリを手動で追加します。
1. HACS を開きます。
2. 右上のメニューを開き、**カスタムリポジトリ** (**Custom repositories**) を選択します。
3. 次のリポジトリを追加します。

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. 種類に **ダッシュボード** (**Dashboard**) を選択し、**追加** (**Add**) を押します。

> **カスタムリポジトリ** に追加しただけでは、プラグインが HACS で利用可能になるだけです。プラグイン本体は **ダウンロード** (**Download**) ボタンから別途インストールします。

#### 2. プラグインをインストール
1. HACS で `MDI Off Fallback` を検索し、開きます。
2. **ダウンロード** (**Download**) を押してインストールを確認します。
3. ダウンロード完了後、ブラウザーのキャッシュを消去して Home Assistant を再読み込みします。

<a id="manual-installation"></a>
### 🧑‍💻 手動インストール（HACS を使用しない場合）

1. [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js) をダウンロードします。
2. ファイルを `/config/www/ha-mdi-off-fallback.js` にコピーします。
3. [リソースを開く](https://my.home-assistant.io/redirect/lovelace_resources/)か、Home Assistant で手動で開きます：**設定 → ダッシュボード → ⋮ → リソース** *(**Settings → Dashboards → ⋮ → Resources**)*。
4. **リソースを追加** (**Add resource**) を押します。
5. URL 欄に `/local/ha-mdi-off-fallback.js` を入力します。
6. **JavaScript モジュール** (**JavaScript Module**) を選択し、**作成** (**Create**) を押します。
7. ブラウザーのキャッシュを消去して Home Assistant を再読み込みします。

<a id="configuration"></a>
## 🔧 設定

カスタム設定は任意です。カスタムファイルがない場合、プラグインは内蔵値を使用します。

<a id="default-configuration"></a>
### デフォルト設定

デフォルトでは、次の状態が非アクティブとして扱われます。

| エンティティドメイン | 非アクティブ状態 |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

次の設定も使用されます。

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### カスタム設定

独自のルールを指定するには、次のファイルを作成します。

```text
/config/www/ha-mdi-off-fallback.config.json
```

例：

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

設定は HACS が管理するプラグインファイルとは別に保存されるため、プラグインの更新で上書きされません。

#### `states` セクションの動作

カスタム設定に `states` オブジェクトが含まれる場合、内蔵リストを**完全に置き換えます**。プラグインは明示的に列挙されたドメインと状態だけを対象にします。

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

この例では、斜線は `light` と `cover` のみに適用されます。`switch`、`fan`、`climate` などの内蔵ルールは使用されません。

内蔵リストに戻すには、設定から `states` を削除するか、設定ファイル自体を削除します。

その他の設定は独立しています。指定しなかった設定には内蔵値が使用されます。

<a id="background"></a>
#### 非アクティブアイコンの背景

Home Assistant がすでに標準の非アクティブ背景を描画している場合、プラグインは変更しません。

背景がない場合、Home Assistant の標準的な非アクティブ Tile アイコンに合う薄い円を追加します。

無効化：

```json
{
  "faint_background_when_missing": false
}
```

不透明度の変更：

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### コンソールからの一時設定

`haMdiOffFallback.configure()` も同じルールを使用します。

指定した `states` オブジェクトは現在のリストを完全に置き換えます。

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

`states` を省略した場合、現在のリストは変更されません。

```js
haMdiOffFallback.configure({
  debug: true
})
```

`configure()` で指定した設定は、ページを再読み込みするまで現在のタブでのみ有効です。永続的な設定には JSON ファイルを使用してください。

<a id="reload-config"></a>
#### 設定の再読み込み

JSON ファイルを編集した後、ページを再読み込みせずに設定を読み直せます。

```js
haMdiOffFallback.reloadConfig()
```

現在の設定を表示：

```js
haMdiOffFallback.getConfig()
```
