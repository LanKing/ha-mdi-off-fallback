# 🚫 Home Assistant-এর জন্য MDI Off Fallback

![প্লাগইনের কাজের দৃশ্যায়ন](demo.jpg)

প্লাগইনটি এমনভাবে তৈরি করা হয়েছে যাতে যোগ করা তির্যক দাগটি Home Assistant-এর স্বাভাবিক অংশের মতো দেখায়:
* স্ট্যান্ডার্ড Tile কার্ড প্রতিস্থাপন না করে কাজ করে এবং তাদের স্বাভাবিক চেহারা, আচরণ, রং, আকার ও ইন্টারঅ্যাকশন বজায় রাখে;
* 🍄 `Mushroom Template Card`-ও সমর্থন করে; প্লাগইন যাতে এর অবস্থা নির্ধারণ করতে পারে, কার্ডে অবশ্যই একটি `entity` নির্ধারিত থাকতে হবে;
* শুধু ইতিমধ্যে রেন্ডার করা আইকন পরিবর্তন করে এবং কেবল তখনই, যখন কোনো বিল্ট-ইন `-off` সংস্করণ নেই;
* নেটিভ ব্যাকগ্রাউন্ড অনুপস্থিত থাকলে ঐচ্ছিকভাবে একটি ম্লান বৃত্তাকার পটভূমি যোগ করতে পারে;
* এন্টিটির অবস্থা পরিবর্তন করে না এবং ডিভাইসের কাজে হস্তক্ষেপ করে না।

## 📦 ইনস্টলেশন

### 🛍 HACS-এর মাধ্যমে ইনস্টলেশন
ℹ️ [HACS কী এবং কীভাবে এটি ইনস্টল করতে হয়?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_bn.md)

🚀 [এই লিংক ব্যবহার করে রিপোজিটরি যোগ করার চেষ্টা করুন](https://my.home-assistant.io/redirect/hacs_repository/?owner=LanKing&repository=ha-mdi-off-fallback&category=plugin)। আপনার HA-তে এই পদ্ধতি সমর্থিত হলে এবং কাজ করলে, খোলা উইন্ডোতে **Add** চাপুন, তারপর নিচের ডানদিকে **Download** চাপুন। সবকিছু ঠিকভাবে হলে ইনস্টলেশন সম্পন্ন এবং বাকি ইনস্টলেশন ধাপগুলো এড়িয়ে যেতে পারেন। সরাসরি [কনফিগারেশন](#configuration)-এ যান।

#### 1. এই রিপোজিটরিটি HACS-এ যোগ করুন
প্লাগইনটি আনুষ্ঠানিকভাবে HACS-এ যোগ হতে কয়েক মাস লাগতে পারে, তাই প্রথমে রিপোজিটরিটি নিজে HACS-এ যোগ করতে হবে:
1. HACS খুলুন।
2. উপরের ডান কোণের মেনু খুলে **কাস্টম রিপোজিটরি** (**Custom repositories**) নির্বাচন করুন।
3. রিপোজিটরিটি যোগ করুন:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```

4. ধরন হিসেবে **ড্যাশবোর্ড** (**Dashboard**) নির্বাচন করে **যোগ করুন** (**Add**) চাপুন।

> **কাস্টম রিপোজিটরি** তালিকায় রিপোজিটরি যোগ করলে প্লাগইনটি শুধু HACS-এ উপলভ্য হয়। প্লাগইনটি আলাদাভাবে **ডাউনলোড** (**Download**) বোতাম দিয়ে ইনস্টল করতে হবে।

#### 2. প্লাগইন ইনস্টল করুন
1. HACS-এ খুঁজুন: `MDI Off Fallback` এবং এটি খুলুন।
2. **ডাউনলোড** (**Download**) চাপুন এবং ইনস্টলেশন নিশ্চিত করুন।
3. ডাউনলোড শেষ হলে ব্রাউজারের ক্যাশ পরিষ্কার করে Home Assistant পুনরায় লোড করুন।

<a id="manual-installation"></a>
### 🧑‍💻 ম্যানুয়াল ইনস্টলেশন (HACS ছাড়া)

1. [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js) ডাউনলোড করুন।
2. ফাইলটি `/config/www/ha-mdi-off-fallback.js`-এ কপি করুন।
3. [রিসোর্সে যান](https://my.home-assistant.io/redirect/lovelace_resources/) অথবা Home Assistant-এ হাতে খুলুন: **সেটিংস → ড্যাশবোর্ড → ⋮ → রিসোর্স** *(**Settings → Dashboards → ⋮ → Resources**)*।
4. **রিসোর্স যোগ করুন** (**Add resource**) চাপুন।
5. URL ঘরে `/local/ha-mdi-off-fallback.js` লিখুন।
6. **JavaScript মডিউল** (**JavaScript Module**) নির্বাচন করে **তৈরি করুন** (**Create**) চাপুন।
7. ব্রাউজারের ক্যাশ পরিষ্কার করে Home Assistant পুনরায় লোড করুন।

<a id="configuration"></a>
## 🔧 কনফিগারেশন

কাস্টম কনফিগারেশন ঐচ্ছিক। কাস্টম ফাইল না থাকলে প্লাগইনটি বিল্ট-ইন মান ব্যবহার করে:

<a id="default-configuration"></a>
### ডিফল্ট কনফিগারেশন

ডিফল্টভাবে নিচের অবস্থাগুলোকে নিষ্ক্রিয় ধরা হয়:

| এন্টিটি ডোমেইন | নিষ্ক্রিয় অবস্থা |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

এছাড়াও নিচের সেটিংস ব্যবহার করা হয়:

```json
{
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### কাস্টম কনফিগারেশন

নিজস্ব নিয়ম নির্ধারণ করতে এই ফাইলটি তৈরি করুন:

```text
/config/www/ha-mdi-off-fallback.config.json
```

উদাহরণ:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

কনফিগারেশনটি HACS পরিচালিত প্লাগইন ফাইল থেকে আলাদা রাখা হয়, তাই প্লাগইন আপডেট এটি ওভাররাইট করবে না।

#### `states` সেকশনের আচরণ

কাস্টম কনফিগারেশনে `states` অবজেক্ট থাকলে এটি **বিল্ট-ইন তালিকাটি সম্পূর্ণভাবে প্রতিস্থাপন করে**। প্লাগইন শুধু স্পষ্টভাবে দেওয়া ডোমেইন ও অবস্থাগুলো বিবেচনা করবে।

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

এই উদাহরণে তির্যক দাগ শুধু `light` এবং `cover`-এ প্রয়োগ হবে। `switch`, `fan`, `climate` এবং অন্য ডোমেইনের বিল্ট-ইন নিয়ম ব্যবহার করা হবে না।

বিল্ট-ইন তালিকায় ফিরতে কনফিগারেশন থেকে `states` সরান অথবা কনফিগারেশন ফাইল মুছে দিন।

অন্য সেটিংস স্বাধীন: কোনো সেটিং উল্লেখ না করলে তার বিল্ট-ইন মান কার্যকর থাকে।

<a id="background"></a>
#### একটি বৃত্ত ছাড়া আইকন জন্য ঐচ্ছিক পটভূমি

কিছু MDI আইকন দৃশ্যত অফ-সেন্টার। একটি স্ল্যাশ যোগ করার পরে, সেগুলিকে ভারসাম্যহীন দেখাতে পারে যখন সেগুলিকে ফ্রেম করার জন্য কোনও বৃত্তাকার পটভূমি নেই৷

এটি আমার ভিজ্যুয়াল অর্ডারের অনুভূতিকে বিরক্ত করেছিল, তাই প্লাগইনটিতে একটি ঐচ্ছিক সেটিং রয়েছে যা নিষ্ক্রিয় আইকনগুলির পিছনে একটি অস্পষ্ট বৃত্ত আঁকে যখন Home Assistant একটি প্রদান করে না।

এই বিকল্পটি ডিফল্টরূপে নিষ্ক্রিয় থাকে কারণ Home Assistant ইন্টারফেসে চেনাশোনাটির একটি অর্থ রয়েছে: একটি Tile কার্ডে, এটি সাধারণত নির্দেশ করে যে আইকনে ক্লিক করা কার্ডের বাকি অংশে ক্লিক করার থেকে একটি পৃথক ক্রিয়া সম্পাদন করে৷ চাক্ষুষ প্রান্তিককরণের জন্য বিশুদ্ধভাবে একটি বৃত্ত যোগ করা তাই সেই ভিজ্যুয়াল শব্দার্থকে পরিবর্তন করে।

আপনি যদি আরও সুষম চেহারা পছন্দ করেন তবে আপনি এখনও পটভূমি সক্ষম করতে পারেন:

```json
{
  "faint_background_when_missing": true
}
```

সক্রিয় করা হলে, প্লাগইনটি শুধুমাত্র সেই পটভূমি যোগ করে যেখানে Home Assistant ইতিমধ্যে একটি রেন্ডার করে না।

আপনি এর অস্বচ্ছতা সামঞ্জস্য করতে পারেন:

```json
{
  "faint_background_opacity": 0.2
}
```

আপনার ড্যাশবোর্ডের জন্য যেটি আচরণ বেশি গুরুত্বপূর্ণ তা বেছে নিন: Home Assistant এর নেটিভ ইন্টারঅ্যাকশন সংকেতগুলি সংরক্ষণ করা বা স্ল্যাশ করা আইকনগুলিকে দৃশ্যত কেন্দ্রীভূত রাখা।

<a id="runtime-configuration"></a>
#### কনসোল থেকে অস্থায়ী কনফিগারেশন

`haMdiOffFallback.configure()` একই নিয়ম ব্যবহার করে।

দেওয়া `states` অবজেক্ট বর্তমান তালিকাটি সম্পূর্ণভাবে প্রতিস্থাপন করে:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

`states` না দিলে বর্তমান তালিকা অপরিবর্তিত থাকে:

```js
haMdiOffFallback.configure({
  debug: true
})
```

`configure()` দিয়ে দেওয়া সেটিংস পৃষ্ঠা পুনরায় লোড না হওয়া পর্যন্ত শুধু বর্তমান ট্যাবে কার্যকর থাকে। স্থায়ী কনফিগারেশনের জন্য JSON ফাইল ব্যবহার করুন।

<a id="reload-config"></a>
#### কনফিগারেশন পুনরায় লোড

JSON ফাইল পরিবর্তনের পর পৃষ্ঠা পুনরায় লোড না করেই কনফিগারেশন পুনরায় পড়া যায়:

```js
haMdiOffFallback.reloadConfig()
```

সক্রিয় কনফিগারেশন দেখতে:

```js
haMdiOffFallback.getConfig()
```
