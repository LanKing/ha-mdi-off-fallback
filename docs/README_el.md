Έτσι, μια συσκευή μπορεί να είναι ήδη απενεργοποιημένη ενώ το εικονίδιό της εξακολουθεί να φαίνεται ενεργό. Αυτό το πρόσθετο προσθέτει αυτόματα μια διαγώνια γραμμή τύπου MDI στις ανενεργές οντότητες όταν δεν υπάρχει ενσωματωμένο εικονίδιο απενεργοποίησης.

# 🚫 MDI Off Fallback για το Home Assistant

![Απεικόνιση της λειτουργίας του πρόσθετου](demo.jpg)

Το πρόσθετο έχει σχεδιαστεί έτσι ώστε η προστιθέμενη διαγώνια γραμμή να μοιάζει με εγγενές τμήμα του Home Assistant:
* λειτουργεί με τις τυπικές κάρτες Tile χωρίς να τις αντικαθιστά και διατηρεί την αρχική εμφάνιση, συμπεριφορά, χρώματα, μεγέθη και αλληλεπιδράσεις τους·
* τροποποιεί μόνο ήδη αποδομένα εικονίδια και μόνο όταν δεν υπάρχει εγγενής παραλλαγή `-off`·
* μπορεί προαιρετικά να προσθέσει ένα αχνό κυκλικό φόντο όταν λείπει το εγγενές φόντο.
* δεν αλλάζει τις καταστάσεις των οντοτήτων και δεν παρεμβαίνει στη λειτουργία των συσκευών.
<a id="installation"></a>
## 📦 Εγκατάσταση

### 🛍 Εγκατάσταση μέσω HACS
ℹ️ [Τι είναι το HACS και πώς εγκαθίσταται;](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_el.md)

#### 1. Προσθήκη αυτού του αποθετηρίου στο HACS
Η επίσημη προσθήκη του πρόσθετου στο HACS μπορεί να διαρκέσει μήνες, επομένως αρχικά πρέπει να προσθέσετε χειροκίνητα το αποθετήριο:
1. Ανοίξτε το HACS.
2. Ανοίξτε το μενού επάνω δεξιά και επιλέξτε **Προσαρμοσμένα αποθετήρια** (**Custom repositories**).
3. Προσθέστε το αποθετήριο:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```

4. Επιλέξτε τύπο **Πίνακας εργαλείων** (**Dashboard**) και πατήστε **Προσθήκη** (**Add**).

> Η προσθήκη του αποθετηρίου στα **Προσαρμοσμένα αποθετήρια** απλώς καθιστά το πρόσθετο διαθέσιμο στο HACS. Το ίδιο το πρόσθετο εγκαθίσταται ξεχωριστά με το κουμπί **Λήψη** (**Download**).

#### 2. Εγκατάσταση του πρόσθετου
1. Αναζητήστε στο HACS: `MDI Off Fallback` και ανοίξτε το.
2. Πατήστε **Λήψη** (**Download**) και επιβεβαιώστε την εγκατάσταση.
3. Μετά την ολοκλήρωση της λήψης, επαναφορτώστε το Home Assistant καθαρίζοντας την προσωρινή μνήμη του προγράμματος περιήγησης.

<a id="manual-installation"></a>
### 🧑‍💻 Χειροκίνητη εγκατάσταση (χωρίς HACS)

1. Κατεβάστε το [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Αντιγράψτε το αρχείο στο `/config/www/ha-mdi-off-fallback.js`.
3. [Μεταβείτε στους Πόρους](https://my.home-assistant.io/redirect/lovelace_resources/) ή ανοίξτε τους χειροκίνητα στο Home Assistant: **Ρυθμίσεις → Πίνακες εργαλείων → ⋮ → Πόροι** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Πατήστε **Προσθήκη πόρου** (**Add resource**).
5. Εισαγάγετε `/local/ha-mdi-off-fallback.js` στο πεδίο URL.
6. Επιλέξτε **Μονάδα JavaScript** (**JavaScript Module**) και πατήστε **Δημιουργία** (**Create**).
7. Επαναφορτώστε το Home Assistant καθαρίζοντας την προσωρινή μνήμη του προγράμματος περιήγησης.

## 🔧 Ρύθμιση

Η προσαρμοσμένη ρύθμιση είναι προαιρετική. Χωρίς προσαρμοσμένο αρχείο, το πρόσθετο χρησιμοποιεί τις ενσωματωμένες τιμές:

<a id="default-configuration"></a>
### Προεπιλεγμένη ρύθμιση

Από προεπιλογή, οι ακόλουθες καταστάσεις θεωρούνται ανενεργές:

| Τομέας οντότητας | Ανενεργές καταστάσεις |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Χρησιμοποιούνται επίσης οι ακόλουθες ρυθμίσεις:

```json
{
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Προσαρμοσμένη ρύθμιση

Για να ορίσετε τους δικούς σας κανόνες, δημιουργήστε το αρχείο:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Παράδειγμα:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Η ρύθμιση αποθηκεύεται ξεχωριστά από τα αρχεία του πρόσθετου που διαχειρίζεται το HACS, επομένως οι ενημερώσεις δεν την αντικαθιστούν.

#### Λειτουργία της ενότητας `states`

Αν η προσαρμοσμένη ρύθμιση περιέχει αντικείμενο `states`, αυτό **αντικαθιστά πλήρως** την ενσωματωμένη λίστα. Το πρόσθετο θα λαμβάνει υπόψη μόνο τους τομείς και τις καταστάσεις που αναφέρονται ρητά.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

Σε αυτό το παράδειγμα, η διαγώνια γραμμή εφαρμόζεται μόνο στα `light` και `cover`. Οι ενσωματωμένοι κανόνες για `switch`, `fan`, `climate` και τους υπόλοιπους τομείς δεν χρησιμοποιούνται.

Για επιστροφή στην ενσωματωμένη λίστα, αφαιρέστε το `states` από τη ρύθμιση ή διαγράψτε το αρχείο ρύθμισης.

Οι υπόλοιπες ρυθμίσεις είναι ανεξάρτητες: αν μια ρύθμιση παραλειφθεί, διατηρείται η ενσωματωμένη τιμή της.

<a id="background"></a>
#### Προαιρετικό φόντο για εικονίδια χωρίς κύκλο

Ορισμένα εικονίδια MDI είναι οπτικά εκτός κέντρου. Αφού προστεθεί μια κάθετο, μπορεί να φαίνονται μη ισορροπημένα όταν δεν υπάρχει κυκλικό φόντο για να τα πλαισιώσει.

Αυτό ενόχλησε την αίσθηση της οπτικής τάξης μου, επομένως η προσθήκη περιλαμβάνει μια προαιρετική ρύθμιση που σχεδιάζει έναν αμυδρό κύκλο πίσω από ανενεργά εικονίδια όταν το Home Assistant δεν παρέχει.

Αυτή η επιλογή είναι απενεργοποιημένη από προεπιλογή επειδή ο κύκλος έχει ένα νόημα στη διεπαφή Home Assistant: σε μια κάρτα Tile, συνήθως υποδεικνύει ότι κάνοντας κλικ στο εικονίδιο εκτελείται μια ξεχωριστή ενέργεια από το κλικ στην υπόλοιπη κάρτα. Επομένως, η προσθήκη ενός κύκλου καθαρά για οπτική στοίχιση αλλάζει αυτή την οπτική σημασιολογία.

Μπορείτε ακόμα να ενεργοποιήσετε το φόντο εάν προτιμάτε την πιο ισορροπημένη εμφάνιση:

```json
{
  "faint_background_when_missing": true
}
```

Όταν είναι ενεργοποιημένη, η προσθήκη προσθέτει μόνο το φόντο όπου το Home Assistant δεν το αποδίδει ήδη.

Μπορείτε επίσης να προσαρμόσετε την αδιαφάνειά του:

```json
{
  "faint_background_opacity": 0.2
}
```

Επιλέξτε οποιαδήποτε συμπεριφορά έχει μεγαλύτερη σημασία για τον πίνακα ελέγχου σας: διατηρώντας τα εγγενή συνθήματα αλληλεπίδρασης του Home Assistant ή διατηρώντας τα κομμένα εικονίδια οπτικά στο κέντρο.

<a id="runtime-configuration"></a>
#### Προσωρινή ρύθμιση μέσω κονσόλας

Η `haMdiOffFallback.configure()` χρησιμοποιεί την ίδια λογική.

Ένα παρεχόμενο αντικείμενο `states` αντικαθιστά πλήρως την τρέχουσα λίστα:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Αν δεν δοθεί `states`, η τρέχουσα λίστα παραμένει αμετάβλητη:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Οι ρυθμίσεις μέσω `configure()` ισχύουν μόνο στην τρέχουσα καρτέλα μέχρι την επαναφόρτωση της σελίδας. Για μόνιμη ρύθμιση χρησιμοποιήστε το αρχείο JSON.

<a id="reload-config"></a>
#### Επαναφόρτωση της ρύθμισης

Μετά την τροποποίηση του αρχείου JSON, η ρύθμιση μπορεί να επαναφορτωθεί χωρίς επαναφόρτωση της σελίδας:

```js
haMdiOffFallback.reloadConfig()
```

Προβολή ενεργής ρύθμισης:

```js
haMdiOffFallback.getConfig()
```
