> Home Assistant امکان استفاده از هر نماد MDI را فراهم می‌کند، اما همهٔ نمادها نسخهٔ `-off` ندارند. در نتیجه ممکن است دستگاه خاموش باشد، ولی نماد آن همچنان فعال به نظر برسد. این افزونه زمانی که نماد خاموش داخلی وجود ندارد، به‌طور خودکار یک خط مورب به سبک MDI به موجودیت‌های غیرفعال اضافه می‌کند.

# 🚫 MDI Off Fallback برای Home Assistant

![نمایش عملکرد افزونه](demo.jpg)

افزونه به‌گونه‌ای طراحی شده است که خط مورب افزوده‌شده مانند بخشی طبیعی از Home Assistant به نظر برسد:
* با کارت‌های استاندارد Tile بدون جایگزین‌کردن آن‌ها کار می‌کند و ظاهر، رفتار، رنگ‌ها، اندازه‌ها و تعاملات اصلی را حفظ می‌کند؛
* از 🍄 `Mushroom Template Card` نیز پشتیبانی می‌کند؛ کارت باید یک `entity` مشخص داشته باشد تا افزونه بتواند وضعیت آن را تشخیص دهد؛
* فقط نمادهایی را تغییر می‌دهد که قبلاً رندر شده‌اند و تنها زمانی که نسخهٔ داخلی `-off` وجود ندارد؛
* می‌تواند به صورت اختیاری یک پس‌زمینه دایره‌ای کم‌نور در زمانی که پس‌زمینه اصلی وجود ندارد، اضافه کند.
* وضعیت موجودیت‌ها را تغییر نمی‌دهد و در عملکرد دستگاه‌ها دخالت نمی‌کند.
<a id="installation"></a>
## 📦 نصب

### 🛍 نصب از طریق HACS
ℹ️ [HACS چیست و چگونه نصب می‌شود؟](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_fa.md)

🚀 [سعی کنید مخزن را با این پیوند اضافه کنید](https://my.home-assistant.io/redirect/hacs_repository/?owner=LanKing&repository=ha-mdi-off-fallback&category=plugin). اگر این روش در HA شما پشتیبانی می‌شود و کار می‌کند، در پنجره بازشده روی **Add** و سپس در گوشه پایین راست روی **Download** کلیک کنید. اگر همه‌چیز درست انجام شد، نصب کامل است و می‌توانید مراحل باقی‌مانده را رد کنید. مستقیماً به [پیکربندی](#configuration) بروید.

#### 1. افزودن این مخزن به HACS
ممکن است اضافه‌شدن رسمی افزونه به HACS چند ماه طول بکشد، بنابراین ابتدا مخزن را به‌صورت دستی اضافه کنید:
1. HACS را باز کنید.
2. منوی گوشهٔ بالا سمت راست را باز کرده و **مخزن‌های سفارشی** (**Custom repositories**) را انتخاب کنید.
3. مخزن را اضافه کنید:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```

4. نوع **داشبورد** (**Dashboard**) را انتخاب کرده و روی **افزودن** (**Add**) بزنید.

> افزودن مخزن به **مخزن‌های سفارشی** فقط افزونه را در HACS در دسترس قرار می‌دهد. خود افزونه جداگانه با دکمهٔ **دریافت** (**Download**) نصب می‌شود.

#### 2. نصب افزونه
1. در HACS جست‌وجو کنید: `MDI Off Fallback` و آن را باز کنید.
2. روی **دریافت** (**Download**) بزنید و نصب را تأیید کنید.
3. پس از پایان دریافت، Home Assistant را با پاک‌کردن حافظهٔ نهان مرورگر دوباره بارگذاری کنید.

<a id="manual-installation"></a>
### 🧑‍💻 نصب دستی (بدون HACS)

1. فایل [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js) را دریافت کنید.
2. فایل را در `/config/www/ha-mdi-off-fallback.js` کپی کنید.
3. [به منابع بروید](https://my.home-assistant.io/redirect/lovelace_resources/) یا آن را به‌صورت دستی در Home Assistant باز کنید: **تنظیمات → داشبوردها → ⋮ → منابع** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. روی **افزودن منبع** (**Add resource**) بزنید.
5. `/local/ha-mdi-off-fallback.js` را در کادر URL وارد کنید.
6. **ماژول JavaScript** (**JavaScript Module**) را انتخاب کرده و روی **ایجاد** (**Create**) بزنید.
7. Home Assistant را با پاک‌کردن حافظهٔ نهان مرورگر دوباره بارگذاری کنید.

<a id="configuration"></a>
## 🔧 پیکربندی

پیکربندی سفارشی اختیاری است. بدون فایل سفارشی، افزونه از مقادیر داخلی استفاده می‌کند:

<a id="default-configuration"></a>
### پیکربندی پیش‌فرض

به‌طور پیش‌فرض وضعیت‌های زیر غیرفعال در نظر گرفته می‌شوند:

| دامنهٔ موجودیت | وضعیت‌های غیرفعال |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

تنظیمات زیر نیز استفاده می‌شوند:

```json
{
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### پیکربندی سفارشی

برای تعریف قوانین خود، این فایل را ایجاد کنید:

```text
/config/www/ha-mdi-off-fallback.config.json
```

نمونه:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": false,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

پیکربندی جدا از فایل‌های افزونه که توسط HACS مدیریت می‌شوند ذخیره می‌شود، بنابراین به‌روزرسانی‌ها آن را بازنویسی نمی‌کنند.

#### نحوهٔ کار بخش `states`

اگر پیکربندی سفارشی شامل شیء `states` باشد، این شیء **فهرست داخلی را به‌طور کامل جایگزین می‌کند**. افزونه فقط دامنه‌ها و وضعیت‌هایی را در نظر می‌گیرد که صریحاً فهرست شده‌اند.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

در این نمونه، خط مورب فقط برای `light` و `cover` اعمال می‌شود. قوانین داخلی برای `switch`، `fan`، `climate` و سایر دامنه‌ها استفاده نمی‌شوند.

برای بازگشت به فهرست داخلی، `states` را از پیکربندی حذف کنید یا فایل پیکربندی را پاک کنید.

سایر تنظیمات مستقل هستند: اگر تنظیمی مشخص نشده باشد، مقدار داخلی آن حفظ می‌شود.

<a id="background"></a>
#### پس‌زمینه اختیاری برای نمادهای بدون دایره

برخی از نمادهای MDI از نظر بصری خارج از مرکز هستند. پس از اضافه شدن یک اسلش، زمانی که پس‌زمینه‌ای دایره‌ای برای قاب‌بندی وجود نداشته باشد، می‌توانند نامتعادل به نظر برسند.

این امر حس نظم بصری من را آزار می‌دهد، بنابراین این افزونه دارای یک تنظیم اختیاری است که در زمانی که Home Assistant یک آیکون را ارائه نمی‌کند، یک دایره ضعیف را پشت نمادهای غیرفعال می‌کشد.

این گزینه به‌طور پیش‌فرض غیرفعال است، زیرا دایره در رابط Home Assistant یک معنی دارد: در کارت Tile، معمولاً نشان می‌دهد که کلیک کردن روی نماد، عملی جدا از کلیک روی بقیه کارت انجام می‌دهد. بنابراین افزودن یک دایره صرفاً برای هم ترازی بصری آن معنای بصری را تغییر می دهد.

اگر ظاهر متعادل تر را ترجیح می دهید، همچنان می توانید پس زمینه را فعال کنید:

```json
{
  "faint_background_when_missing": true
}
```

وقتی فعال باشد، افزونه فقط پس‌زمینه‌ای را اضافه می‌کند که Home Assistant قبلاً آن را ارائه نکرده است.

همچنین می توانید شفافیت آن را تنظیم کنید:

```json
{
  "faint_background_opacity": 0.2
}
```

هر رفتاری را که برای داشبوردتان اهمیت بیشتری دارد انتخاب کنید: حفظ نشانه‌های تعامل بومی Home Assistant یا نگه داشتن نمادهای بریده شده از نظر بصری.

<a id="runtime-configuration"></a>
#### پیکربندی موقت از طریق کنسول

`haMdiOffFallback.configure()` از همان منطق استفاده می‌کند.

شیء `states` ارسال‌شده، فهرست فعلی را به‌طور کامل جایگزین می‌کند:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

اگر `states` ارسال نشود، فهرست فعلی تغییر نمی‌کند:

```js
haMdiOffFallback.configure({
  debug: true
})
```

تنظیمات اعمال‌شده با `configure()` فقط تا بارگذاری مجدد صفحه در زبانهٔ فعلی فعال می‌مانند. برای پیکربندی دائمی از فایل JSON استفاده کنید.

<a id="reload-config"></a>
#### بارگذاری مجدد پیکربندی

پس از ویرایش فایل JSON، می‌توان پیکربندی را بدون بارگذاری مجدد صفحه دوباره خواند:

```js
haMdiOffFallback.reloadConfig()
```

مشاهدهٔ پیکربندی فعال:

```js
haMdiOffFallback.getConfig()
```
