Plugin này tự động thêm đường gạch chéo theo phong cách MDI cho các thực thể không hoạt động khi không có biểu tượng tắt tích hợp.

# 🚫 MDI Off Fallback cho Home Assistant

![Minh họa chức năng của plugin](demo.jpg)

Plugin được thiết kế để đường gạch chéo bổ sung trông như một phần gốc của Home Assistant:
* hoạt động với thẻ Ô tiêu chuẩn mà không thay thế chúng, đồng thời giữ nguyên giao diện, hành vi, màu sắc, kích thước và tương tác;
* chỉ thay đổi các biểu tượng đã được hiển thị và chỉ khi không có biến thể `-off` tích hợp;
* thêm nền tròn mờ theo phong cách Home Assistant khi nền mặc định bị thiếu;
* không thay đổi trạng thái thực thể và không can thiệp vào hoạt động của thiết bị.

<a id="installation"></a>
## 📦 Cài đặt

### 🛍 Cài đặt qua HACS
ℹ️ [HACS là gì và cài đặt như thế nào?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_vi.md)

#### 1. Thêm kho lưu trữ này vào HACS
Có thể mất nhiều tháng để plugin được thêm vào danh mục HACS mặc định, vì vậy trước tiên hãy thêm kho lưu trữ theo cách thủ công:
1. Mở HACS.
2. Mở menu ở góc trên bên phải và chọn **Kho lưu trữ tùy chỉnh**.
3. Thêm kho lưu trữ:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Chọn loại **Bảng điều khiển** và nhấn **Thêm**.

> Việc thêm kho lưu trữ vào **Kho lưu trữ tùy chỉnh** chỉ làm cho plugin xuất hiện trong HACS. Plugin được cài đặt riêng bằng nút **Tải xuống**.

#### 2. Cài đặt plugin
1. Tìm trong HACS: `MDI Off Fallback` và mở kết quả.
2. Nhấn **Tải xuống** và xác nhận cài đặt.
3. Sau khi tải xuống hoàn tất, tải lại trang Home Assistant và xóa bộ nhớ đệm của trình duyệt.

<a id="manual-installation"></a>
### 🧑‍💻 Cài đặt thủ công (không dùng HACS)

1. Tải xuống [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Sao chép tệp vào `/config/www/ha-mdi-off-fallback.js`.
3. [Đi tới Tài nguyên](https://my.home-assistant.io/redirect/lovelace_resources/) hoặc mở thủ công trong Home Assistant: **Cài đặt → Bảng điều khiển → ⋮ → Tài nguyên** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Nhấn **Thêm tài nguyên** (**Add resource**).
5. Nhập `/local/ha-mdi-off-fallback.js` vào trường URL.
6. Chọn **Mô-đun JavaScript** (**JavaScript Module**) và nhấn **Tạo** (**Create**).
7. Tải lại trang Home Assistant và xóa bộ nhớ đệm của trình duyệt.

<a id="configuration"></a>
## 🔧 Cấu hình

Cấu hình tùy chỉnh là không bắt buộc. Nếu không có tệp tùy chỉnh, plugin sử dụng các giá trị tích hợp:

<a id="default-configuration"></a>
### Cấu hình mặc định

Theo mặc định, các trạng thái sau được coi là không hoạt động:

| Miền thực thể | Trạng thái không hoạt động |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Các cài đặt sau cũng được sử dụng:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Cấu hình tùy chỉnh

Để xác định quy tắc riêng, hãy tạo tệp:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Ví dụ:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

Cấu hình được lưu riêng với các tệp plugin do HACS quản lý, vì vậy các bản cập nhật sẽ không ghi đè lên cấu hình.

#### Cách hoạt động của phần `states`

Nếu cấu hình tùy chỉnh chứa đối tượng `states`, đối tượng này sẽ **thay thế hoàn toàn** danh sách tích hợp. Plugin chỉ xét các miền và trạng thái được liệt kê rõ ràng.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

Trong ví dụ này, đường gạch chéo chỉ được áp dụng cho `light` và `cover`. Các quy tắc tích hợp cho `switch`, `fan`, `climate` và các miền khác sẽ không được sử dụng.

Để quay lại danh sách tích hợp, hãy xóa `states` khỏi cấu hình hoặc xóa tệp cấu hình.

Các cài đặt khác độc lập với nhau: nếu một cài đặt bị bỏ qua, giá trị tích hợp của nó vẫn được sử dụng.

<a id="background"></a>
#### Nền biểu tượng không hoạt động

Nếu Home Assistant đã hiển thị nền gốc cho biểu tượng không hoạt động, plugin sẽ không thay đổi nền đó.

Nếu thiếu nền, plugin thêm một vòng tròn mờ phù hợp với phong cách của biểu tượng Ô không hoạt động tiêu chuẩn trong Home Assistant.

Tắt:

```json
{
  "faint_background_when_missing": false
}
```

Thay đổi độ mờ:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Cấu hình tạm thời qua bảng điều khiển

`haMdiOffFallback.configure()` sử dụng cùng các quy tắc.

Đối tượng `states` được cung cấp sẽ thay thế hoàn toàn danh sách hiện tại:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Nếu bỏ qua `states`, danh sách hiện tại sẽ không thay đổi:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Các cài đặt áp dụng bằng `configure()` chỉ có hiệu lực trong tab hiện tại cho đến khi trang được tải lại. Hãy dùng tệp JSON cho cấu hình lâu dài.

<a id="reload-config"></a>
#### Tải lại cấu hình

Sau khi chỉnh sửa tệp JSON, có thể tải lại cấu hình mà không cần tải lại trang:

```js
haMdiOffFallback.reloadConfig()
```

Xem cấu hình đang hoạt động:

```js
haMdiOffFallback.getConfig()
```
