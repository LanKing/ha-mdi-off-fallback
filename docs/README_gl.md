> Home Assistant permite usar calquera icona MDI, pero non todas teñen unha variante `-off`. Como resultado, un dispositivo pode estar xa apagado mentres a súa icona aínda parece activa. Este complemento engade automaticamente unha barra ao estilo MDI ás entidades inactivas cando non existe unha icona de apagado nativa.

# 🚫 MDI Off Fallback para Home Assistant

![Funcionamento do complemento](demo.jpg)

O complemento está deseñado para que a barra engadida pareza unha parte nativa de Home Assistant:
* funciona coas tarxetas Tile estándar sen substituílas e conserva o seu aspecto, comportamento, cores, tamaños e interaccións nativas;
* modifica unicamente as iconas xa renderizadas e só cando non existe unha variante nativa `-off`;
* engade un fondo circular tenue ao estilo de Home Assistant cando falta o fondo nativo;
* non cambia os estados das entidades nin interfire co funcionamento dos dispositivos.

<a id="installation"></a>
## 📦 Instalación

### 🛍 Instalación mediante HACS
ℹ️ [Que é HACS e como se instala?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_gl.md)

#### 1. Engadir este repositorio a HACS
Pode pasar meses antes de que o complemento se engada ao catálogo predeterminado de HACS, polo que primeiro debes engadir este repositorio manualmente:
1. Abre HACS.
2. Abre o menú da esquina superior dereita e selecciona **Repositorios personalizados** (**Custom repositories**).
3. Engade este repositorio:

```text
https://github.com/LanKing/ha-mdi-off-fallback
```
4. Selecciona **Panel** (**Dashboard**) como tipo e preme **Engadir** (**Add**).

> Engadir un repositorio en **Repositorios personalizados** só fai que o complemento estea dispoñible en HACS. O complemento instálase por separado co botón **Descargar** (**Download**).

#### 2. Instalar o complemento
1. Busca en HACS: `MDI Off Fallback` e ábreo.
2. Preme **Descargar** (**Download**) e confirma a instalación.
3. Cando remate a descarga, recarga Home Assistant limpando a caché do navegador.

<a id="manual-installation"></a>
### 🧑‍💻 Instalación manual (sen HACS)

1. Descarga [`ha-mdi-off-fallback.js`](https://github.com/LanKing/ha-mdi-off-fallback/releases/latest/download/ha-mdi-off-fallback.js).
2. Copia o ficheiro en `/config/www/ha-mdi-off-fallback.js`.
3. [Vai a Recursos](https://my.home-assistant.io/redirect/lovelace_resources/) ou ábreos manualmente en Home Assistant: **Configuración → Paneis → ⋮ → Recursos** *(**Settings → Dashboards → ⋮ → Resources**)*.
4. Preme **Engadir recurso** (**Add resource**).
5. Introduce `/local/ha-mdi-off-fallback.js` no campo URL.
6. Selecciona **Módulo JavaScript** (**JavaScript Module**) e preme **Crear** (**Create**).
7. Recarga Home Assistant limpando a caché do navegador.

<a id="configuration"></a>
## 🔧 Configuración

A configuración personalizada é opcional. Sen un ficheiro personalizado, o complemento usa os seus valores incorporados:

<a id="default-configuration"></a>
### Configuración predeterminada

De maneira predeterminada, os seguintes estados considéranse inactivos:

| Dominio da entidade | Estados inactivos |
|---|---|
| `light` | `off` |
| `switch` | `off` |
| `fan` | `off` |
| `climate` | `off` |
| `media_player` | `off` |
| `cover` | `closed` |
| `humidifier` | `off` |
| `water_heater` | `off` |
| `siren` | `off` |

Tamén se usan os seguintes axustes:

```json
{
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

<a id="user-configuration"></a>
### Configuración personalizada

Para definir as túas propias regras, crea este ficheiro:

```text
/config/www/ha-mdi-off-fallback.config.json
```

Exemplo:

```json
{
  "states": {
    "light": ["off"],
    "switch": ["off"],
    "fan": ["off"],
    "climate": ["off"],
    "media_player": ["off"],
    "cover": ["closed"],
    "humidifier": ["off"],
    "water_heater": ["off"],
    "siren": ["off"],
    "remote": ["off"]
  },
  "faint_background_when_missing": true,
  "faint_background_opacity": 0.2,
  "debug": false
}
```

A configuración almacénase por separado dos ficheiros do complemento xestionados por HACS, polo que as actualizacións non a sobrescriben.

#### Como funciona a sección `states`

Se a configuración personalizada contén un obxecto `states`, este **substitúe completamente** a lista incorporada. O complemento só terá en conta os dominios e estados indicados explicitamente.

```json
{
  "states": {
    "light": ["off"],
    "cover": ["closed"]
  }
}
```

Neste exemplo, a barra só se aplicará a `light` e `cover`. Non se usarán as regras incorporadas para `switch`, `fan`, `climate` nin para os demais dominios.

Para volver á lista incorporada, elimina `states` da configuración ou elimina o propio ficheiro de configuración.

Os demais axustes son independentes: se un axuste non se especifica, mantense o seu valor incorporado.

<a id="background"></a>
#### Fondo da icona inactiva

Se Home Assistant xa debuxa o fondo nativo da icona inactiva, o complemento déixao sen cambios.

Se ese fondo falta, o complemento engade un círculo tenue que coincide co estilo estándar das iconas Tile inactivas de Home Assistant.

Para desactivalo:

```json
{
  "faint_background_when_missing": false
}
```

Para cambiar a opacidade:

```json
{
  "faint_background_opacity": 0.2
}
```

<a id="runtime-configuration"></a>
#### Configuración temporal desde a consola

`haMdiOffFallback.configure()` usa as mesmas regras.

Un obxecto `states` fornecido substitúe completamente a lista actual:

```js
haMdiOffFallback.configure({
  states: {
    light: ["off"],
    cover: ["closed"],
    remote: ["off"]
  },
  debug: true
})
```

Se se omite `states`, a lista actual non cambia:

```js
haMdiOffFallback.configure({
  debug: true
})
```

Os axustes aplicados mediante `configure()` permanecen activos só na lapela actual ata que se recargue a páxina. Usa o ficheiro JSON para unha configuración permanente.

<a id="reload-config"></a>
#### Recargar a configuración

Despois de editar o ficheiro JSON, podes recargar a configuración sen recargar a páxina:

```js
haMdiOffFallback.reloadConfig()
```

Ver a configuración activa:

```js
haMdiOffFallback.getConfig()
```
